How to use these notes

Each page follows the same order: the main idea with a picture, the steps in the video's order, the formulas with every symbol explained, the worked example from the video, common mistakes, three to five interview questions, and a 30-second recap. Read the summary box first. If it is enough, move on. If not, read the page and then watch the video.
