Mutual Information

▶ Watch on YouTube

Mutual information is one number that says how closely two variables are related. It works when the variables are yes/no, when they are numbers, or when you mix the two.

In one breath

Josh wants to drop useless features from a data set. R squared cannot help here, because it needs continuous data on both sides. So he counts joint and marginal probabilities in a small table, and feeds them into the mutual information formula. The value is zero when one variable never changes, and it grows when changes in one variable track changes in the other. For a continuous variable like height, he first cuts the values into histogram bins, then treats each bin as a category.

The main idea

The data set has five people and several features: likes popcorn, height, and more. We want to predict one thing: does this person love the movie Troll 2? Collecting every feature costs time, so we want to keep only the features that help.

The usual tool is R squared, but R squared only works with continuous data. Loves Troll 2 is yes or no. Likes popcorn is also yes or no. We need a measure that does not care about the data type. Mutual information is that measure.

It is built from two kinds of probability. A joint probability is the chance that two things happen together. Three of the five people like popcorn and love Troll 2, so that joint probability is 3/5. A marginal probability is the chance of one thing alone. Two of the five people do not like popcorn, so that marginal probability is 2/5.

Josh puts all of them in one small table. The joint probabilities sit in the middle. The marginal probabilities sit along the edges, and that is where the name comes from. You can read a marginal probability straight from the data, or add up the joint probabilities in that row or column. Both routes give the same answer.

Step by step

  1. Pick the pair you care about: one feature, such as likes popcorn, and the thing you want to predict, loves Troll 2.
  2. Count every combination and write the four joint probabilities into the middle of the table.
  3. Fill the margins. Add each row of joint probabilities, and add each column, to get the marginal probabilities.
  4. Expand the two summations. Each summation runs over the values of one variable, so a yes/no pair gives four terms.
  5. Plug the numbers into each term, take the logarithm, and add the terms together. Josh uses the natural log, because that is the default in most machine learning tools.
  6. Repeat for the other features. Compare the values, and keep the features with the higher mutual information.

To show what the number means, Josh edits the data three times and recomputes. When likes popcorn is yes for everybody, the mutual information is zero. A column that never changes can tell you nothing about a column that does.

When both columns change in exactly the same way, the value rises to about 0.5. When both columns change in exactly opposite ways, the value is again about 0.5. Mutual information measures how much the changes are linked, not which direction they point.

Height is continuous, so it has no ready-made categories. Josh builds a histogram of the heights, then treats each bin as one category. With three bins and a yes/no target, the table has six cells, so the sum has six terms. The answer is again 0.22, so height and likes popcorn are equally useful here.

Formulas

Mutual information
$$ I(X;Y) \;=\; \sum_{x \in X} \sum_{y \in Y} P(x,y)\, \log\!\left( \frac{P(x,y)}{P(x)\,P(y)} \right) $$

Symbols: \(X\) is the first variable, such as likes popcorn. \(Y\) is the second variable, loves Troll 2. \(x\) and \(y\) are single values, for example "yes". \(P(x,y)\) is the joint probability that both values appear in the same row. \(P(x)\) and \(P(y)\) are the marginal probabilities. The two sums cover every combination, so a yes/no pair gives four terms. The log is the natural log by default. What it tells you: it compares the real joint probability with the one you would expect if the variables were unrelated.

The empty cell
$$ \lim_{x \to 0} \; x \log(x) \;=\; 0 $$

Symbols: \(x\) here stands for a joint probability that came out as zero. What it tells you: the log of zero is undefined, so a cell with no people looks like a problem. As \(x\) gets close to zero, \(x \log(x)\) goes to zero, so we simply set that term to zero and move on.

The link to entropy
$$ H(X) \;=\; -\sum_{x \in X} P(x) \log P(x) $$

Symbols: \(H(X)\) is the entropy of \(X\). \(P(x)\) is the probability of one value of \(X\). What it tells you: entropy measures the average surprise in one variable. Both formulas are sums of probabilities times logs, and mutual information can be derived from entropy. It says how much the surprise in one variable is related to the surprise in the other.

Worked example from the video

Example

Take the table from the figure above. The joint probabilities are 3/5, 1/5, 0/5 and 1/5. The marginals are 3/5 and 2/5 for popcorn, and 4/5 and 1/5 for Troll 2. Expanding the double sum gives four terms.

$$ I = \tfrac{3}{5}\log\!\frac{3/5}{\tfrac{3}{5}\cdot\tfrac{4}{5}} \;+\; \tfrac{0}{5}\log\!\frac{0/5}{\tfrac{3}{5}\cdot\tfrac{1}{5}} \;+\; \tfrac{1}{5}\log\!\frac{1/5}{\tfrac{2}{5}\cdot\tfrac{4}{5}} \;+\; \tfrac{1}{5}\log\!\frac{1/5}{\tfrac{2}{5}\cdot\tfrac{1}{5}} $$

Term by term, with the natural log: the first term is \(0.6 \times \log(1.25) = +0.134\). The second term has a zero joint probability, so it is 0. The third term is \(0.2 \times \log(0.625) = -0.094\). The fourth term is \(0.2 \times \log(2.5) = +0.183\).

$$ I = 0.134 + 0 - 0.094 + 0.183 = 0.22 $$

So the mutual information between likes popcorn and loves Troll 2 is 0.22. Height also scores 0.22, so either feature is a fine choice. Note that one term is negative, but the total is not.

Common mistakes and subtle points

Watch out

Mutual information is not correlation. Two columns that change in exactly opposite ways score the same as two columns that change in exactly the same way. The value never tells you the direction of the relationship, and it is never negative.

Watch out

Zero cells are normal, not an error. If a joint probability is zero, that term is zero, even though the log of zero is undefined. Handle this case in your own code, or you will get a NaN instead of a number.

Watch out

The log base changes the size of the number. The natural log is the default in most machine learning libraries, but base 2 is also common. Only compare values that were computed with the same base.

Watch out

For continuous data, the bins are your categories. The histogram is a choice you make before the maths starts, so a different set of bins can give a different value. Use the same binning for every feature you plan to compare.

If they ask you in an interview

What is mutual information, and when would you use it instead of R squared?
Mutual information is a single number that says how much one variable tells you about another. I reach for it during feature selection when the data types are mixed. R squared needs continuous data on both sides, so it cannot handle a yes/no target like "loves this movie". Mutual information works with discrete data, continuous data, or a mix of the two.
What does a mutual information of zero mean?
It means the two variables are independent, so one tells you nothing about the other. The clearest case is a column that never changes. Something that never varies cannot explain something that does, so the value collapses to zero. In feature selection that is a strong signal to drop the feature.
How do you compute it when a variable is continuous, like height?
I turn it into a discrete variable first. I build a histogram and treat each bin as a category, then count joint and marginal probabilities exactly as I would for a yes/no feature. With three bins and a yes/no target, the sum expands to six terms. The bin choice matters, so I keep it consistent across the features I compare.
Is mutual information the same as correlation?
No. Correlation is signed and mostly captures linear links. Mutual information is always zero or positive and captures any kind of dependence. If I flip one column so it moves in the opposite direction, correlation flips sign but mutual information does not change at all.
How does mutual information relate to entropy?
Mutual information can be derived from entropy, and the two formulas look alike. Entropy measures the average surprise in one variable. Mutual information measures how much the surprise in one variable relates to the surprise in the other. If one variable has no surprise, there is nothing to relate, so the value is zero.

Recap in 30 seconds

  • Mutual information is one number that scores how closely two variables are related.
  • It works with discrete data, continuous data, or a mix, which is where R squared fails.
  • You build a small table of joint probabilities, with the marginal probabilities in the margins.
  • The formula sums, over every combination, the joint probability times the log of the joint probability divided by the product of the marginals.
  • Any term with a zero joint probability contributes zero, so empty cells are safe.
  • A value of zero means one variable never changes or simply carries no information about the other.
  • Same-way and opposite-way relationships give the same value, because the measure has no direction.
  • For a continuous feature, bin it into a histogram first, then run the same calculation.
