Backpropagation Details Pt. 2: Going bonkers with The Chain Rule

▶ Watch on YouTube Also in: Neural Networks / Deep Learning (video 7)

This video finishes backpropagation for the small neural network from Part 1. It uses the chain rule to get the derivatives for the hidden-layer weights and biases. Then gradient descent trains every parameter at once.

In one breath

Part 1 already gave the derivatives for \(b_3\), \(w_3\) and \(w_4\), and they do not change. Now we need the derivatives of the sum of the squared residuals (SSR) with respect to \(w_1\), \(b_1\), \(w_2\) and \(b_2\). The SSR is linked to \(w_1\) through a chain: predicted values, then the activation output \(y_{1,i}\), then the activation input \(x_{1,i}\). The chain rule multiplies one derivative for each link. With all derivatives in hand, gradient descent updates all the parameters together until the green squiggle fits the data.

The main idea

Think about how \(w_1\) affects the final error. The network multiplies each input by \(w_1\) and adds \(b_1\). That gives \(x_{1,i}\), the x-axis coordinate for the activation function in the top node. The softplus activation function turns \(x_{1,i}\) into a y-axis value, \(y_{1,i}\).

Next, \(y_{1,i}\) times \(w_3\) gives the blue curve. The blue curve, the orange curve and the bias \(b_3\) add up to the green squiggle, which gives the predicted values. The predicted values give the residuals, and the residuals give the SSR.

So the SSR depends on \(w_1\) through three in-between values: \(x_{1,i}\), \(y_{1,i}\) and the predicted values. That makes four links in a row. The chain rule says: to get the derivative across the whole chain, multiply the derivative of each link. Josh spreads the equations out so you can see each link clearly. Then he solves each small derivative one at a time.

Step by step

  1. Keep the derivatives for \(b_3\), \(w_3\) and \(w_4\) from Part 1. They do not change.
  2. For \(w_1\), trace the links from the SSR back to \(w_1\): predicted values, then \(y_{1,i}\), then \(x_{1,i}\). The chain rule multiplies four derivatives, one per link.
  3. Link 1: the SSR with respect to the predicted values is the sum of \(-2\) times (observed minus predicted). This is the same result as in Part 1, because the SSR formula has not changed.
  4. Link 2: the predicted values with respect to \(y_1\) give \(w_3\). The orange curve and \(b_3\) do not contain \(y_1\), so their derivatives are 0.
  5. Link 3: the softplus output \(y_1\) with respect to \(x_1\) gives \(e^x/(1+e^x)\). It needs the chain rule again, because softplus wraps a log around \(1+e^x\).
  6. Link 4: \(x_1\) with respect to \(w_1\) gives the input value. This is because \(x_1\) is the input times \(w_1\), plus \(b_1\).
  7. Multiply the four parts together. Josh calls the result a "big fancy equation" (BFE).
  8. For \(b_1\), the same links apply, so the first three parts stay the same. Only the last part changes: \(x_1\) with respect to \(b_1\) is 1.
  9. For \(w_2\) and \(b_2\), use the bottom node instead. Swap in \(w_4\), \(x_{2,i}\) and \(y_{2,i}\), and the steps are the same.
  10. Initialize the weights with random numbers from a standard normal distribution, and set the biases to 0.
  11. Plug the current values into every derivative. Use each derivative to get a step size and a new value. Update all parameters and repeat until the predictions stop improving very much, or some other rule says stop.

Formulas

The network, top node
$$ x_{1,i} = \text{input}_i \, w_1 + b_1, \qquad y_{1,i} = \log\!\left(1 + e^{x_{1,i}}\right) $$ $$ \text{Predicted}_i = w_3\, y_{1,i} + w_4\, y_{2,i} + b_3, \qquad \text{SSR} = \sum_{i} (\text{Observed}_i - \text{Predicted}_i)^2 $$

Symbols: \(\text{input}_i\) is the i-th input value (a dosage). \(w_1, w_2, w_3, w_4\) are weights and \(b_1, b_2, b_3\) are biases. \(x_{1,i}\) is the x-axis coordinate that goes into the top node's activation function. \(y_{1,i}\) is the y-axis value that comes out of it, using softplus. \(y_{2,i}\) is the same thing for the bottom node. What it tells you: these are the links that connect \(w_1\) to the SSR, one after another.

Chain rule for w1
$$ \frac{d\,\text{SSR}}{d\,w_1} = \frac{d\,\text{SSR}}{d\,\text{Predicted}} \times \frac{d\,\text{Predicted}}{d\,y_1} \times \frac{d\,y_1}{d\,x_1} \times \frac{d\,x_1}{d\,w_1} $$

Symbols: each fraction is the derivative of one link in the chain. What it tells you: a change in \(w_1\) passes through \(x_1\), then \(y_1\), then the predicted values, before it reaches the SSR, so we multiply the four effects.

Solving each link
$$ \frac{d\,\text{SSR}}{d\,\text{Predicted}} = \sum_i -2(\text{Observed}_i - \text{Predicted}_i) $$

This is the same first link we used in earlier videos.

$$ \frac{d\,\text{Predicted}}{d\,y_1} = w_3 + 0 + 0 = w_3 $$

Only the \(w_3 y_1\) term contains \(y_1\), so the other two terms drop out.

$$ \frac{d\,y_1}{d\,x_1} = \frac{1}{1+e^{x}} \times (0 + e^{x}) = \frac{e^{x}}{1+e^{x}} $$

Let \(z = 1 + e^x\). The derivative of \(\log z\) is \(1/z\), and the derivative of the inside is \(e^x\), since the 1 has no \(x\).

$$ \frac{d\,x_1}{d\,w_1} = \text{input} + 0 = \text{input} $$

The \(b_1\) term does not contain \(w_1\), so only the input value is left.

The big fancy equations
$$ \frac{d\,\text{SSR}}{d\,w_1} = \sum_i -2(\text{Observed}_i - \text{Predicted}_i)\; w_3\; \frac{e^{x_{1,i}}}{1+e^{x_{1,i}}}\; \text{input}_i $$ $$ \frac{d\,\text{SSR}}{d\,b_1} = \sum_i -2(\text{Observed}_i - \text{Predicted}_i)\; w_3\; \frac{e^{x_{1,i}}}{1+e^{x_{1,i}}}\; \times 1 $$

Symbols: the same as above; the \(x\) in \(e^{x}\) is \(x_{1,i}\) for each input value. What it tells you: the two derivatives differ only in the last factor, because \(d\,x_1/d\,b_1 = 0 + 1 = 1\). For \(w_2\) and \(b_2\), replace \(w_3\) with \(w_4\) and \(x_{1,i}\) with \(x_{2,i}\).

Worked example from the video

Example

Josh first sets the starting values. The weights get random numbers from a standard normal distribution. The biases \(b_1\), \(b_2\) and \(b_3\) start at 0.

Then he evaluates \(d\,\text{SSR}/d\,w_1\). He expands the sum into one term per data point. He plugs in the observed values and the predicted values from the green squiggle. The predicted values come from running the dosages through the network with the current parameters.

Next he plugs in the current \(w_3\), the values \(x_{1,i}\) from the top node, and the input values. Doing the math gives \(d\,\text{SSR}/d\,w_1 = 0.76\).

He solves all the other derivatives the same way, turns each into a step size and a new value, and updates the network. At the start, the green squiggle fits so badly that it goes off the screen. After 450 steps of gradient descent, it fits the data.

Common mistakes and subtle points

Watch out The \(x\) in \(e^x/(1+e^x)\) is not the dosage. It is \(x_{1,i}\), the x-axis coordinate for the activation function, which you get for each input value.
Watch out The derivative of the predicted values with respect to \(y_1\) is just \(w_3\). The orange curve term and \(b_3\) do not contain \(y_1\), so they add 0.
Watch out The \(w_1\) and \(b_1\) derivatives share the first three factors. Only the last factor differs: the input value for \(w_1\) and 1 for \(b_1\).
Watch out Josh flags that a standard normal distribution is only one of many ways to initialize weights. Starting biases at 0 is common, not required.

If they ask you in an interview

How do you get the derivative of the loss with respect to a first-layer weight?
I trace how the weight reaches the loss. In this network, \(w_1\) sets the activation input, which sets the activation output, which sets the prediction, which sets the SSR. The chain rule multiplies the derivative of each link. So I get the SSR term, times \(w_3\), times the softplus derivative, times the input.
What is the derivative of the softplus function?
Softplus is \(\log(1+e^x)\). Using the chain rule, the outside gives \(1/(1+e^x)\) and the inside gives \(e^x\). So the derivative is \(e^x/(1+e^x)\).
How is the gradient for a bias different from the gradient for its weight?
The chain is the same, so the first factors match. Only the last link changes. The derivative of the activation input with respect to the weight is the input value, but with respect to the bias it is just 1.
Why can you reuse the output-layer derivatives when you add hidden-layer parameters?
The derivatives for \(w_3\), \(w_4\) and \(b_3\) do not change when we also optimize the earlier parameters. We just add the new derivatives next to them. Then gradient descent updates all of the parameters together.
How did the video initialize and train the network?
The weights came from a standard normal distribution, and the biases started at 0. At each step, we plug the current values into every derivative, get a step size and a new value for each parameter, and update. In the video, the fit was good after 450 steps.

Recap in 30 seconds

  • The derivatives for \(b_3\), \(w_3\) and \(w_4\) from Part 1 stay the same.
  • The SSR is linked to \(w_1\) through the predicted values, \(y_{1,i}\) and \(x_{1,i}\).
  • The chain rule multiplies four parts: the SSR term, \(w_3\), \(e^x/(1+e^x)\), and the input.
  • For \(b_1\), the last part becomes 1 and everything else stays the same.
  • For \(w_2\) and \(b_2\), use the bottom node, with \(w_4\) and \(x_{2,i}\).
  • Weights start from a standard normal distribution and biases start at 0.
  • Gradient descent updates all parameters together, and in the video it fits the data after 450 steps.
