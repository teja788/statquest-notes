Logistic Regression

▶ Watch on YouTube

Logistic regression predicts whether something is true or false. This video shows how it differs from linear regression, and why it is fit in a completely different way.

In one breath

Linear regression fits a straight line and predicts a continuous value, like the size of a mouse. Logistic regression fits an S-shaped curve that runs from 0 to 1. Its output is the probability that a mouse is obese. That probability is usually turned into a label: above 50% you call the mouse obese. It accepts continuous predictors like weight and discrete ones like genotype. It has no residuals, so it cannot use least squares or report an ordinary R-squared. It is fit with maximum likelihood instead.

The main idea

Josh starts by reviewing linear regression. We had weight and size for some mice, and we fit a line through the points. That line let us do three things. We could calculate R-squared to see whether weight and size are correlated, calculate a p-value to see whether that R-squared is statistically significant, and use the line to predict the size of a new mouse from its weight.

Using data to predict something is machine learning. So plain linear regression is already a form of machine learning. Multiple regression is a slightly fancier version, where size is predicted from weight and blood volume together. It gives the same things: an R-squared, a p-value, and predictions. It can also use discrete measurements such as genotype, which simply means different types of mice. And you can compare a simple model to a complicated one, to see whether the extra measurement was worth taking.

Logistic regression is similar, with one change. It predicts whether something is true or false, not a continuous value. Here some mice are obese and some are not. Instead of a straight line, it fits an S-shaped logistic function. That curve goes from 0 to 1, so its height at any weight is the probability that a mouse of that weight is obese.

Step by step

  1. Collect the data. For each mouse you record the weight and whether the mouse is obese, true or false.
  2. Fit the S-shaped logistic curve to those points, so that its height gives the probability of obesity at each weight.
  3. Read a probability for any new mouse by finding its weight on the curve.
  4. Classify the mouse. If the probability of obesity is greater than 50%, call it obese; otherwise call it not obese.
  5. Add more predictors if you want. Obesity can be predicted by weight, or by weight and genotype, or by weight, genotype and age, or even by weight, genotype, age and astrological sign.
  6. Test each variable separately. Check whether its effect on the prediction is significantly different from zero, using Wald's test. If the effect is not different from zero, that variable is not helping.
  7. Drop the useless variables. In the video the astrological sign does not help, so leaving it out saves time and space in the study.

The last big difference is how the curve is fit. Linear regression uses least squares: it finds the line that makes the sum of the squared residuals as small as possible. A residual is the vertical gap between a data point and the line. Those same residuals give R-squared and let you compare a simple model with a complicated one.

Logistic regression has no matching idea of a residual. So it cannot use least squares, and it cannot calculate R-squared. It uses maximum likelihood instead. You take a candidate curve, and for each mouse you read off the likelihood of seeing that mouse given the curve. Then you multiply all those likelihoods together to get the likelihood of the whole dataset. Then you shift the curve and do it again, and again. The curve with the largest likelihood wins.

Formulas

The logistic curve
$$ p(\text{obese} \mid x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x)}} $$

Symbols: \(x\) is the weight of the mouse. \(\beta_0\) is the intercept and \(\beta_1\) is the slope; together they set where the S sits and how steep it is. \(e\) is the number 2.718…, the base of natural logarithms. \(p\) is the output. What it tells you: this is the standard form of the S-shaped curve Josh draws. Whatever numbers go in, the output always stays between 0 and 1, so it can be read as a probability.

Classification rule
$$ \hat{y} = \begin{cases} \text{obese} & \text{if } p > 0.5 \\ \text{not obese} & \text{otherwise} \end{cases} $$

Symbols: \(p\) is the probability from the curve. \(\hat{y}\) is the label you assign. What it tells you: logistic regression itself only gives a probability. The 0.5 cut is the extra step that turns it into a classification.

Least squares, for contrast
$$ \min \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $$

Symbols: \(y_i\) is the observed size of mouse \(i\). \(\hat{y}_i\) is the size the line predicts. Their difference is the residual. \(n\) is the number of mice. What it tells you: this is what linear regression minimises. Logistic regression has no such residual, so it cannot use this rule and cannot report R-squared.

Likelihood of the data
$$ L = \prod_{i=1}^{n} p_i^{\,y_i}\,(1-p_i)^{\,1-y_i} $$

Symbols: \(p_i\) is the probability the curve gives for mouse \(i\). \(y_i\) is 1 if that mouse is obese and 0 if it is not. The \(\prod\) sign means multiply all the terms together. What it tells you: for an obese mouse the term is \(p_i\), and for a non-obese mouse it is \(1-p_i\). Multiply them for every mouse and you get the likelihood of the whole dataset. Maximum likelihood picks the curve that makes \(L\) as large as possible.

Worked example from the video

Example

Josh keeps the mouse study running through the whole video. Some mice are obese and some are not, and we want to predict obesity from weight. The fitted curve is the S-shape above.

Take three new mice. A very heavy mouse lands high on the curve, so \(p > 0.5\) and it is classified as obese. An intermediate mouse lands in the middle, where the probability is exactly 50%. A light mouse lands low on the curve, so its probability is small and it is classified as not obese.

Then Josh builds bigger models. Obesity by weight. Obesity by weight and genotype. Obesity by weight, genotype and age. Obesity by weight, genotype, age and astrological sign. Weight and age are continuous; genotype and astrological sign are discrete. Logistic regression handles both kinds.

Each variable is then tested on its own, to see whether its effect differs significantly from zero. Weight, genotype and age pass. The astrological sign does not, so it is not helping the prediction and can be left out of the study.

Common mistakes and subtle points

Watch out Logistic regression has no residuals, so it has no least squares fit and no ordinary R-squared. Do not report one out of habit because linear regression gave you one.
Watch out You cannot easily compare a complicated logistic model with a simple one the way you compare two linear models. Instead test each variable's effect against zero, using Wald's test.
Watch out The direct output is a probability, not a label. The 50% threshold is a separate decision you make afterwards, and it can be moved.
Watch out Fitting is a search, not a one-shot formula. The software shifts the curve many times and keeps the one with the highest likelihood.

If they ask you in an interview

How does logistic regression differ from linear regression?
Linear regression predicts a continuous value and fits a straight line. Logistic regression predicts whether something is true or false, and fits an S-shaped curve that runs from 0 to 1. Because the curve stays inside that range, its height is a probability. Both accept continuous and discrete predictors, so the modelling feels familiar.
Why can't logistic regression use least squares?
Least squares needs residuals, the vertical gaps between the points and the line. In logistic regression the outcome is only true or false, so there is no matching residual to square and add up. That is also why there is no ordinary R-squared. The fit uses maximum likelihood instead.
What does maximum likelihood actually do here?
You start with a candidate curve. For each observation you read the likelihood of seeing that observation given the curve, then multiply all of them to get the likelihood of the whole dataset. You shift the curve and recompute, over and over. The curve with the largest likelihood is the fitted model.
Is logistic regression classification or regression?
Strictly it estimates a probability, so it is a regression on the probability scale. In practice it is used for classification. You apply a threshold, usually 50%, and label anything above it as the positive class. That threshold is your choice, not part of the fit.
How do you decide whether a predictor is worth keeping?
You test whether that variable's effect on the prediction is significantly different from zero, typically with Wald's test. If it is not, the variable is not helping and you can drop it. In the video the astrological sign fails this test, so removing it saves time and effort in the study.

Recap in 30 seconds

  • Logistic regression predicts whether something is true or false, not a continuous value.
  • It fits an S-shaped logistic curve that runs from 0 to 1, so its height is a probability.
  • You classify by putting a threshold on that probability, usually 50%.
  • It works with continuous predictors like weight and age, and discrete ones like genotype.
  • It has no residuals, so no least squares and no ordinary R-squared.
  • It is fit by maximum likelihood: try curves, multiply the likelihoods, keep the best.
  • You cannot easily compare complicated and simple models, so you test each variable's effect against zero with Wald's test.
  • Useless variables, like the astrological sign, can then be dropped from the study.
