MDS and PCoA in R

▶ Watch on YouTube

This video runs multi-dimensional scaling (MDS) in R with the cmdscale function. It also shows how the distance metric changes the plot.

In one breath

Classical (metric) MDS and PCoA are the same method. You start from a distance matrix, not from the raw data. Josh runs MDS on a Euclidean distance matrix and gets the exact same plot as PCA. He then builds a distance matrix by hand, and the plot changes. The metric you pick is the real decision in MDS.

The main idea

PCA starts with the measurements themselves. MDS starts one step later, with a table of distances between samples. So MDS lets you define "far apart" any way you like. Use the Euclidean metric and MDS gives you PCA back, exactly. Use another metric and you get a different picture of the same data.

Step by step

Josh uses the same fake data as the PCA in R video: 100 genes and 10 samples, five wild type and five knockout.

The same data in Python.

# Python equivalent
import numpy as np, pandas as pd
rng = np.random.default_rng(0)
cols = [f"wt{i}" for i in range(1, 6)] + [f"ko{i}" for i in range(1, 6)]
rows = [f"gene{i}" for i in range(1, 101)]
data = pd.DataFrame(
    [np.concatenate([rng.poisson(rng.integers(10, 1000), 5),
                     rng.poisson(rng.integers(10, 1000), 5)]) for _ in rows],
    index=rows, columns=cols)
  1. Make the distance matrix. Transpose the data so samples become rows, centre and scale each gene, then call dist.
  2. Run cmdscale on that matrix. Ask for the eigenvalues with eig=TRUE and the doubly centred matrix with x.ret=TRUE.
  3. Turn the eigenvalues into the percentage of variation each axis accounts for.
  4. Put the coordinates into a data frame and draw the plot with ggplot2.

Steps one to three are three short lines of R.

## step 1: distance matrix
distance.matrix <- dist(scale(t(data.matrix), center=TRUE, scale=TRUE),
                        method="euclidean")

## step 2: classical multi-dimensional scaling
mds.stuff <- cmdscale(distance.matrix, eig=TRUE, x.ret=TRUE)

## step 3: variation per axis
mds.var.per <- round(mds.stuff$eig / sum(mds.stuff$eig) * 100, 1)

Here is the same thing in Python. The eigen block is what cmdscale does internally.

# Python equivalent: classical MDS by hand
from scipy.spatial.distance import pdist, squareform
from sklearn.preprocessing import scale

X = scale(data.T.values)                       # samples in rows, genes centred+scaled
D = squareform(pdist(X, metric="euclidean"))   # 10 x 10 distances

n = D.shape[0]
J = np.eye(n) - np.ones((n, n)) / n
B = -0.5 * J @ (D ** 2) @ J                    # doubly centred matrix
vals, vecs = np.linalg.eigh(B)
order = np.argsort(vals)[::-1]
vals, vecs = vals[order], vecs[:, order]

coords = vecs[:, :2] * np.sqrt(np.clip(vals[:2], 0, None))
var_per = np.round(100 * vals / vals.sum(), 1)

The result matches the PCA plot exactly. Wild type sits on the left, knockout on the right, MDS1 at 91% and MDS2 at 2.7%.

Then Josh changes the metric to the average absolute log fold change. That metric is not built into dist, so he fills a matrix by hand. He only computes the lower triangle, because the full matrix is symmetric.

log2.data.matrix <- log2(data.matrix)
log2.distance.matrix <- matrix(0, nrow=10, ncol=10,
  dimnames=list(colnames(data.matrix), colnames(data.matrix)))
for (i in 1:10) {
  for (j in 1:i) {
    log2.distance.matrix[i,j] <- mean(abs(log2.data.matrix[,i] - log2.data.matrix[,j]))
  }
}
mds.stuff <- cmdscale(as.dist(log2.distance.matrix), eig=TRUE, x.ret=TRUE)
# Python equivalent
L = np.log2(data.values)
D2 = squareform(pdist(L.T, metric=lambda a, b: np.mean(np.abs(a - b))))
# then reuse the double-centring + eigen block above on D2

Everything after that is unchanged. The new plot still separates wild type from knockout, but MDS1 now accounts for 99.2% of the variation instead of 91%.

Formulas

What cmdscale does
$$ B = -\tfrac{1}{2} J D^{(2)} J, \qquad J = I - \tfrac{1}{n}\mathbf{1}\mathbf{1}^{\top} $$
$$ X_k = V_k \Lambda_k^{1/2} $$

Symbols: \(D^{(2)}\) holds the squared distances. \(n\) is the number of samples. \(J\) subtracts row and column means. \(B\) is the doubly centred matrix that x.ret=TRUE returns. \(V_k\) and \(\Lambda_k\) are the top \(k\) eigenvectors and eigenvalues of \(B\). What it tells you: one eigen decomposition turns distances into plot coordinates.

Variation per axis
$$ \text{var}_i = 100 \times \frac{\lambda_i}{\sum_j \lambda_j} $$

Symbols: \(\lambda_i\) is the eigenvalue for axis \(i\). What it tells you: the share of variation that axis \(i\) accounts for. It is the number on the axis label: 91% and 2.7% here.

The hand-made metric
$$ d(i,j) = \frac{1}{p}\sum_{g=1}^{p} \bigl| \log_2 x_{gi} - \log_2 x_{gj} \bigr| $$

Symbols: \(x_{gi}\) is the measurement for gene \(g\) in sample \(i\); \(p\) is the number of genes, 100 here. What it tells you: the average absolute log fold change between two samples. This is the metric edgeR uses in its plotMDS function.

Worked example from the video

Example

The data are 100 genes by 10 samples: wt1 to wt5 and ko1 to ko5. PCA puts wild type on the left and knockout on the right. PC1 accounts for 91% of the variation and PC2 for 2.7%.

MDS on the Euclidean distance matrix gives MDS1 at 91% and MDS2 at 2.7%. The two plots are not just similar, they are the same plot.

The average absolute log fold change gives a similar but different plot. MDS1 now accounts for 99.2% of the variation instead of 91%.

Common mistakes and subtle points

Watch out The dist function measures distances between rows, and your samples are columns. Forget t() and you get a 100 by 100 matrix of gene distances, not a 10 by 10 matrix of sample distances.
Watch out If you build a distance matrix by hand, cmdscale will not know it is one. Wrap it in as.dist() first. A true distance object only stores the lower triangle, which is why Josh only fills that triangle in the loop.
Watch out MDS with the Euclidean metric is the same as PCA, so running both adds nothing. R's dist offers six metrics if you want a different one.

If they ask you in an interview

What is the difference between MDS and PCoA?
There is none. Classical or metric MDS and principal coordinate analysis are two names for the same method. Different fields adopted different names, and R implements it as cmdscale.
When is MDS identical to PCA?
When the distance matrix uses the Euclidean metric on centred and scaled data. In the video the two plots match, and the axes carry the same percentages, 91% and 2.7%.
So why would you use MDS at all?
Because MDS accepts any distance you can define. Josh uses the average absolute log fold change, which is what edgeR does. That helps when Euclidean distance does not match what "similar" means for your data.

Recap in 30 seconds

  • MDS, classical MDS, metric MDS and PCoA all name the same method.
  • In R the four steps are dist, cmdscale, eigenvalues to percentages, then plot.
  • With Euclidean distance the MDS plot is exactly the PCA plot, 91% and 2.7% here.
  • Using the average absolute log fold change moved MDS1 from 91% to 99.2%.
  • A hand-built matrix needs as.dist before cmdscale will accept it.
