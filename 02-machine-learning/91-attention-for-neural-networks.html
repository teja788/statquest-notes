Attention for Neural Networks

▶ Watch on YouTube Also in: Neural Networks / Deep Learning (video 19)

This video adds attention to an encoder-decoder model. Each decoding step can then look straight at every input word. It is a key step toward Transformers, the basis of models like ChatGPT.

In one breath

A basic encoder-decoder squeezes the whole input into one context vector. So early words in long sentences can be forgotten. Attention adds a new path from each input word to every decoder step. At each step, the model scores how similar each encoder output is to the decoder output. A SoftMax turns the scores into percentages, which blend the encoder outputs into attention values. These values and the decoder output feed a fully connected layer that picks the next word.

The main idea

A basic encoder-decoder uses LSTMs, or long short-term memory units, a type of recurrent network. Unrolling them in the encoder compresses the whole input into one context vector. A context vector is just a single list of numbers. This works for a short phrase like "Let's go". For a long sentence, words that come early can be lost. Josh's example is "Don't eat the delicious looking and smelling pizza". If the model forgets "Don't", the meaning flips completely.

LSTMs already give long-term and short-term memories separate paths. But with a lot of data, both paths carry a lot of information. So an early word can still get lost. Attention adds new paths from the encoder to the decoder, one per input value. Each decoder step can then directly access the input values.

The figure shows one decoding step from the video. The decoder has just been given the EOS token, and it must produce the first Spanish word.

Step by step

  1. Build the encoder as before: an embedding layer and two LSTM cells per step, with cell and hidden states set to zero. Feed in "Let's", unroll, then feed in "go".
  2. The final encoder states form the context vector, which initializes a separate set of LSTM cells in the decoder. Without attention, all of the input is jammed into this one vector.
  3. Start decoding by feeding the EOS (end of sentence) token into the decoder's embedding layer. Some manuscripts start with SOS (start of sentence) instead.
  4. Score how similar the decoder's LSTM outputs are to the encoder's outputs at each input step. These outputs are the short-term memories, also called hidden states.
  5. Run the scores through SoftMax. This gives the percentage of each encoded input word to use for this step.
  6. Scale each encoder output by its percentage and add them up. The sums are the attention values for this decoding step.
  7. Feed the attention values and the decoder's EOS outputs into a fully connected layer, where every input connects to every output. Run its output through SoftMax to pick the first word, "Vamos".
  8. Since the output is not EOS, unroll the decoder and feed in "Vamos". Repeat the same math. The second output is EOS, so decoding stops.

Formulas

Cosine similarity
$$ \text{cos sim}(\mathbf{a},\mathbf{b}) = \frac{\sum_{i=1}^{n} a_i b_i}{\sqrt{\sum_{i=1}^{n} a_i^2}\,\sqrt{\sum_{i=1}^{n} b_i^2}} $$

Symbols: \(\mathbf{a}\) is the list of LSTM output values from one encoder step. \(\mathbf{b}\) is the list of LSTM output values from the current decoder step. \(a_i\) and \(b_i\) are their \(i\)-th values. \(n\) is the number of LSTM cells, which is 2 in the video. What it tells you: the numerator measures how similar the two lists are, and the denominator scales that value to lie between −1 and 1.

Dot product (the usual attention score)
$$ \text{score}(\mathbf{a},\mathbf{b}) = \sum_{i=1}^{n} a_i b_i $$

Symbols: the same as above. It is just the numerator of the cosine similarity. What it tells you: large positive numbers mean more similar, and large negative numbers mean more completely backwards. Multiply each pair of output values and add them up.

SoftMax
$$ w_j = \frac{e^{s_j}}{\sum_{k=1}^{m} e^{s_k}} $$

Symbols: \(s_j\) is the similarity score for input word \(j\). \(m\) is the number of input words. \(e\) is Euler's number, about 2.718. \(w_j\) is the weight for input word \(j\). What it tells you: every weight is between 0 and 1, and the weights add up to 1, so each one is a percentage of that encoded word to use.

Attention values
$$ \text{attention} = \sum_{j=1}^{m} w_j\,\mathbf{h}_j $$

Symbols: \(\mathbf{h}_j\) is the list of encoder LSTM output values for input word \(j\). \(w_j\) is its SoftMax weight. What it tells you: the attention values are a blend of all the input encodings, with more similar words having more influence.

Worked example from the video

Example

We translate "Let's go" into Spanish. Each step has two LSTM cells, so each output is two numbers. The encoder outputs for "Let's" are (−0.76, 0.75). The decoder outputs for EOS are (0.91, 0.38).

Cosine similarity. Plugging these into the full formula gives −0.39.

$$ \frac{(-0.76)(0.91) + (0.75)(0.38)}{\sqrt{(-0.76)^2+0.75^2}\,\sqrt{0.91^2+0.38^2}} \approx -0.39 $$

Dot product. Keep only the numerator.

$$ (-0.76)(0.91) + (0.75)(0.38) = -0.692 + 0.285 \approx -0.41 $$

The same dot product between "go" and EOS gives 0.01. Since 0.01 is higher than −0.41, "go" should have more influence on the first output word.

SoftMax. Running −0.41 and 0.01 through SoftMax gives about 0.4 for "Let's" and 0.6 for "go".

$$ \frac{e^{-0.41}}{e^{-0.41}+e^{0.01}} \approx 0.4, \qquad \frac{e^{0.01}}{e^{-0.41}+e^{0.01}} \approx 0.6 $$

Attention values. Scale the values for "Let's" by 0.4 and the values for "go" by 0.6, then add them. These sums are the attention values for EOS. They go into a fully connected layer along with the EOS decoder outputs. A SoftMax then selects "Vamos". Feeding "Vamos" back in produces EOS, so the translation is "Vamos".

Common mistakes and subtle points

Watch out There are conventions but no rules for adding attention. Each manuscript does it a little differently, and the video shows just one example. The constant part is the main idea: an extra path from each input value to every decoder step.
Watch out The dot product is not scaled to −1 to 1. The cosine denominator only removes magnitude, which helps when comparing scores built from different numbers of LSTM cells. Here the number of cells never changes, and the dot product works well in practice.
Watch out SoftMax does not pick one input word. It blends them. Even though "go" scores higher, 40% of "Let's" is still used.
Watch out The attention values are not the only input to the fully connected layer. The decoder's own outputs for the current token go in as well.

If they ask you in an interview

What problem does attention solve in an encoder-decoder model?
A basic encoder-decoder compresses the whole input sentence into one context vector. For long sentences, early words can be forgotten, even with LSTMs. Attention adds a direct path from each input word to every decoder step, so the decoder can look back at any input it needs.
How are the attention weights computed?
At each decoder step, I compute a similarity score between the decoder's LSTM outputs and each encoder step's LSTM outputs, usually with a dot product. I run those scores through SoftMax, which gives weights between 0 and 1 that add up to 1. Each weight is the share of that encoded word to use.
Why use the dot product instead of cosine similarity?
The dot product is just the numerator of the cosine similarity, so it is easier to calculate. The denominator only scales the score to lie between −1 and 1. That matters when comparing scores built from different numbers of cells, but here the count is fixed, and the dot product works well in practice.
What goes into the layer that predicts the next word?
Two things go in: the attention values, which are the weighted sum of the encoder outputs, and the decoder's own outputs for the current token. A fully connected layer combines them, and a SoftMax picks the output word. In the example this gives "Vamos" first, then EOS.
Do we still need LSTMs once we have attention?
Josh says it turns out we don't. That observation leads to Transformers, which are covered in later videos.

Recap in 30 seconds

  • A basic encoder-decoder packs the whole input into one context vector, so early words in long sentences can be lost.
  • Attention adds a path from each input word to every step of the decoder.
  • At each decoder step, we score each encoder output against the decoder output, usually with a dot product.
  • In the example, "Let's" scores −0.41 and "go" scores 0.01 against EOS.
  • SoftMax turns the scores into weights of 0.4 and 0.6, and the weighted sum of encoder outputs gives the attention values.
  • The attention values and the decoder outputs go into a fully connected layer and a SoftMax, which outputs "Vamos".
  • Attention makes the LSTMs unnecessary, which is the starting point for Transformers.
