Neural Networks Part 5: ArgMax and SoftMax

▶ Watch on YouTube Also in: Neural Networks / Deep Learning (video 10)

When a neural network has several outputs, its raw output values can be any size, so they are hard to read. This video shows two layers that fix this, ArgMax and SoftMax, and explains why we classify with one and train with the other.

In one breath

Raw output values can be above 1 or below 0. ArgMax sets the largest value to 1 and all others to 0, which is very easy to read. But its derivative is zero or undefined, so we cannot use it for backpropagation. SoftMax turns the raw values into numbers between 0 and 1 that keep the same order and add up to 1, and it has a useful derivative. So networks often train with SoftMax and classify new data with ArgMax.

The main idea

Josh reuses the iris network from the previous video. It takes petal width and sepal width and gives one raw output value for each species: Setosa, Versicolor and Virginica. With petal width 0 and sepal width 1, the raw outputs are 1.43, -0.4 and 0.23.

These numbers are not between 0 and 1. Setosa is above 1, and Versicolor is below 0. This wide range makes the output harder to interpret than it needs to be. So, when there is more than one output, the raw values usually go through an ArgMax layer or a SoftMax layer before the final decision.

The figure shows the same three raw values going both ways. ArgMax keeps only the winner. SoftMax keeps information about every class.

Step by step

  1. Run the input through the network and get one raw output value per class. Here they are 1.43, -0.4 and 0.23.
  2. ArgMax sets the largest value to 1 and every other value to 0. Setosa has the largest value, so the prediction is Setosa. The prediction is simply the output that holds the 1.
  3. ArgMax has one problem: we cannot use it to optimize the weights and biases. Its outputs are the constants 0 and 1, so its slope is zero, as the figure below shows.
  4. A zero derivative goes into the chain rule and makes the whole derivative zero. With a zero gradient, gradient descent takes no step toward better parameter values. So ArgMax cannot be used for backpropagation.
  5. SoftMax fixes this. For each class, raise \(e\) to that class's raw value and divide by the sum of \(e\) raised to every raw value. Only the numerator changes from class to class.
  6. Look at the results: they keep the ranking of the raw values, they are all between 0 and 1, and they add up to 1. If the classes are mutually exclusive, we can read them as predicted "probabilities".
  7. SoftMax has a derivative that is not always zero, so gradient descent can use it. Networks with several outputs often train with SoftMax and classify new observations with ArgMax.
  8. With SoftMax outputs, we often measure fit with cross entropy instead of the sum of squared residuals. The next video in the series covers cross entropy.

Formulas

ArgMax
$$ \text{ArgMax}_i = \begin{cases} 1 & \text{if } \text{raw}_i \text{ is the largest raw value} \\ 0 & \text{otherwise} \end{cases} $$

Symbols: \(i\) is one output class; \(\text{raw}_i\) is the raw output value for that class. What it tells you: only the winning class gets a 1, so the output is very easy to read but is made of constants.

SoftMax
$$ p_i = \frac{e^{\text{raw}_i}}{\sum_{j} e^{\text{raw}_j}} $$

Symbols: \(p_i\) is the SoftMax output (predicted probability) for class \(i\); \(e\) is Euler's number, about 2.718; \(\text{raw}_i\) is the raw output for class \(i\); the sum in the denominator runs over every class \(j\). What it tells you: each class gets its share of the total, so the outputs are between 0 and 1, keep the original order, and add up to 1.

SoftMax derivative, same class
$$ \frac{\partial p_{\text{setosa}}}{\partial\, \text{raw}_{\text{setosa}}} = p_{\text{setosa}}\,(1 - p_{\text{setosa}}) $$

Symbols: \(\partial\) means "the rate of change of"; \(p_{\text{setosa}}\) is the SoftMax output for Setosa; \(\text{raw}_{\text{setosa}}\) is the raw output for Setosa. What it tells you: how much Setosa's predicted probability moves when its own raw value changes.

SoftMax derivative, other class
$$ \frac{\partial p_{\text{setosa}}}{\partial\, \text{raw}_{\text{versicolor}}} = -\,p_{\text{setosa}}\; p_{\text{versicolor}} $$

Symbols: \(p_{\text{versicolor}}\) is the SoftMax output for Versicolor; \(\text{raw}_{\text{versicolor}}\) is its raw output. The same form holds for Virginica. What it tells you: the other classes' raw values also change Setosa's probability, so backpropagation needs these derivatives too.

Worked example from the video

Example

The raw outputs are 1.43 for Setosa, -0.4 for Versicolor and 0.23 for Virginica. ArgMax gives 1 to Setosa and 0 to the other two, so the network predicts Setosa.

For SoftMax, the shared denominator is \(e^{1.43} + e^{-0.4} + e^{0.23} \approx 4.18 + 0.67 + 1.26 = 6.11\). Then:

Josh gets 0.69 for Setosa, 0.10 for Versicolor and 0.21 for Virginica. Dividing each numerator by 6.11 by hand gives about 0.68, 0.11 and 0.21. The small gaps come only from rounding. Either way, the values add up to 1, and Setosa still ranks first.

Now the derivatives for Setosa's probability. With respect to its own raw value: \(0.69 \times (1 - 0.69) \approx 0.21\). With respect to Versicolor: \(-0.69 \times 0.10 \approx -0.07\). With respect to Virginica: \(-0.69 \times 0.21 \approx -0.14\), which Josh shows as -0.15 after rounding. None of these is zero, so gradient descent can use them.

Common mistakes and subtle points

Watch out Do not put much trust in SoftMax "probabilities". They depend on the weights and biases, which depend on random initial values. A different start can give a network that classifies just as well but gives different probabilities.
Watch out SoftMax outputs can be read as probabilities only when the output classes are mutually exclusive. The sum of 1 is what allows this reading.
Watch out ArgMax is fine for making the final call on new data, but not for training. Its derivative is zero or undefined, so the chain rule gives zero and gradient descent does not move.
Watch out When the derivative of Setosa's probability is needed, do not forget the other classes. Their raw values are in the denominator, so each one has its own derivative.

If they ask you in an interview

Why not train a classifier with ArgMax on the output?
ArgMax outputs only the constants 0 and 1, so its slope is zero everywhere, or undefined at the jump. That zero enters the chain rule and makes the whole gradient zero. Gradient descent then cannot update the weights and biases.
What three properties does SoftMax guarantee?
It keeps the ranking of the raw output values. Every output is between 0 and 1, no matter how many classes there are. And the outputs add up to 1, so for mutually exclusive classes we can read them as predicted probabilities.
Can you trust SoftMax outputs as real probabilities?
Only loosely. They depend on the weights and biases, and those depend on the random initial values. Two networks can classify equally well and still give different probabilities for the same input.
What is the derivative of a SoftMax output?
With respect to its own raw value it is \(p_i(1 - p_i)\). With respect to another class's raw value it is \(-p_i p_j\). For example, with Setosa at 0.69 the first gives about 0.21, and with Versicolor at 0.10 the second gives about -0.07.
How do SoftMax and ArgMax work together in practice?
We often use SoftMax during training because it has a useful derivative. Then we use ArgMax to classify new observations because its output is very easy to read. With SoftMax, the loss is often cross entropy rather than the sum of squared residuals.

Recap in 30 seconds

  • Raw output values of a multi-output network can be above 1 or below 0, which makes them hard to read.
  • ArgMax sets the largest value to 1 and all others to 0, so the prediction is the output with the 1.
  • ArgMax has a derivative of zero or undefined, so we cannot use it for backpropagation.
  • SoftMax divides \(e\) raised to each raw value by the sum of \(e\) raised to all raw values.
  • SoftMax outputs keep the ranking, stay between 0 and 1, and add up to 1.
  • Treat SoftMax "probabilities" with care, because they depend on random initial weights and biases.
  • SoftMax has a non-zero derivative, so networks often train with SoftMax and classify with ArgMax.
  • With SoftMax, fit is often measured with cross entropy, which is the topic of the next video.
