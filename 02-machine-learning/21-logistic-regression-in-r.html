Logistic Regression in R

▶ Watch on YouTube

Josh fits a real logistic regression from start to finish. He cleans the UCI heart disease data, fits two models, and reads the output.

In one breath

Most of the work is cleaning. You name the columns, turn question marks into missing values, and cast the categorical columns to factors. Six of the 303 samples have missing values, so 297 remain. A simple model uses sex alone, and its two coefficients are a log odds and a log odds ratio. A full model uses every variable and fits much better, with a pseudo R squared of 0.55.

The main idea

Logistic regression predicts a yes or no outcome. In R you fit it with the glm function. The name stands for generalized linear model. You pass family = "binomial" to ask for logistic regression and not some other kind.

The coefficients that come back are not probabilities. They sit on the log odds scale. The odds are the chance of the event divided by the chance of no event. The log odds are the natural log of the odds. The intercept is the log odds for the baseline group. Every other coefficient is a log odds ratio.

The figure follows Josh's simple model from the two printed numbers to a probability.

Step by step

  1. Read the UCI heart disease data and name the columns yourself.
  2. Cast sex, cp and the other categorical columns to factors. A factor is R's type for a categorical variable.
  3. Turn every question mark into NA, then drop those rows. That leaves 297 of the 303 samples.
  4. Count the levels with xtabs and check that each level has enough patients.
  5. Fit the simple model with sex alone, then the full model with every variable.
  6. Compute McFadden's pseudo R squared, then plot the ranked predicted probabilities.

Load and clean the data

This block reads the file, names the columns, and casts the messy columns to factors.

url <- "http://archive.ics.uci.edu/ml/machine-learning-databases/heart-disease/processed.cleveland.data"
data <- read.csv(url, header = FALSE)

colnames(data) <- c("age","sex","cp","trestbps","chol","fbs","restecg",
                    "thalach","exang","oldpeak","slope","ca","thal","hd")

data[data == "?"] <- NA
data$sex  <- as.factor(ifelse(data$sex == 0, "F", "M"))
data$cp   <- as.factor(data$cp)
data$ca   <- as.factor(as.integer(data$ca))    # was read as strings
data$thal <- as.factor(as.integer(data$thal))
data$hd   <- as.factor(ifelse(data$hd == 0, "Healthy", "Unhealthy"))

data <- data[!(is.na(data$ca) | is.na(data$thal)), ]   # 303 rows become 297

The same thing in Python, with pandas.

import pandas as pd

cols = ["age","sex","cp","trestbps","chol","fbs","restecg",
        "thalach","exang","oldpeak","slope","ca","thal","hd"]
df = pd.read_csv(url, header=None, names=cols, na_values="?")

df["sex"] = df["sex"].map({0: "F", 1: "M"}).astype("category")
for c in ["cp","fbs","restecg","exang","slope","ca","thal"]:
    df[c] = df[c].astype("category")
df["hd"] = (df["hd"] > 0).astype(int)          # 0 = Healthy, 1 = Unhealthy

df = df.dropna()                               # 303 rows become 297

Sanity check the counts

Count how many patients sit in each combination of outcome and predictor.

xtabs(~ hd + sex, data = data)
xtabs(~ hd + cp, data = data)
xtabs(~ hd + restecg, data = data)   # only 4 patients in one level

In Python, pd.crosstab does the same job.

pd.crosstab(df["hd"], df["sex"])
pd.crosstab(df["hd"], df["cp"])

Fit the simple model, then the full model

The first model uses sex only. The family = "binomial" argument is what makes glm do logistic regression.

logistic <- glm(hd ~ sex, data = data, family = "binomial")
summary(logistic)

logistic <- glm(hd ~ ., data = data, family = "binomial")   # "." means all other columns
summary(logistic)

In Python, statsmodels is the closest match. It prints coefficients, p values and deviances.

import statsmodels.formula.api as smf

simple = smf.logit("hd ~ sex", data=df).fit()
print(simple.summary())

rhs  = " + ".join(c for c in df.columns if c != "hd")
full = smf.logit(f"hd ~ {rhs}", data=df).fit()
print(full.summary())

Effect size and the plot

McFadden's pseudo R squared comes from the two deviances in the summary.

ll.null     <- logistic$null.deviance / -2
ll.proposed <- logistic$deviance / -2

(ll.null - ll.proposed) / ll.null                       # 0.55
1 - pchisq(2 * (ll.proposed - ll.null),
           df = (length(logistic$coefficients) - 1))    # a tiny p value

In Python, statsmodels reports both numbers directly.

full.prsquared     # McFadden pseudo R-squared, about 0.55
full.llr_pvalue    # chi-squared p value for the whole model

Formulas

The logistic model
$$ \log\!\left(\frac{p}{1-p}\right) = \beta_0 + \beta_1 x_1 + \dots + \beta_k x_k $$

Symbols: \(p\) is the probability of the event, here heart disease. \(p/(1-p)\) are the odds. \(\beta_0\) is the intercept and \(\beta_1 \dots \beta_k\) are the coefficients for the predictors \(x_1 \dots x_k\). What it tells you: the model is linear on the log odds scale, not the probability scale. That is why glm prints log odds.

The fitted simple model
$$ \log(\text{odds of heart disease}) = -1.0438 + 1.2737 \times \text{sex}_{M} $$

Symbols: \(\text{sex}_M\) is 0 for a female patient and 1 for a male patient. What it tells you: \(-1.0438\) is the female log odds, and \(1.2737\) is how much higher the male log odds are.

The second coefficient is a log odds ratio
$$ 1.2737 = \log\!\left(\frac{\text{odds}_{male}}{\text{odds}_{female}}\right) \quad\Longrightarrow\quad \frac{\text{odds}_{male}}{\text{odds}_{female}} = e^{1.2737} = 3.57 $$

Symbols: the two odds are the odds of heart disease within each sex. What it tells you: the odds of heart disease for a male patient are about 3.6 times the odds for a female patient. That is the effect size, which matters more than a small p value.

McFadden's pseudo R squared
$$ R^2 = \frac{LL(\text{null}) - LL(\text{fit})}{LL(\text{null})}, \qquad LL = \frac{\text{deviance}}{-2} $$

Symbols: \(LL(\text{null})\) comes from the null deviance, the model with no predictors. \(LL(\text{fit})\) comes from the residual deviance the same way. What it tells you: the share of the null model's badness the predictors explain. Here it is 0.55.

P value for that R squared
$$ \chi^2 = 2\big(LL(\text{fit}) - LL(\text{null})\big), \qquad df = k $$

Symbols: \(k\) is the number of coefficients minus one for the intercept. What it tells you: how likely an R squared this big is by chance. Here the p value is tiny, so the fit is not luck.

Worked example from the video

Example

The simple model prints an intercept of \(-1.0438\) and \(1.2737\) for the male level of sex.

For a female patient \(\text{sex}_M = 0\), so the log odds are \(-1.0438\). The odds are \(e^{-1.0438} = 0.35\), a probability of \(0.35 / 1.35 = 0.26\).

For a male patient \(\text{sex}_M = 1\), so the log odds are \(-1.0438 + 1.2737 = 0.2299\). The odds are \(e^{0.2299} = 1.26\), a probability of \(1.26 / 2.26 = 0.56\).

Both Wald test p values are well below 0.05, so both coefficients are significant.

The full model, fitted with hd ~ ., has a much smaller residual deviance and AIC. Age is a weak predictor, because the median age is 56 and most patients are old. Sex stays a good predictor. The pseudo R squared is 0.55.

Common mistakes and subtle points

Watch out Do not read the coefficients as probabilities. They are log odds. An intercept of \(-1.0438\) means odds of 0.35, or a probability of 0.26.
Watch out Check your column types before you fit. If sex or cp stay numeric, R treats them as continuous. That silently changes the model.
Watch out Count the levels with xtabs first. One level of restecg has only four patients. Levels that thin can make the fit unstable.
Watch out The fitted probability plot uses the training data. It shows the fit, not future performance.

If they ask you in an interview

Why do you pass family = "binomial" to glm?
The glm function fits many kinds of generalized linear model. The family argument tells it which one. Binomial gives logistic regression, so the model predicts a yes or no outcome on the log odds scale.
How do you interpret a logistic regression coefficient?
The intercept is the log odds of the outcome for the baseline group. Every other coefficient is a log odds ratio for a one unit change in that predictor. I exponentiate it to make it readable. Here 1.2737 becomes an odds ratio of about 3.6 for male over female.
Why is there no ordinary R squared, and what do you report instead?
Logistic regression is fitted by maximum likelihood, not least squares. So there is no residual sum of squares to split. I report McFadden's pseudo R squared, which compares the fitted model's log likelihood with the null model's. Here it was 0.55, with a tiny chi squared p value.
How do you compare two logistic models?
I look at the residual deviance and the AIC. Lower deviance means a better fit. The AIC is that deviance adjusted for the number of parameters. The full model beat the sex only model on both.
