Decoder-Only Transformers, ChatGPTs specific Transformer

▶ Watch on YouTube Also in: Neural Networks / Deep Learning (video 21)

This video builds a decoder-only transformer, the kind of transformer used for ChatGPT, one piece at a time. It shows how the model reads the prompt "What is StatQuest?" and answers "Awesome".

In one breath

Each token is turned into numbers with word embedding, and positional encoding adds word order. Masked self-attention lets each token look only at itself and the tokens before it. A residual connection adds the input back, and a fully connected layer plus SoftMax picks the next token. The same unit encodes the prompt and generates the answer, feeding each new token back in until it outputs EOS. Unlike the original transformer, there is no separate encoder and only one type of attention.

The main idea

A neural network needs numbers as input. So every word, word fragment, or symbol becomes a token, which is mapped to numbers. The model then adds position values so it knows word order. "Squatch eats pizza" and "Pizza eats Squatch" use the same words but mean very different things.

Next, masked self-attention works out how each token relates to the tokens before it. "Masked" means a token may never look at tokens that come after it. Because each token depends only on what came earlier, the method is also called autoregressive.

Finally, the model turns each token's numbers into a guess for the next token. When it answers a prompt, it appends that guess to the sequence and runs again. It stops when it generates the EOS (end of sequence) token.

Step by step

  1. Word embedding. A small network has one input per token in the vocabulary. Put 1 in the input for the current token and 0 elsewhere. The weights on that input pass through identity activation functions and become the token's numbers.
  2. Weights come from training. All weights start random. Backpropagation adjusts them step by step while the model learns to predict words in known documents.
  3. Positional encoding. Alternating sine and cosine squiggles give a position value for each embedding of each token. These values are added to the embeddings. A value may repeat now and then. But the squiggles get wider for later embeddings, so each token's full sequence is unique.
  4. Queries, keys, and values. For each token, three separate sets of weights turn its position-encoded numbers into query, key, and value numbers. The same three weight sets are reused for every token.
  5. Masked similarity. The dot product of a token's query with each key gives a similarity score. A dot product multiplies matching numbers and adds the products. A token only compares itself with itself and the tokens before it.
  6. SoftMax and weighted sum. SoftMax turns the scores into percentages that add up to 1. Each value is scaled by its percentage, and the scaled values are added to give the masked self-attention values.
  7. Residual connection. The position-encoded values are added to the self-attention values. This makes training easier, because attention does not also need to preserve the embedding and position information.
  8. Next-token prediction. A fully connected layer has one input per number and one output per token in the vocabulary. A final SoftMax picks the next token. This happens for every prompt token too, which lets training compare predictions with known words.
  9. Generate the answer. Start from EOS placed after the prompt, run the same steps, and get "awesome". Feed "awesome" back in, and the model outputs EOS, so it stops.

Formulas

The video shows these calculations with numbers rather than symbols. The lines below write the same arithmetic in compact form, for a model with 2 numbers per token.

Embedding plus position
$$ p_i = e_i + \text{PE}_i $$

Symbols: \(e_i\) is the pair of word embedding numbers for token \(i\). \(\text{PE}_i\) is the pair of sine and cosine position values for position \(i\). \(p_i\) is the position-encoded token. What it tells you: the same word gets different numbers in different positions, so word order is kept.

Query, key, value
$$ q_i = W_Q\,p_i,\quad k_i = W_K\,p_i,\quad v_i = W_V\,p_i $$

Symbols: \(W_Q, W_K, W_V\) are three separate sets of weights, shared by all tokens. \(q_i, k_i, v_i\) are the query, key, and value numbers for token \(i\). What it tells you: because the weights are reused, the model handles prompts of any length.

Masked similarity and SoftMax
$$ s_{ij} = q_i \cdot k_j \;\; (j \le i), \qquad w_{ij} = \frac{e^{s_{ij}}}{\sum_{m \le i} e^{s_{im}}} $$

Symbols: \(s_{ij}\) is the dot product similarity of token \(i\)'s query with token \(j\)'s key. \(j \le i\) is the mask: only the token itself and earlier tokens count. \(w_{ij}\) is the SoftMax percentage, between 0 and 1, and the percentages for token \(i\) add up to 1. What it tells you: more similar earlier tokens get a bigger share in the encoding.

Attention output and residual
$$ a_i = \sum_{j \le i} w_{ij}\, v_j, \qquad h_i = a_i + p_i $$

Symbols: \(a_i\) is the masked self-attention values for token \(i\). \(h_i\) is the result after adding the residual connection \(p_i\). What it tells you: each token's new numbers mix in context from earlier tokens, while the original information is still carried forward.

Next-token prediction
$$ \text{next token} = \text{SoftMax}\big(W\,h_i + b\big) $$

Symbols: \(W\) and \(b\) are the weights and biases of the fully connected layer. It has one output per token in the vocabulary (five here). What it tells you: the token with the largest output becomes the predicted next token.

Worked example from the video

Example

Vocabulary. There are five tokens: What, is, StatQuest, Awesome, and EOS. There are two embedding numbers per token.

Embedding. Put 1 in the input for "What" and 0 elsewhere. The identity activation functions return its weights, so "What" becomes \((-2.38,\ 0.10)\). "is" becomes \((0.61,\ 0.17)\).

Position. For the first position, the sine squiggle gives 0 and the cosine squiggle gives 1. So the position-encoded "What" is \((-2.38 + 0,\ 0.10 + 1) = (-2.38,\ 1.10)\).

Attention for "is". Its query is \((-2.4,\ 2.6)\). The query's dot product with the key for "is" is 5.9. Its dot product with the key for "What" is \(-25.7\). SoftMax turns these into 1.0 for "is" and 0.0 for "What", because \(1/(1+e^{5.9-(-25.7)}) = 1/(1+e^{31.6})\) is essentially 0. So the attention values for "is" are 100% of its own value numbers.

Attention for "What". It only compares with itself: the similarity is \(-12.4\), and SoftMax of a single score is 1.0. Its attention values are just its value numbers, \((-2.9,\ -1.3)\).

Residual. Add the position-encoded "What": \((-2.9 + (-2.38),\ -1.3 + 1.10) = (-5.28,\ -0.20)\). These two numbers go into the fully connected layer.

Predictions on the prompt. "What" predicts "is", which is correct. "is" predicts "What", which is wrong, though "StatQuest" came close. "StatQuest" predicts EOS, which is correct. During training, the mistake would be used to update the weights. When answering, these guesses do not matter.

Generating. EOS goes in at position 4. Its query is compared with its own key and the keys for "What is StatQuest". The output is "awesome". Then "awesome" goes in at position 5, and the output is EOS, so generation stops.

Common mistakes and subtle points

Watch out In a decoder-only transformer, masked self-attention covers both the prompt and the output, at all times. In the original transformer, masked self-attention is used only on the output tokens, during training.
Watch out Generated tokens must still attend to the prompt. In "Don't eat the delicious-looking and smelling pizza", losing "Don't" flips the meaning. Including the prompt in masked self-attention while generating is what prevents this.
Watch out The model predicts a next token for every prompt token, even though those words are already known. The unit must both encode the prompt and generate output. Those predictions are also what training compares with the known words.
Watch out Generation starts from EOS even if EOS was not predicted at the end of the prompt. Some people use SOS (start of sequence) instead. Either way, generation continues until EOS is produced.

If they ask you in an interview

How does a decoder-only transformer differ from the original encoder-decoder transformer?
The original transformer has an encoder for the input and a separate decoder for the output. At inference it uses self-attention over all input words and encoder-decoder attention, with queries from the decoder and keys and values from the encoder. A decoder-only transformer uses one unit for both jobs and only one kind of attention, masked self-attention. It applies that masking all the time, to the prompt and to the output.
Why is the attention masked?
Each token may only look at itself and the tokens before it. This is what makes the model autoregressive: each new token depends only on what came earlier. It lets the model learn to generate correct output without looking ahead at the answer.
Why not just use the position-encoded values instead of computing attention?
The attention values mix in information from earlier tokens, which gives each token context. Stacking several attention cells, each with its own weights, captures different relationships among words. The original GPT stacked twelve of them.
What do the residual connections do?
They add the position-encoded values back onto the attention output. This makes complex networks easier to train. The attention layer can focus on relationships among words, without also having to preserve the embedding and position information.
How does the model turn its numbers into a word?
A fully connected layer maps each token's numbers to one output per vocabulary token, and a SoftMax picks the next token. The original GPT instead reused the word embedding weights in reverse. A fully connected layer is a common alternative.

Recap in 30 seconds

  • Word embedding turns each token into numbers, and sine and cosine positional encoding adds word order.
  • Query, key, and value weights are shared across tokens, so prompts can have any length.
  • Masked self-attention compares each token only with itself and earlier tokens, using dot products and SoftMax.
  • Residual connections add the input back, which makes the network easier to train.
  • A fully connected layer and SoftMax predict the next token for every position.
  • Generation starts from EOS, feeds each new token back in, and stops when EOS is produced.
  • Unlike the encoder-decoder transformer, a decoder-only transformer has one unit and one attention type, masked everywhere.
