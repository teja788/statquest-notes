Support Vector Machines Part 1 (of 3): Main Ideas

▶ Watch on YouTube Also in: —

This video builds up to support vector machines in three steps: maximal margin classifiers, support vector classifiers, and then support vector machines with kernels. Each step fixes a weakness of the one before it.

In one breath

A maximal margin classifier puts the threshold halfway between the edge observations of two classes, but one outlier can ruin it. A support vector classifier uses a soft margin that allows some misclassifications, and cross-validation picks how many. When the classes overlap too much for any flat boundary, a support vector machine moves the data into a higher dimension and finds a support vector classifier there. Kernel functions, such as the polynomial and radial kernels, do this in a systematic way. The kernel trick computes the high-dimensional relationships without actually transforming the data.

The main idea

Josh starts with the mass of some mice. Some mice are not obese and some are obese. We want a threshold: a cut-off point on the mass line that splits the two groups. A good choice is the midpoint between the observations on the edge of each cluster.

The shortest distance between the observations and the threshold is called the margin. The midpoint makes this margin as large as possible. Using the threshold with the largest margin is called a maximal margin classifier. Its problem is outliers. One not-obese mouse that sits close to the obese mice drags the threshold right next to the obese group.

The fix is to allow misclassifications. When we allow them, the distance between the observations and the threshold is called a soft margin. A classifier that uses a soft margin is a soft margin classifier, also called a support vector classifier. The observations on the edge of the soft margin and inside it are the support vectors.

Support vector classifiers still fail when the classes overlap a lot. A support vector machine handles this. It moves the data into a higher dimension, then finds a support vector classifier there.

Step by step

  1. Pick a threshold at the midpoint between the edge observations of each class. New observations are classified by which side of the threshold they fall on.
  2. This maximal margin classifier is very sensitive to outliers in the training data. An outlier can place the threshold far from most of its own class.
  3. Allow misclassifications to get a soft margin. This is the bias-variance trade-off, where fitting the training data less closely helps on new data. The threshold has higher bias, but lower variance.
  4. Use cross-validation to decide how many misclassifications and how many observations to allow inside the soft margin. Cross-validation tests each choice on data held back from training.
  5. With one measurement the support vector classifier is a point. With two it is a line, and with three it is a plane. With four or more it is a hyperplane. Technically, all of these flat boundaries are hyperplanes, but we use the word only when we cannot draw it.
  6. For drug dosages where only the middle dosages cure patients, no single point separates the classes. So we add a y-axis equal to dosage squared, which makes the data two-dimensional.
  7. In two dimensions, a line (a support vector classifier) now separates cured from not cured. New dosages are squared and classified by which side of the line they land on.

Josh sums up the main ideas of a support vector machine in three steps. Start with data in a relatively low dimension. Move the data into a higher dimension. Find a support vector classifier that separates the higher-dimensional data into two groups.

But why dosage squared, and not dosage cubed? Support vector machines use kernel functions to find support vector classifiers in higher dimensions in a systematic way. The polynomial kernel has a parameter \(d\), the degree of the polynomial. It computes the relationships between each pair of observations in \(d\) dimensions, and those relationships are used to find the support vector classifier. Cross-validation finds a good value for \(d\).

The radial kernel, also called the radial basis function kernel, finds support vector classifiers in infinite dimensions. On a new observation, it behaves like a weighted nearest neighbour model. The closest observations have a lot of influence on the classification, and far observations have little.

Kernels do not actually transform the data. They only calculate the relationships between every pair of points as if they were in the higher dimension. This is the kernel trick. It saves computation, and it makes the infinite dimensions of the radial kernel possible.

Formulas

This video is about main ideas, so it has only simple formulas. The kernel formulas themselves come in Parts 2 and 3.

Maximal margin threshold
$$\text{threshold} = \frac{x_{\text{edge, class A}} + x_{\text{edge, class B}}}{2}$$

Symbols: \(x_{\text{edge, class A}}\) is the observation of the first class that is closest to the other class; \(x_{\text{edge, class B}}\) is the same for the second class. What it tells you: the midpoint makes the distance to both edge observations equal, which gives the largest possible margin.

Lifting 1-D data into 2-D
$$\text{dosage} \;\longrightarrow\; (x,\,y) = (\text{dosage},\ \text{dosage}^2)$$

Symbols: \(x\) is the original dosage; \(y\) is the dosage squared. What it tells you: each observation gets a second coordinate, so a straight line in two dimensions can separate classes that no single point could separate in one dimension.

Polynomial kernel dimensions
$$d = 1:\ (\text{dosage}) \qquad d = 2:\ (\text{dosage},\ \text{dosage}^2) \qquad d = 3:\ (\text{dosage},\ \text{dosage}^2,\ \text{dosage}^3)$$

Symbols: \(d\) is the degree of the polynomial. Each step up in \(d\) adds one dimension, based on the next power of the dosage. What it tells you: setting \(d\) systematically increases the dimensions in which the kernel looks for a support vector classifier; pick \(d\) with cross-validation.

Worked example from the video

Example

The drug works only when the dosage is just right. Low and high dosages do not cure patients. On a single dosage line, any threshold makes many misclassifications.

Take the observation with dosage 0.5. Its new y-axis value is \(0.5^2 = 0.25\), so it moves to the point \((0.5,\ 0.25)\). Do the same for every other observation. The data are now two-dimensional, and a support vector classifier (a line) separates cured from not cured.

For a new patient, square the dosage to get the y-coordinate. If the point lands on the not-cured side of the line, classify the patient as not cured. If it lands on the other side, classify the patient as cured.

Earlier in the video, cross-validation picks a soft margin that allows one misclassification and two correctly classified observations inside the soft margin.

Common mistakes and subtle points

Watch out A maximal margin classifier has low bias but high variance. One outlier in the training data can put the threshold in a bad place, so it performs poorly on new data.
Watch out Support vectors are not only the two closest points. They are all observations on the edge of the soft margin and inside it, including misclassified ones.
Watch out Do not choose the soft margin by eye. Cross-validation decides how many misclassifications and observations to allow inside it. Cross-validation also picks the degree \(d\) of a polynomial kernel.
Watch out Kernels do not actually move the data to a higher dimension. The kernel trick only computes the pairwise relationships as if the data were there.

If they ask you in an interview

How do maximal margin classifiers, support vector classifiers, and support vector machines differ?
A maximal margin classifier puts the threshold where the margin is largest, and it allows no misclassifications, so outliers hurt it. A support vector classifier uses a soft margin that allows some misclassifications. A support vector machine moves the data into a higher dimension with a kernel, then finds a support vector classifier there.
What is a soft margin, and how do you choose it?
A soft margin is the distance between the observations and the threshold when we allow misclassifications. It trades a bit more bias for lower variance on new data. I would use cross-validation to decide how many misclassifications and observations to allow inside it.
What are support vectors?
They are the observations on the edge of the soft margin and inside it. They set where the support vector classifier goes, which is where the name comes from.
What is the kernel trick?
A kernel calculates the relationships between every pair of observations as if they were in a higher dimension, without actually transforming the data. This reduces computation. It also makes the radial kernel possible, because that kernel works in infinite dimensions.
How does the radial kernel behave on a new observation?
It behaves like a weighted nearest neighbour model. The closest observations have a lot of influence on the classification, and observations that are far away have relatively little.

Recap in 30 seconds

  • The margin is the shortest distance between the observations and the threshold.
  • A maximal margin classifier uses the midpoint between the edge observations, but outliers ruin it.
  • A support vector classifier uses a soft margin that allows misclassifications, chosen with cross-validation.
  • Support vectors are the observations on the edge of the soft margin and inside it.
  • The classifier is a point in 1-D, a line in 2-D, a plane in 3-D, and a hyperplane in higher dimensions.
  • A support vector machine moves data to a higher dimension, for example by adding dosage squared, and finds a support vector classifier there.
  • The polynomial kernel adds dimensions with degree \(d\); the radial kernel works in infinite dimensions and acts like weighted nearest neighbours.
  • The kernel trick computes high-dimensional relationships without actually transforming the data.
