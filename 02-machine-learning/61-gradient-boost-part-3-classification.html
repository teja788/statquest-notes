Gradient Boost Part 3 (of 4): Classification

▶ Watch on YouTube

This video shows how Gradient Boost predicts a yes/no answer instead of a number. The method keeps its shape, but every prediction now lives on the log odds scale.

In one breath

Gradient Boost for classification starts with one leaf that holds the log of the odds for the whole dataset. The logistic function turns that log odds into a probability. The errors between labels and probabilities are called pseudo residuals. A small tree is fit to them, and each leaf gets an output value from a special formula. The scaled tree is added to the running log odds, and the loop repeats.

The main idea

Josh uses a tiny training set of six people. For each person he records whether they like popcorn, their age, and their favourite colour. The thing to predict is whether the person loves the movie Troll 2. Four people love it and two do not.

In Part 1 the first prediction was the average of the target. Here the first prediction is the log of the odds. Josh calls it the logistic regression version of the average. The odds are 4 yes divided by 2 no, and the log of that is 0.7.

To use a log odds for classification, you convert it to a probability with the logistic function. That gives a probability of 0.7 for every person. Since 0.7 is above the usual 0.5 threshold, the model labels all six people as fans. That is wrong for two of them.

The error for one person is called a pseudo residual. It is the observed value minus the predicted probability. A fan has an observed value of 1, so the residual is 0.3. A non fan has an observed value of 0, so the residual is −0.7.

Step by step

  1. Count the yes and no answers, and take the log of their ratio. This log odds is the first leaf and the first prediction for everyone.
  2. Push that log odds through the logistic function to get a probability. Compare it to a threshold, usually 0.5, to get a label.
  3. Compute a pseudo residual for each person: the observed value minus the predicted probability.
  4. Grow a small tree that uses the features to predict those residuals. Josh limits it to three leaves. In practice people often allow 8 to 32 leaves.
  5. Give every leaf an output value with the transformation formula. A plain average does not work, because the residuals come from probabilities but the prediction is a log odds.
  6. Add the learning rate times the leaf output to each person's log odds. Josh uses 0.8 to make the change visible, though 0.1 is more common.
  7. Convert the new log odds to probabilities, compute new residuals, and grow the next tree. Repeat until you reach the maximum number of trees or the residuals get very small.

Formulas

Initial leaf
$$ \log(\text{odds}) = \log\!\left(\frac{\#\,\text{yes}}{\#\,\text{no}}\right) = \log\!\left(\frac{4}{2}\right) = 0.7 $$

Symbols: \(\#\,\text{yes}\) is the number of fans, 4. \(\#\,\text{no}\) is the number of non fans, 2. Their ratio is the odds, and \(\log\) is the natural logarithm. What it tells you: it gives one starting prediction for everyone.

Logistic function
$$ p = \frac{e^{\log(\text{odds})}}{1 + e^{\log(\text{odds})}} $$

Symbols: \(p\) is the predicted probability of loving Troll 2. \(e\) is Euler's number, about 2.718. \(\log(\text{odds})\) is the current prediction. What it tells you: it turns any log odds into a probability between 0 and 1.

Pseudo residual
$$ r_i = y_i - p_i $$

Symbols: \(r_i\) is the residual for person \(i\). \(y_i\) is the observed value, 1 for loves and 0 for does not love. \(p_i\) is that person's current predicted probability. What it tells you: it is the error that the next tree tries to predict.

Leaf output value
$$ \gamma = \frac{\sum_i r_i}{\sum_i p_i\,(1 - p_i)} $$

Symbols: \(\gamma\) is the output value of one leaf. The sums run over every person who lands in that leaf. \(r_i\) is that person's residual, and \(p_i\) is their probability from before this tree. What it tells you: it turns residuals on the probability scale into a step on the log odds scale. Josh derives it in Part 4.

Update rule
$$ \log(\text{odds})_{\text{new}} = \log(\text{odds})_{\text{old}} + \nu \times \gamma $$

Symbols: \(\log(\text{odds})_{\text{old}}\) is the prediction before this tree. \(\nu\) is the learning rate, 0.8 in this video. \(\gamma\) is the output value of the leaf the person falls into. What it tells you: each tree moves the prediction only part of the way.

Worked example from the video

Example

The first leaf holds \(\log(4/2) = 0.7\), and the logistic function turns that into a probability of 0.7. So the residual is \(1 - 0.7 = 0.3\) for each of the four fans, and \(0 - 0.7 = -0.7\) for each of the other two.

The first tree has three leaves. One leaf holds a single residual of −0.7, so its output is \(-0.7 \div (0.7 \times 0.3) = -0.7 \div 0.21 = -3.3\). Another leaf holds two residuals, 0.3 and −0.7, so its output is \((0.3 - 0.7) \div (0.21 + 0.21) = -0.4 \div 0.42 = -1\). The last leaf holds three residuals of 0.3, so its output is \(0.9 \div 0.63 = 1.4\).

Now update the predictions with a learning rate of 0.8. The first person lands in the 1.4 leaf. The new log odds is \(0.7 + 0.8 \times 1.4 = 1.8\), and the probability rises to 0.9. This is a step in the right direction, because this person loves Troll 2.

The second person, also a fan, lands in the −1 leaf. The new log odds is \(0.7 + 0.8 \times (-1) = -0.1\), and the probability falls to 0.5. This prediction got worse, which is one reason to build many trees, not one.

New residuals use these new probabilities, which now differ per person. The second tree's three leaves get outputs of 2, −2, and 0.6.

To classify a new person, start at the initial leaf and add both trees' scaled outputs. Josh's new person gets a log odds of 2.3, which is a probability of 0.9. That is above 0.5, so the model says this person loves Troll 2.

Common mistakes and subtle points

Watch out Do not average the residuals in a leaf, as you would for regression. A leaf with the single residual −0.7 outputs −3.3, not −0.7. The denominator \(\sum p(1-p)\) converts the probability errors into log odds.
Watch out The probability in the denominator is the one from before the current tree. For the first tree it is 0.7 for everybody. From the second tree on, each person has their own probability.
Watch out The log odds and the probability both show as 0.7 only because Josh rounds. The true values are 0.6931 and 0.6667. The 0.5 threshold is also a common choice, not a rule.

If they ask you in an interview

How does Gradient Boost for classification differ from Gradient Boost for regression?
The structure is the same: an initial guess, then trees fit to residuals, each scaled by a learning rate. The difference is the scale. Classification keeps the prediction as a log odds and starts from the log of the odds of the data. It uses the logistic function to get a probability, and leaf outputs use a transformation formula instead of an average.
Why is the leaf output value not just the average residual?
The residuals sit on the probability scale, but the tree is added to a log odds prediction. So you divide the sum of the residuals by the sum of \(p(1-p)\) in that leaf. That converts the step into log odds units. Josh derives the formula in Part 4.
What does the learning rate do, and what value would you use?
It scales each tree's contribution, so the model takes many small steps. The video uses 0.8 so the change is easy to see. In practice I would start near 0.1, which Josh calls more common.
How do you make a prediction for a new person?
Start with the initial log odds. Run the person down every tree, and add each leaf output times the learning rate. Then turn the total into a probability and compare it to the threshold. In the video the total is 2.3, a probability of 0.9, so the person is a fan.

Recap in 30 seconds

  • The first prediction is one leaf with the log of the odds, here \(\log(4/2) = 0.7\).
  • The logistic function turns any log odds into a probability, and 0.5 is a common threshold.
  • A pseudo residual is the observed value minus the predicted probability.
  • Each tree is fit to the residuals, usually with 8 to 32 leaves.
  • A leaf's output is the sum of its residuals divided by the sum of \(p(1-p)\), using earlier probabilities.
  • The learning rate times the output is added to the log odds, and the loop repeats.
  • To predict, add up the scaled outputs, convert to a probability, and apply the threshold.
