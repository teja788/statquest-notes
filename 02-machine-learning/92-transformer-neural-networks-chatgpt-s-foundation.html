Transformer Neural Networks, ChatGPT's foundation

▶ Watch on YouTube Also in: Neural Networks / Deep Learning (video 20)

This video builds a tiny Transformer one piece at a time. It translates the English phrase "Let's go" into the Spanish word "Vamos". Transformers are the foundation of ChatGPT, so each part is core interview material.

In one breath

A Transformer turns words into numbers with word embedding. It adds positional encoding so it knows word order. Self-attention compares every word with every word, using queries, keys and values, and mixes values by similarity. Residual connections add the inputs back so each part can focus on one job. The decoder repeats these steps and adds encoder-decoder attention to track the important input words. A fully connected layer and a SoftMax pick each output word until the decoder outputs EOS.

The main idea

Neural networks need numbers as input, so the first job is to turn words into numbers. Josh uses word embedding, a small network with one input per token. A token is any item in the vocabulary, such as a word, a word fragment, or a symbol like EOS (end of sequence).

Word order matters. "Squatch eats pizza" and "Pizza eats Squatch" use the same words but mean very different things. So the Transformer adds position values to each word's embedding. This is called positional encoding.

Next, the Transformer needs to know how words relate to each other. In "The pizza came out of the oven and it tasted good", the word "it" should be linked to "pizza", not "oven". Self-attention does this by measuring how similar each word is to every word in the sentence, including itself. Those similarities decide how much each word contributes to the new encoding of a word.

Finally, the original position-encoded values are added back to the self-attention values. These bypasses are called residual connections. The figure shows the whole encoder path for the word "let's" with the video's numbers.

Step by step

  1. Word embedding. Put a 1 in the input for the word and 0 everywhere else. Each connection multiplies the input by a weight. The activation functions are identity functions (output equals input), so that word's weights come straight out. The same network is reused for every word, so any sentence length works.
  2. Training. All weights start as random numbers. Backpropagation, an iterative fitting method, improves them step by step. It learns from English phrases with known Spanish translations.
  3. Positional encoding. Position values come from a sequence of alternating sine and cosine squiggles, one squiggle per embedding value. Later squiggles are wider, so each word gets a unique sequence of position values. These are added to the embedding values.
  4. Queries, keys and values. For each word, multiply the position-encoded values by sets of weights and add the products. This gives a query, a key and a value for each word. The same weights are reused for every word.
  5. Self-attention. Take the dot product of a word's query with every word's key. Run these similarities through a SoftMax, scale each word's values by its percentage, and add them up.
  6. Run it in parallel and stack it. Queries, keys and values for all words can be computed at the same time, so Transformers run fast on GPUs. A stack of self-attention cells, each with its own weights, is called multi-head attention. The original paper used eight.
  7. Residual connections. Add the position-encoded values to the self-attention values. Now self-attention can focus on relationships without also having to preserve the embedding and position information. This finishes the encoder.
  8. Decoder start. The decoder embeds the output vocabulary: "ir", "vamos", "y" and EOS. It starts with the EOS token, though some people use SOS (start of sequence). It adds the same positional encoding, then its own self-attention with different weights, plus residual connections.
  9. Encoder-decoder attention. A query from the decoder is compared with keys from each encoded input word. A SoftMax turns the similarities into percentages, which scale the input words' values. This keeps important input words, like "don't" in "Don't eat the delicious looking and smelling pizza", from being lost. Another set of residual connections follows.
  10. Pick the word. A fully connected layer (a simple network with weights and biases) has one input per value and one output per output token. A final SoftMax selects "vamos". Then "vamos" goes back into a copy of the decoder, which outputs EOS, so decoding stops.

Formulas

Position-encoded input
$$ x = e + p $$

Symbols: \(x\) is the position-encoded values for a word, \(e\) is its word embedding values, and \(p\) is its position values from the sine and cosine squiggles. What it tells you: word meaning and word position are simply added together, value by value.

Making a query (keys and values work the same way)
$$ q_1 = w_1 x_1 + w_2 x_2, \qquad q_2 = w_3 x_1 + w_4 x_2 $$

Symbols: \(x_1, x_2\) are a word's two position-encoded values, \(w_1\) to \(w_4\) are weights learned by backpropagation, and \(q_1, q_2\) are the two query values. What it tells you: each query, key or value is just a weighted sum of the inputs, with separate weights for queries, keys and values.

Dot-product similarity
$$ s = q \cdot k = q_1 k_1 + q_2 k_2 $$

Symbols: \(q\) is the query for the word being encoded, \(k\) is the key for the word it is compared with, and \(s\) is their similarity score. What it tells you: multiply each pair of numbers and add the products; a larger score means the two words are more similar.

SoftMax
$$ p_i = \frac{e^{s_i}}{\sum_j e^{s_j}} $$

Symbols: \(s_i\) is the similarity with word \(i\), \(e\) is Euler's number (about 2.718), the sum runs over all words \(j\), and \(p_i\) is the share given to word \(i\). What it tells you: it keeps the order of the scores from low to high and turns them into numbers between 0 and 1 that add up to 1.

Weighted sum of values, plus the residual
$$ a = \sum_i p_i \, v_i, \qquad \text{output} = a + x $$

Symbols: \(v_i\) is the value for word \(i\), \(p_i\) is its SoftMax share, \(a\) is the attention values, and \(x\) is the position-encoded input added back by the residual connection. What it tells you: each word's new encoding is a blend of all words' values, weighted by similarity, plus its original values.

Scaled dot product (original paper)
$$ s = \frac{q \cdot k}{\sqrt{d}} $$

Symbols: \(q \cdot k\) is the dot product above and \(d\) is the number of embedding values per token. What it tells you: the authors found that scaling the dot product helped encode and decode long, complicated phrases.

Worked example from the video

Example

Embedding. "Let's" becomes 1.87 and 0.09. "Go" becomes −0.78 and 0.27. For "to", the weights are −1.45 and 1.50, but its input is 0, so it sends only zeros.

Positional encoding. "Let's" gets position values 0 and 1, so it becomes \(1.87 + 0 = 1.87\) and \(0.09 + 1 = 1.09\). "Go" gets −0.9 and 0.4, so it becomes \(-0.78 - 0.9 = -1.68\) and \(0.27 + 0.4 = 0.67\).

Self-attention for "let's". The query for "let's" is −1.0 and 3.7. Its dot product with the key for "let's" is 11.7, and with the key for "go" it is −2.6. SoftMax turns these into 1.0 and 0.0, so "let's" is encoded from 100% of its own values and 0% of the values for "go". The same steps, with a new query, give the self-attention values for "go".

Decoder. EOS embeds as 2.70 and −1.34. Adding position values 0 and 1 gives 2.70 and −0.34. Its self-attention values are −2.8 and −2.3. Encoder-decoder attention says to use 100% of the first input word and 0% of the second. The fully connected layer gives four outputs, and SoftMax picks "vamos". Feeding "vamos" back in gives EOS, so the translation is "Vamos".

Common mistakes and subtle points

Watch out Weights are shared across words, not across parts. The same query, key and value weights are reused for every word, but the decoder's self-attention and the encoder-decoder attention each use their own sets, different from the encoder's.
Watch out Two words can get the same value from one squiggle. In "Squatch eats pizza", the second and third words both got −0.9 for the first position value. The full sequence of position values is still unique, because later squiggles are wider.
Watch out In encoder-decoder attention, the query comes from the decoder, while the keys and values come from the encoded input words. Mixing these up is a common slip.
Watch out The video's Transformer is deliberately minimal. The original one also normalized values after each step, scaled the dot product, and added extra neural networks with hidden layers to both the encoder and decoder.

If they ask you in an interview

Why do Transformers need positional encoding?
Word order changes meaning, as in "Squatch eats pizza" versus "Pizza eats Squatch". Positional encoding is how a Transformer keeps track of that order. It adds values from sine and cosine squiggles to each word's embedding. Each position gets a unique sequence of values, so the model can tell where each word sits.
Walk me through self-attention.
Each word's position-encoded values are turned into a query, a key and a value using shared weights. The query for one word is compared with every key using a dot product. A SoftMax turns those similarities into percentages, and the word's new encoding is the sum of all values scaled by those percentages.
What do residual connections do?
They add a sub-unit's input back to its output, for example adding position-encoded values to the self-attention values. This lets each sub-unit focus on one part of the problem, such as word relationships, without also preserving the earlier information. It also makes complex networks easier to train.
How is encoder-decoder attention different from self-attention?
Self-attention relates words within one phrase. Encoder-decoder attention takes a query from the decoder and compares it with keys from the encoded input words, then scales those input words' values. It makes sure important input words, like "don't", are not lost in the translation.
Why are Transformers fast to train?
One unit is built per word and copied for every word, with the same weights. So embeddings, queries, keys, values and attention for all words can be computed at the same time. That fits well on hardware with many cores, like GPUs.

Recap in 30 seconds

  • Word embedding turns each token into numbers, using one network reused for every word.
  • Positional encoding adds sine and cosine values so the Transformer keeps track of word order.
  • Self-attention compares queries with keys by dot product, applies SoftMax, and sums the scaled values.
  • Residual connections add inputs back so each sub-unit can focus on one job.
  • The decoder starts from EOS and uses its own self-attention plus encoder-decoder attention.
  • A fully connected layer and SoftMax pick each output word until the decoder outputs EOS.
  • Shared weights let all words be processed in parallel, which makes Transformers fast.
