Neural Networks Part 8: Image Classification with Convolutional Neural Networks (CNNs)

▶ Watch on YouTube Also in: Neural Networks / Deep Learning (video 14)

This video shows how a convolutional neural network (CNN) classifies a small image. It follows one image of the letter O through every step, from raw pixels to the final answer.

In one breath

A normal neural network needs one weight per pixel for each hidden node. So it does not scale to big images. A CNN first slides a small learned filter over the image and adds a bias to make a feature map. It then runs the feature map through ReLU and keeps only the largest value in each region with max pooling. The few values that remain go into a normal neural network that makes the decision. This reduces the number of inputs, uses the correlation between nearby pixels, and tolerates small shifts in the image.

The main idea

StatSquatch plays tic-tac-toe against a computer and draws either an X or an O. The computer must decide which letter it is. Each drawing is a 6 by 6 grid of pixels, where 0 is a white pixel and 1 is a black pixel.

For an image this small, a normal neural network could work. You turn the 36 pixels into 36 input nodes and connect them to a hidden layer. But each hidden node then needs 36 weights, and a 100 by 100 image would need 10,000 weights per node. The network may also fail if the image moves by one pixel. It also cannot use the fact that nearby pixels tend to be similar, which Josh calls correlated pixels.

A CNN fixes all three problems. It reduces the number of input nodes, it tolerates small shifts, and it takes advantage of the correlation between neighbouring pixels. The figure below shows the full path for the letter O.

Step by step

  1. Pick a filter. A filter is a small square, commonly 3 by 3 pixels. Its pixel values start random and are learned with backpropagation during training.
  2. Overlay and multiply. Place the filter on the top-left corner of the image, multiply each pair of overlapping pixels, and add the products. For the letter O this sum is 3. This sum of products is called a dot product, and the filter is said to be convolved with the input.
  3. Add a bias and store it. Add a bias term to the dot product and put the result into a new grid called the feature map.
  4. Slide the filter. Move the filter one pixel to the right and repeat. Other CNNs may move two or more pixels at a time. Keep sliding until the feature map is full. Each feature-map cell summarises a group of neighbouring pixels, which is how the CNN uses their correlation.
  5. Apply ReLU. Run every feature-map value through ReLU. Negative values become 0 and positive values stay the same. For the O, only two cells stay above zero.
  6. Max pool. Slide another filter over the feature map that simply keeps the largest value in each region. It usually moves so that it does not overlap itself. This keeps the spot where the filter matched the image best. Taking the average instead is called average or mean pooling.
  7. Flatten. Turn the pooled grid into a column of input nodes. Here the 6 by 6 image becomes just four inputs.
  8. Use a normal neural network. The four inputs feed one hidden node with ReLU, which connects to two outputs: one for O and one for X.

Formulas

Josh does not write these as equations, but each step he describes is a simple rule. The lines below put his words into symbols.

One feature-map cell
$$ F_{r,c} = \sum_{i=1}^{3}\sum_{j=1}^{3} x_{r+i-1,\,c+j-1}\; w_{i,j} \;+\; b $$

Symbols: \(F_{r,c}\) is the feature-map value at row \(r\), column \(c\). \(x\) is an image pixel (0 for white, 1 for black). \(w_{i,j}\) is the filter pixel at row \(i\), column \(j\), learned by backpropagation. \(b\) is the bias term. What it tells you: each cell is a dot product between the filter and the patch under it, plus a bias; for the top-left patch of the O this is \(3 + b\).

ReLU activation
$$ \text{ReLU}(z) = \max(0,\, z) $$

Symbols: \(z\) is any input value, such as a feature-map cell. What it tells you: negative values become 0 and positive values pass through unchanged.

Max pooling
$$ P_k = \max\{\, F_{r,c} : (r,c) \in \text{region } k \,\} $$

Symbols: \(P_k\) is the pooled value for region \(k\). \(F_{r,c}\) are the values in that region after ReLU. What it tells you: each region keeps only the spot where the filter matched best. Replace max with the mean to get average pooling.

Hidden node for the O
$$ h = \text{ReLU}\Big(\sum_{k=1}^{4} v_k P_k + b_h\Big) = \text{ReLU}(0.34) = 0.34 $$

Symbols: \(P_k\) are the four input nodes. \(v_k\) are their weights. \(b_h\) is the hidden node's bias. \(h\) is the hidden node's output. What it tells you: after pooling, the rest is an ordinary neural network with weighted sums, a bias, and ReLU.

Weights per hidden node without a CNN
$$ 6 \times 6 = 36 \qquad 100 \times 100 = 10{,}000 $$

Symbols: each number is the pixel count, which equals the number of weights one hidden node needs when every pixel is an input. What it tells you: the plain approach grows with image size, which is why it does not scale.

Worked example from the video

Example

The letter O. The filter lands on the top-left corner, which matches the filter exactly. The dot product is 3, the highest possible value, and a bias is added. After sliding over the whole image, ReLU sets every cell to 0 except two. Max pooling keeps those two best matches, so the four input nodes hold two positive values and two zeros.

The weighted sum of the inputs plus the bias is 0.34. Since 0.34 is greater than 0, ReLU outputs 0.34. The connections to the outputs then give 1 for O and 0 for X. The CNN says the image is an O.

The letter X. The filter, the pooling, and every weight and bias stay the same. Only the image changes. The same steps give 0 for O and 1 for X.

The X shifted one pixel right. The output for X is 1.23 and the output for O is −0.2. Since 1.23 is much closer to 1, the CNN still says X. This shows the tolerance to small shifts.

Common mistakes and subtle points

Watch out The filter values are not chosen by hand. They start random and are learned with backpropagation, just like the weights in the dense part of the network.
Watch out The pooling step does not compute a dot product. It simply selects the maximum, or the mean for average pooling, and it usually moves without overlapping itself. The convolution filter, in contrast, moved one pixel at a time here, and other CNNs may move further.
Watch out Raw outputs such as 1.23 and −0.2 are not probabilities. Josh notes that you can run them through softmax or argmax to make them easier to interpret.
Watch out This is about as simple as a CNN gets. Fancier CNNs still rest on the same three parts: filters (convolution), an activation function on the filter output, and pooling.

If they ask you in an interview

Why use a CNN instead of a plain neural network for images?
A plain network needs one weight per pixel for every hidden node. A 100 by 100 image means 10,000 weights per node. It may also fail when the image shifts by a pixel, and it ignores that nearby pixels are correlated. A CNN reduces the number of inputs, tolerates small shifts, and uses those correlations through its filters.
What does a convolutional filter do?
It is a small grid, often 3 by 3, that slides over the image. At each position it takes the dot product with the pixels underneath and adds a bias, which fills one cell of the feature map. Its values are learned with backpropagation, so it becomes a detector for a useful pattern.
What is max pooling, and how does it differ from average pooling?
Max pooling keeps the largest value in each region of the feature map, usually with regions that do not overlap. That keeps the spot where the filter matched the image best. Average pooling takes the mean of each region instead.
How does a CNN cope with an image shifted by one pixel?
The filter still finds the same local pattern, just in a nearby position, and pooling keeps the strongest match in each region. In the video, an X shifted one pixel still gave 1.23 for X and −0.2 for O, so it was classified correctly.
What are the core building blocks of any CNN?
Filters, which perform the convolution, then an activation function such as ReLU on the filter output, then pooling. The pooled values are flattened and passed to an ordinary neural network that makes the final decision.

Recap in 30 seconds

  • Plain neural networks need too many weights for images and are sensitive to small shifts.
  • A CNN slides a small learned filter over the image, takes dot products, and adds a bias to build a feature map.
  • ReLU sets negative feature-map values to zero and keeps positive values.
  • Max pooling keeps the best match in each region; average pooling keeps the mean instead.
  • The pooled values are flattened into input nodes for a normal neural network.
  • In the video, 36 pixels shrink to 4 inputs, and the network outputs 1 for O and 0 for X.
  • A shifted X still scores 1.23 for X versus −0.2 for O, so the CNN tolerates small shifts.
