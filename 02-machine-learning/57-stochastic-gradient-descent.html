Stochastic Gradient Descent

▶ Watch on YouTube

Regular gradient descent uses every sample in every step. With big data that is too slow. Stochastic gradient descent uses one random sample per step instead.

In one breath

Gradient descent finds the best parameters by taking small steps down a loss function. Each step plugs every data point into every derivative, so the cost grows with samples and with parameters. Stochastic gradient descent picks one random sample per step and uses only that sample. In practice people use a small subset, called a mini batch, because it is faster than all the data and steadier than one point. The video also shows that new data can update the parameters without starting again.

The main idea

Josh starts with the example from the earlier gradient descent video. Three people gave their height and weight. We want to fit a line, so we need an intercept and a slope. We measure the fit with the sum of the squared residuals, which is one of many loss functions. Gradient descent then takes the derivative of that loss with respect to each parameter and steps downhill.

With three data points and two parameters, each step is cheap. Each derivative has only three terms. The problem appears when the model grows. Imagine a logistic regression that uses 23,000 genes to predict a disease. That gives 23,000 derivatives. Now imagine one million samples. Each derivative then needs one million terms, so one step costs 23 billion terms. A run of 1,000 steps costs at least 2.3 trillion terms.

Stochastic gradient descent removes the sum. It picks one sample at random and uses only that sample to compute the derivatives. The model is the same, the loss is the same, and the update rule is the same. Only the number of terms per step changes, and it drops by a factor equal to the sample size.

Step by step

  1. Start with a guess for the parameters. In the video the intercept is 0 and the slope is 1.
  2. Pick one sample at random from the data. Josh picks a point with weight 3 and height 3.3.
  3. Plug that one sample into the derivative of the loss with respect to the intercept, and with respect to the slope. These derivatives are the slopes of the loss surface at the current guess.
  4. Multiply each derivative by the learning rate to get the step size. The video uses a learning rate of 0.01.
  5. Subtract each step size from the matching old parameter. That gives the new intercept and the new slope, and so a new line.
  6. Pick another random sample and repeat. Stop after the maximum number of steps, or when the steps become very small.

Stochastic gradient descent helps most when the data repeat themselves. The video shows 12 points that form three clusters. Points inside a cluster carry almost the same information, so one point from a cluster already tells you most of what the whole cluster would tell you.

Formulas

The fitted line
$$ \hat{h}_i = b + m\,w_i $$

Symbols: \(\hat{h}_i\) is the predicted height for person \(i\). \(b\) is the intercept, the height when weight is zero. \(m\) is the slope, the change in height for one unit of weight. \(w_i\) is the observed weight of person \(i\). What it tells you: the two numbers we are searching for are \(b\) and \(m\).

Loss over all the data
$$ \mathrm{SSR} = \sum_{i=1}^{n}\bigl(h_i - (b + m\,w_i)\bigr)^{2} $$

Symbols: \(\mathrm{SSR}\) is the sum of the squared residuals. \(h_i\) is the observed height. \(n\) is the number of samples. The bracket is the residual, the gap between what we saw and what we predicted. What it tells you: smaller is better, and every sample adds one term to the sum.

Derivatives used by regular gradient descent
$$ \frac{\partial\,\mathrm{SSR}}{\partial b} = \sum_{i=1}^{n} -2\bigl(h_i - (b + m\,w_i)\bigr) \qquad \frac{\partial\,\mathrm{SSR}}{\partial m} = \sum_{i=1}^{n} -2\,w_i\bigl(h_i - (b + m\,w_i)\bigr) $$

Symbols: \(\partial\,\mathrm{SSR}/\partial b\) is how fast the loss changes when the intercept changes. \(\partial\,\mathrm{SSR}/\partial m\) is the same for the slope. All other symbols are as above. What it tells you: one step needs \(n\) terms for each parameter, so the cost grows with the size of the data.

Derivatives used by stochastic gradient descent
$$ \frac{\partial L_j}{\partial b} = -2\bigl(h_j - (b + m\,w_j)\bigr) \qquad \frac{\partial L_j}{\partial m} = -2\,w_j\bigl(h_j - (b + m\,w_j)\bigr) $$

Symbols: \(j\) is the one sample chosen at random for this step. \(L_j\) is the squared residual of that single sample. \(h_j\) and \(w_j\) are its height and weight. What it tells you: the sum is gone, so each derivative costs one term instead of \(n\) terms.

Step size and update
$$ \text{step}_b = \frac{\partial L}{\partial b}\times\eta \qquad b_{\text{new}} = b_{\text{old}} - \text{step}_b \qquad m_{\text{new}} = m_{\text{old}} - \text{step}_m $$

Symbols: \(\eta\) is the learning rate, set to 0.01 in the video. \(\text{step}_b\) and \(\text{step}_m\) are how far we move the intercept and the slope. What it tells you: the update rule is exactly the same as regular gradient descent, so only the derivative changed.

Worked example from the video

Example

We start with intercept \(b=0\) and slope \(m=1\). We pick one random point with weight 3 and height 3.3. The learning rate is 0.01.

$$ \hat{h} = 0 + 1\times 3 = 3 \qquad\Rightarrow\qquad h - \hat{h} = 3.3 - 3 = 0.3 $$

Josh skips the arithmetic here, so it is worked out below. First, plug that residual into the two single sample derivatives.

$$ \frac{\partial L}{\partial b} = -2(0.3) = -0.6 \qquad \frac{\partial L}{\partial m} = -2(3)(0.3) = -1.8 $$

Multiply each by the learning rate to get the step sizes, then update.

$$ b_{\text{new}} = 0 - (-0.6\times0.01) = 0.006 \qquad m_{\text{new}} = 1 - (-1.8\times0.01) = 1.018 $$

We repeat this with new random points many times. The video ends with an intercept of 0.85 and a slope of 0.68. Least squares, the exact answer, gives 0.87 and 0.68. With a mini batch of three samples per step the intercept comes out at 0.86, a little closer to the exact value.

Then a new person is measured, with weight 1.1 and height 2. We do not go back to the first guess. We start from the most recent estimate and take one more step with the same rule. The line becomes intercept 0.878 and slope 0.7.

Common mistakes and subtle points

Watch out

The strict meaning of stochastic gradient descent is one sample per step. In real work people almost always use a small subset, called a mini batch. A mini batch is steadier than one point and much faster than all the data. Say which one you mean.

Watch out

Like regular gradient descent, stochastic gradient descent is sensitive to the learning rate. The usual strategy is to start fairly large and shrink it at each step. The rule that controls this shrinking is called the schedule. If your parameters never settle, adjust the schedule first.

Watch out

Single sample steps are noisy, because each step follows one point instead of the whole data set. A mini batch can give more stable estimates in fewer steps. Here it got the intercept a little closer to 0.87.

If they ask you in an interview

What problem does stochastic gradient descent solve?
Regular gradient descent puts every sample into every derivative at every step. With 23,000 parameters and a million samples, that is 23 billion terms per step. Stochastic gradient descent uses one random sample per step, so the cost drops by a factor of the sample size. It makes fitting feasible when full gradient descent is not.
What is the difference between batch, stochastic and mini batch gradient descent?
They differ only in how many samples are used to compute the derivatives at each step. Batch uses all of them, stochastic uses exactly one, and mini batch uses a small subset. Mini batch sits between the two: more stable estimates in fewer steps than pure stochastic, and far faster than using all the data. The model, the loss and the update rule are identical in all three.
What is a learning rate schedule, and why does it matter?
The schedule is the rule that changes the learning rate as training goes on. The common strategy is to start relatively large, then make the rate smaller with each step. Many implementations set a schedule for you by default. If the estimates fail to converge, the schedule is the first setting I would tune.
Why can stochastic gradient descent absorb new data so easily?
Each step only needs the current parameter values and one sample. So when new data arrive, we start from the most recent estimate and take one more step. In the video a new point with weight 1.1 and height 2 moved the line to intercept 0.878 and slope 0.7. Nothing has to be recomputed from the original guess, which makes it a good fit for online or streaming settings.

Recap in 30 seconds

  • Gradient descent finds the intercept and slope by stepping down the sum of the squared residuals.
  • Every step plugs every sample into every derivative, so large data and many parameters make it very slow.
  • Stochastic gradient descent picks one sample at random and computes the derivatives from that sample alone.
  • Everything else is unchanged: the same loss, the same step size formula, and the same update rule.
  • In practice we use a mini batch of a few samples, which is steadier than one point and faster than all of them.
  • The learning rate still matters, and the schedule shrinks it as the steps go on.
  • On the 12 point example the method gave 0.85 and 0.68, close to the exact answer of 0.87 and 0.68.
  • New data can update the parameters with one extra step, without starting from the first guess.
