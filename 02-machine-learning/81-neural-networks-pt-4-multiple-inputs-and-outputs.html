Neural Networks Pt. 4: Multiple Inputs and Outputs

▶ Watch on YouTube Also in: Neural Networks / Deep Learning (video 9)

This video shows what a neural network does when it has two inputs and three outputs. It uses the Iris flower data, and it shows that the same "bend, scale, and add" idea still works, only now in three dimensions.

In one breath

The network takes petal width and sepal width and predicts the species: setosa, versicolor, or virginica. With two inputs, each hidden node makes a bent surface instead of a bent line. Each output node scales the two bent surfaces by its own weights, adds them, and adds a bias, which gives one crinkled surface per species. To classify a flower, you run its two widths through the network and pick the output closest to 1. In practice, the outputs usually go to argmax or softmax first.

The main idea

The earlier networks in this series had one input (drug dosage) and one output (effectiveness). One input needs one axis, and one output needs one more axis. So everything fit on a flat two-dimensional graph, and we could watch the weights and biases slice, flip, and stretch the activation functions into a squiggle.

This network has two input nodes and three output nodes. The inputs are two measurements of an iris flower: the width of a petal and the width of a sepal. A sepal is the leafy part under the petals. The outputs are one score for each of the three species. There are two hidden nodes, and both use the ReLU activation function, which turns any negative value into zero.

Two inputs plus one output need three axes, so each picture is now a 3-D surface. The key point is that nothing new happens in the math. Each hidden node still makes one bent shape. Each output still scales and adds those shapes. The only change is that the shapes are surfaces, not lines.

Step by step

  1. Scale the inputs. Josh scales both widths so the smallest value in the training data is 0 and the largest is 1. This keeps the math simple.
  2. Start with one output. To keep things simple, he first uses both inputs but only the setosa output. The graph has petal width and sepal width on the floor, and the setosa score going up.
  3. Compute the top hidden node. Multiply petal width by −2.5, multiply sepal width by 0.6, add them, and add the bias 1.6. This gives the x-axis coordinate for the activation function.
  4. Apply ReLU. ReLU returns the value if it is above zero, and zero otherwise. Doing this for every pair of widths from 0 to 1 gives a blue bent surface. The bend is where ReLU sets values to zero.
  5. Scale the blue surface. Multiply every height on the blue surface by the setosa weight for that node, −0.1.
  6. Repeat for the bottom hidden node. The same steps give an orange bent surface. Its heights are multiplied by 1.5.
  7. Add and add the bias. Add the blue and orange heights point by point to get a green crinkled surface. Then add the final bias, 0. This is the setosa output.
  8. Repeat for the other outputs. Versicolor and virginica reuse the same blue and orange surfaces. Only the output weights and final bias change, so each species gets its own crinkled surface.
  9. Classify a flower. Run its widths through the network and pick the output closest to 1. Usually the outputs go to argmax or softmax first, which is the topic of the next video.

Formulas

Scaling the inputs
$$ x_{\text{scaled}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}} $$

Symbols: \(x\) is the raw width; \(x_{\min}\) and \(x_{\max}\) are the smallest and largest widths in the training data. What it tells you: a scaled value of 0 means "the smallest width seen", not "zero centimetres".

Top hidden node
$$ z_{\text{top}} = -2.5\,p + 0.6\,s + 1.6, \qquad h_{\text{top}} = \max(0,\; z_{\text{top}}) $$

Symbols: \(p\) is scaled petal width; \(s\) is scaled sepal width; −2.5 and 0.6 are the weights on the two connections; 1.6 is the bias; \(z_{\text{top}}\) is the x-axis coordinate for the activation function; \(h_{\text{top}}\) is the ReLU output. What it tells you: over all \((p, s)\) pairs, \(h_{\text{top}}\) forms the blue bent surface. The bottom node works the same way with its own weights and gives the orange surface.

One output node
$$ y_k = w_{k,\text{top}}\, h_{\text{top}} + w_{k,\text{bot}}\, h_{\text{bot}} + b_k $$

Symbols: \(k\) is the species; \(h_{\text{top}}\) and \(h_{\text{bot}}\) are the blue and orange surface heights; \(w_{k,\text{top}}\) and \(w_{k,\text{bot}}\) are that species' weights on the two hidden nodes; \(b_k\) is its final bias; \(y_k\) is its score. What it tells you: every species' crinkled surface is just a different weighted sum of the same two bent surfaces.

Worked example from the video

Example

Corner point, petal width 0 and sepal width 0. The top node gets \(-2.5(0) + 0.6(0) + 1.6 = 1.6\). ReLU keeps 1.6, because it is greater than zero. For setosa, multiply by −0.1: \(1.6 \times -0.1 = -0.16\). At the same point, the scaled orange height is 1.05. So the green height is \(-0.16 + 1.05 = 0.89\), and adding the bias 0 leaves 0.89.

Move along petal width. With petal width 0.2 and sepal width 0, the top node gets \(-2.5(0.2) + 1.6 = 1.1\). ReLU keeps 1.1. Repeating this over the whole grid of widths builds the blue bent surface.

A flower found in the woods. Its scaled petal width is 0.5 and its scaled sepal width is 0.37. The network gives setosa a score of 0.09, so it is probably not setosa. Versicolor scores 0.86, which is closest to 1, so the network predicts versicolor.

Reading the surfaces. Setosa is highest when petal width is near 0 and lowest near 1. Versicolor is high when petal width is near 0.4. Virginica is high when petal width is near 1.

Common mistakes and subtle points

Watch out A scaled petal width of 0 does not mean the petal is zero centimetres wide. It means the smallest width in the training data, and 1 means the largest.
Watch out The raw output surfaces live on very different scales. Josh changes the y-axis range for versicolor and virginica just to see their shape. Do not compare surface shapes without checking the axis range.
Watch out The three outputs do not have their own hidden nodes. They all reuse the same blue and orange surfaces and differ only in output weights and bias.
Watch out "Pick the output closest to 1" is a simple reading. With two or more outputs, the values usually go through argmax or softmax before the final decision.

If they ask you in an interview

What changes when a neural network has two inputs instead of one?
The math is the same, but the shapes gain a dimension. Each hidden node now makes a bent surface over the two inputs instead of a bent line. The output adds scaled copies of those surfaces into a crinkled surface.
How does a network with three outputs reuse its hidden layer?
Every output node sees the same hidden-node values. Each output has its own weights on those hidden nodes and its own bias. So each class gets a different weighted sum of the same bent surfaces.
Walk me through one hidden node's calculation.
Multiply each input by its connection weight, add the products, and add the bias. Then pass the result through the activation function. In the Iris example, that is −2.5 times petal width plus 0.6 times sepal width plus 1.6, then ReLU.
How do you turn the three output values into a class?
In the simple view, you pick the class whose output is closest to 1. In practice, with two or more outputs, you usually pass the values to argmax or softmax before making the final decision.

Recap in 30 seconds

  • The Iris network uses petal width and sepal width to predict setosa, versicolor, or virginica.
  • The inputs are scaled so 0 is the smallest and 1 is the largest width in the training data.
  • Each ReLU hidden node turns the two inputs into a bent surface.
  • Each output scales the two bent surfaces, adds them, and adds a bias to make a crinkled surface.
  • All three outputs share the hidden surfaces and differ only in their output weights and biases.
  • For the found iris, versicolor scored 0.86, closest to 1, so the network predicts versicolor.
  • With several outputs, the values usually go to argmax or softmax before the final choice.
