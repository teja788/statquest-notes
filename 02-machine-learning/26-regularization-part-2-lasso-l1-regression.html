Regularization Part 2: Lasso (L1) Regression

▶ Watch on YouTube

Lasso regression adds a penalty to least squares, just like ridge regression does. The one change in the penalty lets lasso delete useless variables from the model.

In one breath

Ridge regression minimises the sum of the squared residuals plus lambda times the slope squared. Lasso regression uses the absolute value of the slope instead of the square. Both add a little bias and remove a lot of variance, and both pick lambda by cross validation. The big difference is that ridge can only push a parameter close to zero, while lasso can push it all the way to zero. So lasso can drop useless variables and leave you with a simpler equation.

The main idea

Josh starts with the mouse data from the ridge video. Weight predicts size. The red dots are the training data and the green dots are the testing data. A least squares line fits the training dots very well, so it has low bias. But it misses the testing dots badly, so it has high variance.

Ridge regression minimises the sum of the squared residuals plus lambda times the slope squared. That second part is the penalty. The ridge line fits the training data a bit worse, so it has more bias. In return the variance drops a lot.

Now change one thing. Instead of squaring the slope, take its absolute value. That is lasso regression. Everything else stays the same. Lambda is still any value from zero to infinity, chosen by cross validation.

The important difference appears when you keep raising lambda. Ridge regression shrinks the slope closer and closer to zero, but never reaches it. Lasso shrinks the slope until it is exactly zero.

Step by step

  1. Fit the training data with least squares. This gives the line with the smallest sum of squared residuals, and often high variance on new data.
  2. Write down the lasso objective. It is the sum of the squared residuals plus lambda times the absolute value of the slope.
  3. Include every estimated parameter in the penalty except the y intercept. The intercept is left alone, exactly as in ridge regression.
  4. Try many values of lambda from zero upwards. Use cross validation to see which value predicts new data best.
  5. Watch the parameters shrink as lambda grows. They do not shrink at the same speed, so a weak term can fall much faster than a strong one.
  6. Keep the terms that survive. Any parameter that lasso drives to exactly zero removes its variable from the final equation.

Formulas

Least squares
$$ \min \; \mathrm{SSR} = \sum_{i=1}^{n} \left( y_i - \hat{y}_i \right)^2 $$

Symbols: \(y_i\) is the measured size of mouse \(i\). \(\hat{y}_i\) is the size the line predicts. \(n\) is the number of training points. A residual is the gap between the dot and the line. What it tells you: least squares only cares about the training points, so it can fit them too closely.

Ridge regression (L2)
$$ \min \; \mathrm{SSR} + \lambda \times \mathrm{slope}^2 $$

Symbols: \(\lambda\) (lambda) is the penalty strength, any value from zero to positive infinity. The slope is the estimated parameter for weight. What it tells you: a large slope now costs you, so the fitted line gets flatter as lambda grows.

Lasso regression (L1)
$$ \min \; \mathrm{SSR} + \lambda \times \left| \mathrm{slope} \right| $$

Symbols: the vertical bars mean absolute value, so the size of the slope without its sign. Everything else means the same as above. What it tells you: this is the only change from ridge, and it is what allows a parameter to land on exactly zero.

Many parameters
$$ \min \; \mathrm{SSR} + \lambda \sum_{j=1}^{p} \left| \beta_j \right| $$

Symbols: \(\beta_j\) is the estimated parameter for the \(j\)-th variable, such as the slope for weight or the diet difference. \(p\) is the number of such parameters. The y intercept is not in this sum. What it tells you: the same penalty works for many variables at once, and for logistic regression too.

Worked example from the video

Example

Josh writes a big equation that predicts size from four terms: weight, high fat diet, astrological sign, and the air speed of a swallow. The first two are sensible. The other two are nonsense.

Apply ridge regression and raise lambda. The useful parameters shrink a little and the silly ones shrink a lot. None of them ever becomes zero, so all four terms stay.

Apply lasso regression and raise lambda. The silly parameters go all the way to zero, so those two terms disappear. You are left with a prediction that uses only weight and diet.

Because lasso can throw out useless variables, it does a little better than ridge when a model is full of junk terms. When most of the variables are actually useful, ridge tends to do a little better.

Common mistakes and subtle points

Watch out Do not say that ridge regression performs variable selection. Ridge can only shrink a parameter asymptotically close to zero. The term stays in the equation no matter how large lambda gets.
Watch out The penalty never includes the y intercept. Both ridge and lasso penalise all the other estimated parameters, but the intercept is left free.
Watch out Lambda is not a number you guess. You choose it with cross validation. At lambda equal to zero, lasso gives back the plain least squares line.
Watch out Parameters do not shrink at the same rate. A diet difference may shrink far more than a slope. So do not read shrinkage as a ranking of the variables.

If they ask you in an interview

What is the difference between ridge and lasso regression?
Both start from the sum of the squared residuals and add lambda times a penalty on the parameters. Ridge squares each parameter, and lasso takes the absolute value. That looks small, but it matters. Ridge only pushes a parameter close to zero, while lasso sets it to exactly zero and removes the variable.
When would you choose lasso over ridge?
I would lean to lasso when I think the model contains many useless variables. Lasso removes them, so it cuts variance more in that situation and gives a simpler equation. When I believe most of my variables carry real signal, ridge usually does a little better, because it keeps them all and just shrinks them.
How do you pick lambda, and what happens at the two extremes?
I pick it by cross validation, trying a range of values and keeping the one with the best performance on held out data. At lambda equal to zero there is no penalty, so I get the least squares fit with its high variance. As lambda grows the parameters shrink towards zero, which adds bias but reduces variance.
Where can you apply these penalties?
Anywhere you estimate parameters, not just simple linear regression. Josh shows a model with two diets, a logistic regression that predicts obesity from weight, and a model that mixes continuous weight with a discrete diet term. The same penalty is added to whatever the model already minimises.

Recap in 30 seconds

  • Lasso regression minimises the sum of the squared residuals plus lambda times the absolute value of the parameters.
  • Ridge regression is the same idea, except it squares the parameters instead.
  • Both add a small amount of bias and buy a large drop in variance.
  • Lambda runs from zero to positive infinity and is chosen by cross validation.
  • Neither penalty touches the y intercept, and neither shrinks every parameter equally.
  • Ridge can only get asymptotically close to zero, so every variable stays in the model.
  • Lasso reaches exactly zero, so it removes useless variables and leaves a simpler equation.
  • Lasso wins when many variables are useless, and ridge wins when most are useful.
