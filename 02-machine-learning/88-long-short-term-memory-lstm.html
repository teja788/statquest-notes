Long Short-Term Memory (LSTM)

▶ Watch on YouTube Also in: Neural Networks / Deep Learning (video 16)

This video explains Long Short-Term Memory (LSTM), a type of recurrent neural network built to avoid the exploding and vanishing gradient problem. Josh walks through one LSTM unit with real numbers, then shows it remembering an early value in a stock price sequence.

In one breath

A basic recurrent neural network uses one feedback loop for all memories, so its gradients can explode or vanish. An LSTM keeps separate paths for long-term and short-term memory. The long-term path has no weights on it, so it flows safely through many unrolled units. Three stages decide how much long-term memory to keep, what to add, and what short-term memory to pass on.

The main idea

Josh starts with the problem from the previous video. In a basic, or vanilla, recurrent neural network, the input is multiplied by the feedback weight once per unrolled step. With 50 days of data, a weight of 2 gives \(2^{50}\), and the gradient explodes. A weight of 0.5 gives \(0.5^{50}\), and the gradient vanishes.

The LSTM fixes this with one simple change. Instead of one feedback loop for events from long ago and from yesterday, it uses two separate paths. The cell state (the green line across the top) carries long-term memory. The hidden state (the pink line along the bottom) carries short-term memory.

The key detail is that no weights or biases touch the long-term memory directly. It is changed only by one multiplication and one addition. This lack of weights keeps the gradient from exploding or vanishing. The short-term memory, in contrast, is directly connected to weights.

Step by step

  1. Two activation functions. Unlike earlier networks in the series, an LSTM uses sigmoid and tanh. The sigmoid turns any input into a number between 0 and 1. The tanh (hyperbolic tangent) turns any input into a number between −1 and 1.
  2. Stage 1: how much long-term memory to keep. The short-term memory and the input are weighted, summed with a bias, and passed through a sigmoid. The long-term memory is multiplied by that percentage. Oddly, this stage is called the forget gate.
  3. Stage 2: create a potential memory. One block combines the short-term memory and the input with weights and a bias, then applies tanh. The result is a potential long-term memory.
  4. Stage 2: decide how much of it to add. A second block uses the same sigmoid method to pick a percentage of that potential memory. That share is added to the long-term memory. This stage is usually called the input gate.
  5. Stage 3: update the short-term memory. The new long-term memory goes through tanh to give a potential short-term memory. A sigmoid block picks what percentage of it to pass on, and the product is the new short-term memory.
  6. The output. The new short-term memory is also the output of the whole unit, so this stage is called the output gate.
  7. Unroll over time. For sequential data, the unit is unrolled once per data point, passing both memories forward. Every unrolled copy uses the exact same weights and biases, so the LSTM can handle sequences of different lengths.

Formulas

Below, \(C\) is the long-term memory, \(h\) is the short-term memory, and \(x\) is the input. Every \(w\) is a weight and every \(b\) is a bias. Each stage uses its own weights and bias.

Sigmoid activation
$$ \sigma(z) = \frac{1}{1 + e^{-z}} $$

Symbols: \(z\) is the x-axis coordinate going in. \(e\) is Euler's number, about 2.718. \(\sigma(z)\) is the y-axis coordinate coming out. What it tells you: any input becomes a number between 0 and 1, so the LSTM uses it as a percentage. For example, \(\sigma(10) = 0.99995\) and \(\sigma(-5) \approx 0.01\).

Tanh activation
$$ \tanh(z) = \frac{e^{z} - e^{-z}}{e^{z} + e^{-z}} $$

Symbols: \(z\) is the input, and \(e\) is Euler's number again. What it tells you: any input becomes a number between −1 and 1, so the LSTM uses it to make potential memories. For example, \(\tanh(2) = 0.96\) and \(\tanh(-5) \approx -1\).

Stage 1: forget gate
$$ f = \sigma(w_1 h + w_2 x + b_1), \qquad C' = f \cdot C $$

Symbols: \(f\) is the percentage of long-term memory to remember. \(C'\) is the long-term memory after this stage. What it tells you: the long-term memory is only scaled down, never pushed through a weight.

Stage 2: input gate
$$ g = \tanh(w_3 h + w_4 x + b_2), \quad i = \sigma(w_5 h + w_6 x + b_3), \quad C_{\text{new}} = C' + i \cdot g $$

Symbols: \(g\) is the potential long-term memory. \(i\) is the percentage of it to add. \(C_{\text{new}}\) is the new long-term memory. What it tells you: new information enters the long-term memory only by addition.

Stage 3: output gate
$$ o = \sigma(w_7 h + w_8 x + b_4), \qquad h_{\text{new}} = o \cdot \tanh(C_{\text{new}}) $$

Symbols: \(o\) is the percentage of the potential short-term memory to pass on. \(h_{\text{new}}\) is the new short-term memory and the unit's output. What it tells you: the short-term memory is rebuilt from the new long-term memory at every step.

Worked example from the video

Example 1: one unit

Start with long-term memory 2, short-term memory 1, and input 1.

Stage 1. \(1 \times 2.7 + 1 \times 1.63 + 1.62 = 5.95\). Then \(\sigma(5.95) = 0.997\), and \(2 \times 0.997 = 1.99\). The long-term memory shrank a little. With an input of −10, the sigmoid would give 0 and the long-term memory would be completely forgotten.

Stage 2. The tanh block sums to 2.03, and \(\tanh(2.03) = 0.97\), the potential memory. The sigmoid block sums to 4.27, and \(\sigma(4.27) = 1.0\), so all of it is kept. The new long-term memory is \(1.99 + 0.97 = 2.96\).

Stage 3. \(\tanh(2.96) = 0.99\) is the potential short-term memory. The sigmoid block gives 0.99. The new short-term memory, and the output, is \(0.99 \times 0.99 = 0.98\).

Example 2: two companies' stock prices

Company A and Company B have five days of stock prices. They differ only on day 1 and day 5. On day 1, A is 0 and B is 1. On day 5, A returns to 0 and B returns to 1. Days 2, 3, and 4 are identical. To predict day 5 correctly, the LSTM must remember day 1.

Company A. Both memories start at 0. Day 1's value, 0, goes in. The new long-term memory is −0.20 and the new short-term memory is −0.13, rounded to −0.1. The unit is unrolled and day 2's value, 0.5, goes in, then days 3 and 4. The final short-term memory is 0.0, which correctly predicts A's day 5 value.

Company B. The same LSTM, with the same weights and biases, starts again from 0. Day 1's value, 1, goes in. The new long-term memory is 0.5 and the new short-term memory is 0.28, rounded to 0.3. After days 2 to 4, the final short-term memory is 1.0, which correctly predicts B's day 5 value.

Common mistakes and subtle points

Watch out The forget gate does not output "how much to forget." Its sigmoid output is the percentage of long-term memory that is remembered. A value near 1 keeps almost everything, and a value of 0 forgets everything.
Watch out "No weights on the long-term path" does not mean the long-term memory never changes. The forget gate scales it, and the input gate adds to it, at every step.

If they ask you in an interview

Why are vanilla RNNs hard to train?
When we unroll a vanilla RNN, the input gets multiplied by the feedback weight once per step. Over 50 steps, a weight of 2 gives 2 to the 50th power, so the gradient explodes. A weight of 0.5 gives a number near zero, so the gradient vanishes.
What is the main idea behind an LSTM?
Instead of one feedback loop for everything, an LSTM uses two paths. The cell state carries long-term memory and the hidden state carries short-term memory. The long-term path has no weights on it, so it can pass through many unrolled steps without exploding or vanishing gradients.
Walk me through the three gates.
The forget gate uses a sigmoid to decide what percentage of the long-term memory to keep. The input gate uses tanh to build a potential memory and a sigmoid to decide how much of it to add. The output gate passes the new long-term memory through tanh, then uses a sigmoid to decide how much becomes the new short-term memory, which is also the output.
Why use sigmoid in some places and tanh in others?
Sigmoid outputs a number between 0 and 1, so it works as a percentage of what to keep. Tanh outputs a number between −1 and 1, so it is used to create candidate memories that can be positive or negative.

Recap in 30 seconds

  • Vanilla RNNs suffer from exploding or vanishing gradients when unrolled many times.
  • An LSTM uses separate paths for long-term memory (cell state) and short-term memory (hidden state).
  • The long-term path has no weights acting on it, so gradients stay stable across many steps.
  • The forget gate keeps a percentage of the long-term memory, and the input gate adds a share of a new potential memory.
  • The output gate makes the new short-term memory, which is also the unit's output.
  • The same weights and biases are reused at every step, and the LSTM correctly predicted day 5 for both companies.
