Backpropagation Details Pt. 1: Optimizing 3 parameters simultaneously.

▶ Watch on YouTube Also in: Neural Networks / Deep Learning (video 6)

This video extends backpropagation from one parameter to three. Josh optimizes the last two weights, \(w_3\) and \(w_4\), and the last bias, \(b_3\), at the same time.

In one breath

We use the same drug dosage data and the same small neural network as in the Main Ideas video. The other weights and biases are already optimal, so only \(w_3\), \(w_4\) and \(b_3\) are unknown. The chain rule links the sum of the squared residuals (SSR) to each of the three parameters through the predicted values. The first part of each derivative is the same for all three parameters; only the second part changes. We plug all three derivatives into gradient descent and repeat until the green squiggle fits the data.

The main idea

In the Main Ideas video, only the last bias \(b_3\) was unknown. Now Josh pretends he also does not know the last two weights, \(w_3\) and \(w_4\). The weights and biases in the first layer stay fixed at their optimal values. The goal is to see how the chain rule and gradient descent handle more than one parameter, and to learn some notation.

Each dosage goes through two connections, one to each node in the hidden layer. Each node applies the softplus activation function, a smooth bent curve, \(\log(1 + e^{x})\). The top curve is scaled by \(w_3\) and the bottom curve by \(w_4\). The two scaled curves are added, and then \(b_3\) is added. The result is the green squiggle, which gives the predicted values.

All three unknown parameters reach the SSR only through the predicted values. So the chain rule splits each derivative into two factors. The first factor, the derivative of the SSR with respect to the predicted values, is shared. The second factor is simple for each parameter.

Step by step

  1. Initialize \(w_3\) and \(w_4\) with random values from a standard normal distribution, a bell curve with mean 0 and standard deviation 1. Here they start at 0.36 and 0.63. Set \(b_3\) to 0, because bias terms frequently start at zero.
  2. Run dosages from 0 to 1 through the top node to get the blue curve. Multiply its y-axis values by \(w_3\) to get a new blue curve.
  3. Run the dosages through the bottom node to get the orange curve. Multiply its y-axis values by \(w_4\) to get a new orange curve.
  4. Add the blue and orange curves to get the green squiggle. Adding \(b_3 = 0\) changes nothing yet.
  5. Measure the fit with the SSR. With these starting values, the SSR is 1.4.
  6. Find the derivative of the SSR with respect to \(b_3\). It is exactly the same derivative as in the Main Ideas video. Derivatives we already found do not change when we add more parameters.
  7. Introduce notation for the hidden layer, then find the derivatives with respect to \(w_3\) and \(w_4\) with the chain rule.
  8. Plug the observed values, predicted values and activation outputs into all three derivatives. Use them in gradient descent to calculate new values for \(w_3\), \(w_4\) and \(b_3\).
  9. Repeat until the predictions no longer improve very much, a maximum number of steps is reached, or some other criterion is met.

Formulas

Hidden-layer notation
$$ x_{1,i} = \text{input}_i \times w_1 + b_1, \qquad y_{1,i} = \text{softplus}(x_{1,i}) $$ $$ x_{2,i} = \text{input}_i \times w_2 + b_2, \qquad y_{2,i} = \text{softplus}(x_{2,i}) $$

Symbols: \(i\) is the index of the data point, so \(\text{input}_i\) is dosage \(i\). The first subscript, 1 or 2, names the top or bottom node. \(x\) is the x-axis coordinate that goes into the activation function, and \(y\) is the y-axis coordinate that comes out. \(w_1, b_1, w_2, b_2\) are the fixed first-layer weights and biases. What it tells you: each dosage makes two numbers in the hidden layer, one per node.

Predicted values (the green squiggle)
$$ \text{Predicted}_i = y_{1,i}\, w_3 + y_{2,i}\, w_4 + b_3 $$

Symbols: \(w_3\) scales the top curve, \(w_4\) scales the bottom curve, and \(b_3\) is the final bias. What it tells you: the prediction is the sum of the two scaled curves plus the bias, so all three parameters act on it directly.

Sum of the squared residuals
$$ \text{SSR} = \sum_{i=1}^{n} (\text{Observed}_i - \text{Predicted}_i)^2 $$

Symbols: \(n\) is the number of data points (3 here). \(\text{Observed}_i\) is the true value for dosage \(i\). What it tells you: a smaller SSR means the green squiggle fits the data better.

Shared derivative
$$ \frac{d\,\text{SSR}}{d\,\text{Predicted}} = \sum_{i=1}^{n} 2(\text{Observed}_i - \text{Predicted}_i) \times (-1) = \sum_{i=1}^{n} -2(\text{Observed}_i - \text{Predicted}_i) $$

Symbols: the 2 comes from moving the square to the front. The \(-1\) is the derivative of the inside of the parentheses with respect to the predicted value. What it tells you: this factor is the same for \(w_3\), \(w_4\) and \(b_3\).

Chain rule for w3
$$ \frac{d\,\text{SSR}}{d w_3} = \frac{d\,\text{SSR}}{d\,\text{Predicted}} \times \frac{d\,\text{Predicted}}{d w_3} = \sum_{i=1}^{n} -2(\text{Observed}_i - \text{Predicted}_i) \times y_{1,i} $$

Only the first term of the predicted value contains \(w_3\), and its derivative is \(y_{1,i}\), so we multiply the shared factor by the top node's output.

Chain rule for w4
$$ \frac{d\,\text{SSR}}{d w_4} = \frac{d\,\text{SSR}}{d\,\text{Predicted}} \times \frac{d\,\text{Predicted}}{d w_4} = \sum_{i=1}^{n} -2(\text{Observed}_i - \text{Predicted}_i) \times y_{2,i} $$

Only the second term contains \(w_4\), so the other terms give zero and we multiply the shared factor by the bottom node's output \(y_{2,i}\).

Chain rule for b3
$$ \frac{d\,\text{SSR}}{d b_3} = \frac{d\,\text{SSR}}{d\,\text{Predicted}} \times \frac{d\,\text{Predicted}}{d b_3} = \sum_{i=1}^{n} -2(\text{Observed}_i - \text{Predicted}_i) \times 1 $$

The bias is added on its own, so its derivative is 1 and the result is just the shared factor, the same as in the Main Ideas video.

Worked example from the video

Example

The data has three dosages: 0, 0.5 and 1. The fixed first-layer values are \(w_1 = 3.34\), \(b_1 = -1.43\), \(w_2 = -3.53\) and \(b_2 = 0.57\). The starting values are \(w_3 = 0.36\), \(w_4 = 0.63\) and \(b_3 = 0\).

Notation check for i = 3. Dosage 3 is 1, the maximum dosage. For the top node, \(x_{1,3} = 1 \times 3.34 - 1.43 = 1.91\). For the bottom node, \(x_{2,3} = 1 \times (-3.53) + 0.57 = -2.96\).

First prediction. For dosage 0, the observed value is 0 and the green squiggle predicts 0.72. With all three dosages, the SSR is 1.4.

Derivative for w3. Expand the sum, then plug in the observed values (0, 1, 0), the predicted values, and the top node's outputs \(y_{1,i}\). With rounded numbers:

$$ -2(0 - 0.72)(0.21) + -2(1 - 0.46)(0.82) + -2(0 - 0.77)(2.05) \approx 0.30 - 0.89 + 3.16 = 2.57 $$

Josh gets 2.58, because he uses the unrounded values.

The derivatives for \(w_4\) and \(b_3\) are found the same way. Gradient descent then uses all three to calculate new parameter values. Josh's animation shows the green squiggle fitting the data after 175 steps.

Common mistakes and subtle points

Watch out Adding more parameters does not change the derivatives you already found. The derivative for \(b_3\) is exactly the one from the Main Ideas video.
Watch out Read the subscripts in order. In \(x_{1,i}\) and \(y_{1,i}\), the first number names the node and \(i\) names the dosage. Mixing them up gives the wrong values in the sum.
Watch out The second factor for a weight is not a constant. \(y_{1,i}\) and \(y_{2,i}\) change with each dosage, so they must sit inside the sum next to their own residual.
Watch out Weights and biases start differently here. The weights get random values from a standard normal distribution, while the bias starts at 0.

If they ask you in an interview

How do you get the gradient of the loss for a last-layer weight?
I use the chain rule through the predicted values. The derivative of the SSR with respect to the weight is the derivative of the SSR with respect to the prediction, times the derivative of the prediction with respect to the weight. For a last-layer weight, that second part is just the output of the hidden node it multiplies.
Why can part of the calculation be reused across parameters?
All three parameters reach the SSR only through the predicted values. So the derivative of the SSR with respect to the predictions is the same for each of them. Only the second factor changes: the top node's output, the bottom node's output, or 1 for the bias.
How were the parameters initialized in this example?
The two weights got random values from a standard normal distribution, here 0.36 and 0.63. The bias was set to 0, because bias terms frequently start at zero.
When does gradient descent stop?
It repeats the update until the predictions no longer improve very much. It can also stop at a maximum number of steps, or when some other criterion is met.

Recap in 30 seconds

  • We optimize \(w_3\), \(w_4\) and \(b_3\) together, while the first-layer parameters stay fixed.
  • The weights start with random values from a standard normal distribution, and the bias starts at 0.
  • The prediction is \(y_{1,i} w_3 + y_{2,i} w_4 + b_3\), where \(y\) is a hidden node's softplus output.
  • The chain rule gives each derivative as the shared factor \(\sum -2(\text{Observed}_i - \text{Predicted}_i)\) times one simple term.
  • That simple term is \(y_{1,i}\) for \(w_3\), \(y_{2,i}\) for \(w_4\), and 1 for \(b_3\).
  • Derivatives we already found do not change when we add parameters.
  • Gradient descent uses all three derivatives at each step and repeats until the fit stops improving.
