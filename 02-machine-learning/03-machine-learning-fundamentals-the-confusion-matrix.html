Machine Learning Fundamentals: The Confusion Matrix

▶ Watch on YouTube

A confusion matrix is a small table. It counts what a classifier got right and what it got wrong on test data.

In one breath

Josh wants to predict heart disease, and many methods can do that job. So we need a fair way to compare them. We split the data, train each method, then test each one. We count the test results in a table. Its rows are the predictions and its columns are the known truth. The diagonal holds the correct calls, and the other cells hold the mistakes.

The main idea

Imagine clinical measurements for a group of patients: chest pain, good blood circulation, blocked arteries, and weight. We want to predict who will develop heart disease. Logistic regression, K nearest neighbours and random forest can all try. Which one works best with our data?

A confusion matrix answers that by counting. Each row is what the algorithm predicted. Each column is the known truth from the testing data. With two categories the table has four cells, and each cell has a name.

The top left cell holds the true positives: sick patients called sick. The bottom right holds the true negatives: healthy patients called healthy. The bottom left holds the false negatives, where a sick patient was called healthy. The top right holds the false positives, where a healthy patient was called sick.

Step by step

  1. Divide the data into a training set and a testing set. Cross validation is a good choice here.
  2. Train every method you are interested in on the training data.
  3. Test each trained method on the testing data, which it has never seen.
  4. Build one confusion matrix per method. Each test patient goes in the cell matching its prediction and its true label.
  5. Compare the matrices. The method with the bigger diagonal numbers is the better fit for this data.

The size of the table comes from the number of things you predict. Two categories give two rows and two columns. Josh then shows a second data set. People rate four films, and the model guesses a favourite from three options. That needs a three by three table.

Formulas

The video teaches a table, not an equation. Two short rules still help.

Size of the matrix
$$ \text{rows} \times \text{columns} = k \times k $$

Symbols: \(k\) is the number of categories you predict. What it tells you: the matrix is always square. It grows with the number of classes, not with the number of samples.

Accuracy (the usual rule of thumb)
$$ \text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN} $$

Symbols: \(TP\) is true positives, sick patients called sick. \(TN\) is true negatives, healthy patients called healthy. \(FP\) is false positives and \(FN\) is false negatives. What it tells you: it is the share of the table sitting on the diagonal. One number is easy to read, but it hides which kind of mistake you made.

Worked example from the video

Example

Josh applied a random forest to the testing data. It found 142 true positives and 110 true negatives. It missed 29 patients who did have heart disease. It also flagged 22 healthy patients as sick. So the testing set held \(142 + 110 + 29 + 22 = 303\) patients, and accuracy was \((142 + 110) / 303 \approx 0.83\).

K nearest neighbours was tested on the same data. It got 107 sick patients right, against 142, and 79 healthy patients right, against 110. Both diagonal counts are lower, so we choose the random forest.

Logistic regression gave a third matrix that looked much like the random forest one. When two tables are that close, the counts cannot pick a winner. Josh points to sensitivity, specificity, ROC and AUC as the next step.

Common mistakes and subtle points

Watch out The layout is a convention, not a law. Josh puts the predictions in the rows and the truth in the columns. Many software libraries do the opposite, so read the labels before you name a cell.
Watch out The two mistakes do not cost the same. Sending 29 sick patients home is not the same as worrying 22 healthy people. One accuracy number hides that difference.
Watch out A confusion matrix summarises, it does not decide. When two matrices look alike, you need finer metrics before you commit.

If they ask you in an interview

What is a confusion matrix?
It is a square table that compares predictions against the known truth on a test set. The diagonal counts the correct calls and the other cells count the errors. Almost every classification metric is built from it.
What is the difference between a false positive and a false negative?
A false positive is a healthy patient labelled as sick. A false negative is a sick patient labelled as healthy. The two usually carry very different costs, so I look at them separately.
How would you use it to choose between two models?
I build one matrix per model on the same testing data, then compare the diagonals. If one model wins in every correct cell, the choice is easy. If the matrices are close, I move on to sensitivity, specificity or an ROC curve.
What happens with more than two classes?
Only the size changes. Three categories give a three by three table, and forty give a forty by forty table. The diagonal is still where the model was right. The other cells show which classes it confuses.
