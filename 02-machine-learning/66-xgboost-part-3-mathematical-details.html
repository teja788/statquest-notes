XGBoost Part 3 (of 4): Mathematical Details

▶ Watch on YouTube

This video derives the two formulas that drive XGBoost: the output value of a leaf and the similarity score. It also shows that regression and classification differ only in the loss function.

In one breath

XGBoost picks the leaf output value that minimises a loss function plus a ridge-style penalty. The loss can be hard to minimise directly. So XGBoost swaps it for a second-order Taylor approximation: a parabola built from the loss's first and second derivatives. Setting the parabola's slope to zero gives the output value in one line. Flipping the same parabola upside down gives the similarity score.

The main idea

XGBoost starts with an initial prediction, usually 0.5. The residuals are the gaps between the observed values and that prediction. A loss function turns those gaps into one number that says how bad the prediction is. For regression Josh uses one half of the squared residual. For classification he uses the negative log likelihood, also called log loss.

A new tree must add something to the prediction. XGBoost puts all residuals in one leaf and asks a simple question: what single output value makes the total loss as small as possible? To that total it adds a regularization term, \( \tfrac{1}{2}\lambda\,O_{value}^{2} \). This works exactly like ridge regression. It punishes large output values, so the leaf stays modest.

Josh first sets lambda to zero and answers the question by hand. He tries an output value of 0, then −1, then +1, and plots the total loss each time. The plotted points trace a parabola. The best output value sits at the bottom of that parabola, where the derivative is zero. When lambda grows, the bottom of the parabola slides toward zero. That is regularization doing its job.

Step by step

  1. Choose a loss function. Regression uses half the squared residual. Classification uses the negative log likelihood.
  2. Write the objective for the new tree: the sum of the losses plus the ridge-style penalty on the output value.
  3. Replace the prediction inside the loss with the old prediction plus the new output value. Now the objective depends on one unknown.
  4. Put every residual in one leaf. Try a few output values by hand and plot the totals to see the shape.
  5. Replace each loss term with its second-order Taylor approximation. Plain gradient boost did this only for classification. XGBoost does it for both tasks.
  6. Drop the terms that do not contain the output value, then group the rest into one linear and one squared term.
  7. Take the derivative, set it to zero, and solve. This gives the general output value formula.
  8. Plug in the gradient and the Hessian of your loss. This gives the regression or the classification version.
  9. Multiply the simplified objective by −1 and substitute the optimal output value. The height of the flipped peak is the similarity score.

Formulas

Loss for regression
$$ L(y_i, p_i) = \tfrac{1}{2}\,(y_i - p_i)^2 $$

Symbols: \(y_i\) is the observed value of observation \(i\); \(p_i\) is the prediction for that same observation. What it tells you: each observation contributes half its squared residual, and the half is there only to make later derivatives tidy.

Loss for classification
$$ L(y_i, p_i) = -\big[\, y_i \log(p_i) + (1-y_i)\log(1-p_i) \,\big] $$

Symbols: \(y_i\) is the observed label, 0 or 1; \(p_i\) is the predicted probability between 0 and 1. What it tells you: this is the negative log likelihood, the same loss as in gradient boost for classification.

What XGBoost minimises
$$ \sum_{i=1}^{n} L\!\left(y_i,\; p_i^{0} + O_{value}\right) \; + \; \tfrac{1}{2}\lambda\, O_{value}^{2} $$

Step: each prediction becomes the old prediction plus the new output value, so the output value is the only unknown. Symbols: \(p_i^{0}\) is the previous prediction; \(O_{value}\) is the output value of the leaf; \(\lambda\) is the regularization parameter; \(n\) is the number of residuals in the leaf. What it tells you: the leaf must lower the loss, but a large output value costs extra.

Second-order Taylor approximation
$$ L\!\left(y_i,\, p_i^{0} + O_{value}\right) \approx L\!\left(y_i,\, p_i^{0}\right) + g_i\,O_{value} + \tfrac{1}{2}h_i\,O_{value}^{2} $$

Step: each loss is swapped for a parabola in the output value, because a parabola is easy to minimise. Symbols: \(L(y_i, p_i^{0})\) is the loss at the old prediction. \(g_i\) is the first derivative of the loss, called the gradient. \(h_i\) is the second derivative, called the Hessian.

Put the approximation into the objective
$$ \sum_{i=1}^{n}\Big[L\!\left(y_i, p_i^{0}\right) + g_i\,O_{value} + \tfrac{1}{2}h_i\,O_{value}^{2}\Big] + \tfrac{1}{2}\lambda\,O_{value}^{2} $$

Step: the approximation replaces every loss term in the sum, and the penalty is added back.

$$ \Big(\sum_{i=1}^{n} g_i\Big)\, O_{value} \; + \; \tfrac{1}{2}\Big(\sum_{i=1}^{n} h_i + \lambda\Big)\, O_{value}^{2} $$

Step: the \(L(y_i, p_i^{0})\) terms are dropped, because they have no output value and cannot move the minimum. The linear terms and the squared terms are then collected, so \(\lambda\) joins the squared term.

Set the derivative to zero
$$ \sum g_i +\Big(\sum h_i + \lambda\Big)\, O_{value} = 0 $$

Step: we take the derivative with respect to \(O_{value}\) and set it to zero, because the bottom of a parabola has zero slope. The exponent 2 comes down and cancels the one half.

$$ O_{value} = \frac{-\sum g_i}{\sum h_i + \lambda} $$

Step: we subtract \(\sum g_i\) from both sides, then divide by \(\sum h_i + \lambda\). What it tells you: this is the output value for any loss; only the derivatives change.

Output value for regression
$$ g_i = -(y_i - p_i), \quad h_i = 1 \;\;\Longrightarrow\;\; O_{value} = \frac{\sum (y_i - p_i)}{n + \lambda} $$

Step: we plug in the derivatives of the regression loss. The gradient is the negative residual, so its minus sign cancels the one in front. Symbols: \(y_i - p_i\) is the residual; each \(h_i = 1\), so the denominator is \(n + \lambda\).

Output value for classification
$$ g_i = -(y_i - p_i), \quad h_i = p_i\,(1-p_i) \;\;\Longrightarrow\;\; O_{value} = \frac{\sum (y_i - p_i)}{\sum p_i(1-p_i) + \lambda} $$

Step: we plug in the derivatives of log loss. The numerator is again the sum of residuals; only the denominator changes. Symbols: \(p_i\) is the previously predicted probability, not the log odds.

Similarity score
$$ -\Big(\sum g_i\Big)\, O_{value} - \tfrac{1}{2}\Big(\sum h_i + \lambda\Big)\, O_{value}^{2} $$

Step: we multiply the simplified objective by −1, so its lowest point becomes a highest point.

$$ = \frac{\left(\sum g_i\right)^{2}}{\sum h_i + \lambda} - \frac{1}{2}\cdot\frac{\left(\sum g_i\right)^{2}}{\sum h_i + \lambda} $$

Step: we substitute the optimal output value. In the first term two minus signs cancel; in the second, one \(\sum h_i + \lambda\) cancels.

$$ = \frac{1}{2}\cdot\frac{\left(\sum g_i\right)^{2}}{\sum h_i + \lambda} \quad\longrightarrow\quad \text{Similarity} = \frac{\left(\sum g_i\right)^{2}}{\sum h_i + \lambda} $$

Step: we add the two terms to get the peak height from the original manuscript. The software drops the one half. Similarity is only compared with other similarities, so scaling every score alike changes no decision.

Similarity for each task
$$ \frac{\left(\sum (y_i-p_i)\right)^{2}}{n + \lambda} \qquad\text{and}\qquad \frac{\left(\sum (y_i-p_i)\right)^{2}}{\sum p_i(1-p_i) + \lambda} $$

Symbols: the left formula is for regression, the right one for classification. What it tells you: these are exactly the similarity scores used in Parts 1 and 2, now with a derivation behind them.

Cover
$$ \text{Cover} = \sum_{i=1}^{n} h_i $$

Symbols: \(h_i\) is the Hessian of one residual. What it tells you: cover is the similarity denominator minus lambda, so for regression it is simply the count of residuals, and for classification it is the sum of \(p_i(1-p_i)\).

Worked example from the video

Example

Josh uses three regression observations, an initial prediction of 0.5, and \(\lambda = 0\). With lambda at zero the penalty disappears, so only the summed loss matters.

With an output value of 0 the prediction stays at 0.5, and the summed loss \(\tfrac{1}{2}\sum (y_i - p_i)^2\) is 104.4. With an output value of −1 the prediction drops to −0.5. That shrinks the first residual but enlarges the other two, and the total rises to 109.4. With an output value of +1 the prediction rises to 1.5, the last two residuals shrink, and the total falls to 102.4.

So +1 is the best of the three guesses. Plotting the whole function shows a parabola whose lowest point sits a little to the right of +1. Setting \(\lambda = 4\) pulls that lowest point back toward zero, and \(\lambda = 40\) pulls it almost onto zero. The output value formula \(\sum(y_i-p_i)/(n+\lambda)\) gives that same x-coordinate directly, without any guessing.

Common mistakes and subtle points

Watch out The original objective also contains \(\gamma T\), where \(T\) is the number of leaves and \(\gamma\) is a pruning penalty. Josh leaves it out on purpose. Pruning happens after the full tree is built, so that term never affects the output value or the similarity score.
Watch out Dropping the constant terms changes the value of the function, but not the location of its minimum. So the simplified expression is no longer equal to the loss. Only the optimal output value carries over.
Watch out The manuscript similarity carries a factor of one half, and the implementations drop it. Both give the same splits. Only compare similarity scores that come from the same convention.
Watch out For classification, the leaf output value lives in log odds, but the Hessian uses the previously predicted probability. Mixing the two scales is the easiest way to get the denominator wrong.

If they ask you in an interview

Why does XGBoost use a second-order Taylor approximation?
Some losses, like log loss, are hard to minimise directly. The approximation replaces each loss with a parabola in the output value. A parabola has a one-line solution, so XGBoost gets the optimal leaf value directly. Plain gradient boost used this trick only for classification; XGBoost uses it for both tasks.
What are G and H in the XGBoost formulas?
G is the first derivative of the loss with respect to the prediction, called the gradient. H is the second derivative, called the Hessian. For both losses in the video, G is the negative residual. H is one for regression and \(p(1-p)\) for classification.
What actually changes between regression and classification in XGBoost?
Only the loss function. Everything else is the same machinery. You write down the gradient and the Hessian of the loss. Then you drop them into the same output value formula and the same similarity formula.
How does lambda change the tree?
Lambda sits in the denominator of both the output value and the similarity score. A larger lambda pulls the output value toward zero, exactly like ridge regression shrinks coefficients. It also lowers similarity scores, and it lowers them most for leaves with few residuals. So lambda both softens the predictions and discourages small, noisy leaves.
What is cover, in derivative terms?
Cover is the similarity denominator without lambda, which means it is the sum of the Hessians in a leaf. For regression each Hessian is one, so cover is just the number of residuals in the leaf. For classification each Hessian is \(p(1-p)\), so cover depends on the previous probabilities in the leaf.

Recap in 30 seconds

  • XGBoost picks the leaf output value that minimises a loss function plus a ridge-style penalty on that value.
  • The prediction inside the loss is the old prediction plus the new output value, so there is one unknown.
  • A second-order Taylor approximation turns any loss into a parabola built from the gradient G and the Hessian H.
  • Setting the derivative to zero gives the output value as minus the sum of the G's over the sum of the H's plus lambda.
  • Flipping the simplified parabola with minus one and substituting that output value gives the similarity score.
  • Regression uses G equal to the negative residual and H equal to one, so the denominator is the residual count plus lambda.
  • Classification keeps the same G but uses H equal to p times one minus p, and cover is simply the sum of the Hessians.
