CatBoost Part 2: Building and Using Trees

▶ Watch on YouTube Also in: —

This video shows how CatBoost builds each tree, scores splits, and makes predictions. It also explains why CatBoost uses symmetric (oblivious) trees when the trees get larger.

In one breath

Before each tree, CatBoost shuffles the rows and applies ordered target encoding to the categorical columns. It then runs the rows down the tree one at a time, so a row's own residual never affects its own leaf output. Each threshold is scored by the cosine similarity of residuals and leaf outputs. Predictions are updated by adding the leaf outputs times a learning rate. Larger trees are symmetric, so every node on the same level asks the same question. This makes them weaker learners, and faster to use.

The main idea

The video uses a tiny five-row data set where "Favorite Color" predicts "Height". It assumes you know two ideas from earlier videos. Ordered target encoding turns each category into a number, using only the target values of earlier rows. The cosine similarity is a score that tells how closely two columns of numbers point the same way.

The key idea is the same one from Part 1. CatBoost treats the data as if it arrives one row at a time. When it calculates a row's leaf output, it uses only the rows that went down the tree before it. So the residual in a row is never part of the prediction for that same row.

This avoids leakage. Here, leakage means a row's target value has an effect on something calculated for that same row. The figure below shows the first stump (a tree with only one split) in the video, with the threshold Favorite Color < 0.04.

Step by step

  1. Shuffle and encode. Each time CatBoost makes a tree, it randomizes the rows. Then it applies ordered target encoding to every discrete column with more than two options. A column with only two options is simply replaced with 1s and 0s.
  2. Bin the target. Ordered target encoding needs a discrete target, but "Height" is continuous. So CatBoost puts the heights into bins. With so little data, the video uses two bins: the two smallest heights get bin 0 and the three larger heights get bin 1.
  3. Encode with bin numbers. The bin numbers replace "Height" for ordered target encoding. Then they are ignored until the next tree.
  4. Start at zero. CatBoost sets every prediction to 0. The first residuals (observed minus predicted) are just the heights. For row 1, the residual is 1.81 − 0 = 1.81.
  5. Find thresholds. Sort the encoded colors: 0.025, 0.05, 0.525. The halfway points give two candidate thresholds, 0.04 and 0.29. With lots of data, CatBoost limits the number of thresholds by putting close values in the same bin.
  6. Run rows down one at a time. The leaf outputs start at 0. Each row goes to a leaf, records the leaf's current output, and then the leaf output becomes the average of the residuals in it. The video builds a stump to keep it simple.
  7. Score the threshold. Compute the cosine similarity between the residuals and the recorded leaf outputs. Threshold 0.04 scores 0.71. Reset the leaves to 0, repeat for 0.29, and get 0.79. The higher score wins, so the root uses Favorite Color < 0.29. Larger trees score every split the same way.
  8. Update predictions. Add each row's leaf output, times a learning rate of 0.1, to its prediction. The learning rate is a small number that shrinks each tree's effect. Then compute new residuals.
  9. Build the next tree. Put back the original color names, shuffle the rows again, and reuse the same bin numbers for ordered target encoding. In the video's second tree there is only one threshold, 0.29. In practice CatBoost keeps adding trees, possibly hundreds, until the predictions are good.
  10. Predict new data. To encode a new "Blue", CatBoost uses all training rows with "Blue", not only earlier rows. Then it runs the row down every tree and adds the leaf outputs times 0.1.

When CatBoost builds larger trees, it builds symmetric (also called oblivious) decision trees. A symmetric tree uses the exact same threshold for every node on the same level.

CatBoost uses symmetric trees for two reasons. First, they are worse at making predictions. Gradient boosting combines many weak learners, and a symmetric tree is just a weaker learner. Second, they predict faster. In a normal tree, if Favorite Color < 0.87 you ask about "Age", otherwise about "Movie". Keeping track of which question comes next takes time. In a symmetric tree every path asks the same questions. So all of them can be asked in a single vector operation, one fast calculation for the whole tree.

Formulas

Split score: cosine similarity
$$ \text{score} = \frac{\sum_{i} A_i B_i}{\sqrt{\sum_{i} A_i^2}\;\sqrt{\sum_{i} B_i^2}} $$

Symbols: \(A_i\) is the residual for row \(i\). \(B_i\) is the leaf output recorded for row \(i\) before its own residual joined the leaf. The sums run over the rows. What it tells you: a higher score means the leaf outputs line up better with the residuals, so the threshold makes better predictions.

Prediction update
$$ \hat{y}_{\text{new}} = \hat{y}_{\text{old}} + \eta \times \text{leaf output} $$

Symbols: \(\hat{y}_{\text{old}}\) is the current prediction for a row. \(\eta\) is the learning rate, 0.1 in the video. The leaf output is the value recorded for that row in the new tree. What it tells you: each tree moves the predictions a small step toward the observed values.

Final prediction for new data
$$ \hat{y} = \sum_{t=1}^{T} \eta \times \text{leaf output}_t $$

Symbols: \(T\) is the number of trees. \(\text{leaf output}_t\) is the output of the leaf the new row lands in for tree \(t\). The sum has no starting value because CatBoost starts every prediction at 0. What it tells you: a prediction is the scaled sum of one leaf from each tree.

Worked example from the video

Example

Threshold 0.04. The residuals are A = (1.81, 1.56, 1.77, 1.31, 1.64). Running the rows down one at a time gives recorded leaf outputs B = (0, 1.81, 0, 1.69, 1.56), as in the first figure.

Top: \(1.56(1.81) + 1.31(1.69) + 1.64(1.56) = 2.82 + 2.21 + 2.56 = 7.60\). Rows 1 and 3 add nothing because their B is 0.

Bottom: \(\sqrt{13.25} \times \sqrt{8.57} = 3.64 \times 2.93 = 10.65\).

Score: \(7.60 / 10.65 = 0.71\). Doing the same for threshold 0.29 gives 0.79, so CatBoost picks Favorite Color < 0.29 for the root.

Update. For row 1, the new prediction is \(0 + 0.1 \times 0 = 0\). The predictions after one tree are not very good, but they are better than predicting 0 for everyone.

New data. After two trees, a new person who likes "Blue" is encoded with all the "Blue" training rows. Adding the two leaf outputs times 0.1 gives a prediction of 0.3. Josh admits this is a terrible prediction, but it comes from only two trees.

Common mistakes and subtle points

Watch out The leaf output a row records is the value from before its own residual joined the leaf. This is how CatBoost keeps a row's residual out of its own prediction.
Watch out Leaf outputs of 0 are just starting values, not based on any data. The video includes them only because it has five rows. With lots of data, CatBoost ignores the first bunch of rows when it calculates the cosine similarity.
Watch out A continuous target must be binned before ordered target encoding. With more data there can be more than two bins, and then CatBoost uses a slightly different encoding equation, documented on the CatBoost website.

If they ask you in an interview

How does CatBoost avoid leakage when it builds trees?
It treats the data as if the rows arrive one at a time. Each row records the leaf output that existed before its own residual was added to the leaf. So a row's residual never helps calculate that row's prediction, just as its target never helps encode its own category.
How does CatBoost choose a split threshold?
For each candidate threshold, it runs the rows down the tree one at a time and records the leaf outputs. Then it computes the cosine similarity between the residuals and those leaf outputs. The threshold with the highest cosine similarity is used.
What is a symmetric or oblivious tree, and why does CatBoost use it?
It is a tree where every node on the same level uses the exact same threshold. CatBoost uses them because they are weaker learners, which suits gradient boosting, and because they predict fast. Every path asks the same questions, so all questions can be asked in one vector operation.
How does CatBoost do target encoding when the target is continuous?
It first puts the continuous target values into discrete bins. Then it uses the bin numbers as the target for ordered target encoding. The same bin numbers are reused when it encodes the data for later trees.

Recap in 30 seconds

  • Before each tree, CatBoost shuffles the rows and applies ordered target encoding.
  • A continuous target is put into bins so it can be used for the encoding.
  • Predictions start at 0, so the first residuals equal the observed values.
  • Rows go down the tree one at a time, and each row records the leaf output from before its own residual joined.
  • Each threshold is scored by the cosine similarity of residuals and recorded leaf outputs; the highest score wins.
  • Predictions are updated by adding leaf outputs times a learning rate, such as 0.1.
  • Larger CatBoost trees are symmetric, which makes them weaker learners and faster to use.
