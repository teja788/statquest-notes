Recurrent Neural Networks (RNNs)

▶ Watch on YouTube Also in: Neural Networks / Deep Learning (video 15)

This video shows how a recurrent neural network uses a feedback loop to make predictions from sequential data of any length. It also explains why basic RNNs are hard to train, which is the reason fancier models like LSTMs exist.

In one breath

Stock prices come as sequences, and different companies have different amounts of history. Earlier networks in the series took a fixed number of inputs, so they cannot handle this. An RNN adds a feedback loop that lets earlier values influence the prediction made with later values. Unrolling the loop makes one copy of the network per input, and all copies share the same weights and biases. The catch is the vanishing / exploding gradient problem. Gradients are the derivatives that training uses to update each weight. The feedback weight is multiplied in once per copy, so long sequences make gradients huge or tiny.

The main idea

Josh wants a network that predicts tomorrow's stock price. One company may have nine days of data and another only five. So the network must be flexible in how much sequential data it uses. Sequential data means values that come in a fixed order, like prices over time.

The networks seen earlier in the series were rigid. One took exactly one input. Another took exactly two inputs. The image classifier took exactly a 6 by 6 pixel image. None of them can take nine values for one company and five for another.

An RNN has the usual weights, biases, layers and activation functions. The big difference is a feedback loop. The output of the activation function is sent back and added into the sum for the next input. This way, yesterday's value can influence the prediction made with today's value.

The loop is easier to see if you unroll it. Unrolling means making one copy of the network for each input value. Instead of pointing the loop back at itself, each copy points to the sum in the next copy. Only the last output is the prediction we want.

Step by step

  1. Scale the prices so the network sees simple numbers: low is 0, medium is 0.5 and high is 1.
  2. Put yesterday's value into the input and do the math as in any neural network. Call the activation function's output \(y_1\).
  3. \(y_1\) could go to the output, which would predict today's price. We already know today's price, so we ignore that output.
  4. Instead, \(y_1\) goes around the feedback loop. The sum adds \(y_1 \times w_2\) to today's value times \(w_1\). Now both days influence the prediction.
  5. Unroll the loop into one copy per input. The last copy's output is the prediction for tomorrow.
  6. For three days of data, unroll three times. Plug in the day before yesterday, then yesterday, then today, always from oldest to newest.
  7. All copies share the same weights and biases. Unrolling more never increases the number of parameters to train.
  8. The weakness: the more you unroll, the harder the network is to train. This is the vanishing / exploding gradient problem, which comes from \(w_2\) being copied with every unroll.

Formulas

The sum inside one copy
$$ s_t = x_t\, w_1 + y_{t-1}\, w_2 + b_1, \qquad y_t = \text{activation}(s_t) $$

Symbols: \(x_t\) is the input value for day \(t\). \(w_1\) is the weight on the input. \(y_{t-1}\) is the activation output from the previous copy, which is the feedback. \(w_2\) is the weight on the feedback loop. \(b_1\) is the bias. \(s_t\) is the sum, and \(y_t\) is the activation function's output. The first copy has no previous day, so it has no feedback term. What it tells you: each step mixes the new value with what came before, using the same \(w_1\), \(w_2\) and \(b_1\) every time.

How far the first input is scaled
$$ \text{input}_1 \times w_2^{\,n} $$

Symbols: \(\text{input}_1\) is the first (oldest) input value. \(w_2\) is the feedback weight. \(n\) is the number of times the network is unrolled. What it tells you: the first input is multiplied by \(w_2\) once per unroll before it reaches the last copy, so \(w_2\) gets raised to a power.

With \(w_2 = 2\) and four unrolls: \(2^4 = 16\), so the first input is amplified 16 times.

With 50 days of data: \(2^{50} \approx 1.1 \times 10^{15}\), a huge number. This is the exploding gradient.

With \(w_2 = 0.5\) and 50 days: \(0.5^{50} \approx 8.9 \times 10^{-16}\), super close to zero. This is the vanishing gradient.

Worked example from the video

Example

In StatLand, stock prices follow four simple patterns. Josh scales them to low = 0, medium = 0.5 and high = 1.

  • Low, then low (0, 0): tomorrow stays low.
  • Low, then medium (0, 0.5): tomorrow goes even higher.
  • High, then medium (1, 0.5): tomorrow goes even lower.
  • High, then high (1, 1): tomorrow stays high.

For the first case, Josh puts yesterday's 0 into the first copy and follows the link to the second copy's sum. Then he puts today's 0 into the second input. The final output is 0, which matches the observed pattern. The other three cases also give the correct value for tomorrow.

Then the trouble. Set \(w_2 = 2\) and unroll four times: input 1 is multiplied by \(2 \times 2 \times 2 \times 2 = 16\). With 50 days, which is not much data, it becomes \(2^{50}\). That huge number finds its way into the gradients. Gradient descent then takes large steps and bounces around instead of finding the best parameters. Set \(w_2 = 0.5\) instead, and \(0.5^{50}\) is nearly zero. Now the steps are too small, and training hits the maximum number of steps before finding the best value.

Common mistakes and subtle points

Watch out Unrolling does not add parameters. Every copy uses the same \(w_1\), \(b_1\), \(w_2\) and the other weights and biases. A network unrolled 50 times trains exactly as many parameters as one unrolled twice.
Watch out The outputs from the earlier copies are predictions for days we already know. They are ignored. Only the last copy's output is the prediction for tomorrow.
Watch out Inputs go in order, from the oldest value to the newest. Order matters because each value is carried forward through \(w_2\).
Watch out Keeping \(w_2\) below 1 does not fix the problem. It only swaps an exploding gradient for a vanishing one. That is why basic RNNs are seen as a stepping stone to LSTMs and Transformers.

If they ask you in an interview

Why do we need recurrent neural networks?
Many problems have sequential data of different lengths, like stock prices where one company has nine days of history and another has five. A regular network takes a fixed number of inputs. An RNN uses a feedback loop, so the same network can take as many sequential values as we have.
What does it mean to unroll an RNN?
We make one copy of the network for each input value. Instead of the loop feeding back into itself, each copy feeds its activation output into the sum of the next copy. We put values in from oldest to newest, and the last output is the prediction.
Does a longer sequence mean more parameters?
No. The weights and biases are shared across every copy. So no matter how many times we unroll the network, the number of weights and biases to train stays the same.
Explain the vanishing and exploding gradient problem.
The feedback weight is multiplied in once per unroll, so the first input gets scaled by that weight raised to the number of unrolls. If the weight is above 1, say 2, then 2 to the 50th is huge, and gradient descent takes giant steps and bounces around. If it is below 1, say 0.5, then 0.5 to the 50th is nearly zero, and the steps are so small that we run out of steps before reaching the best value.
Why are basic RNNs not used very often?
The more you unroll them, the harder they are to train, because of vanishing and exploding gradients. Restricting the feedback weight does not help, since it just moves you from one problem to the other. Long Short-Term Memory networks are a popular solution.

Recap in 30 seconds

  • RNNs handle sequential data of different lengths, which fixed-input networks cannot.
  • A feedback loop adds the previous activation output, times \(w_2\), into the next sum.
  • Unrolling makes one copy per input, fed from oldest to newest, and the last output is the prediction.
  • All copies share the same weights and biases, so longer sequences do not add parameters.
  • In the StatLand example, the RNN correctly predicts tomorrow's price for all four patterns.
  • The first input is scaled by \(w_2\) raised to the number of unrolls.
  • With \(w_2\) above 1 gradients explode; with \(w_2\) below 1 they vanish, and both make training hard.
  • LSTMs, covered next, are a popular fix.
