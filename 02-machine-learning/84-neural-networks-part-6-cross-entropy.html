Neural Networks Part 6: Cross Entropy

▶ Watch on YouTube Also in: Neural Networks / Deep Learning (video 12)

This video shows how cross entropy measures how well a neural network fits the data when its outputs are probabilities. It also shows why cross entropy trains better than squared residuals when a prediction is very bad.

In one breath

When a network has several outputs, SoftMax turns them into predicted probabilities between 0 and 1. For each training row, cross entropy is minus the natural log of the predicted probability for the observed class. We add these values over all rows to get the total error, and backpropagation tries to make it small. Cross entropy grows very large for bad predictions, so its slope is steep there. A steep slope gives backpropagation a large step toward a better prediction.

The main idea

A network with one output can give any value. For that case, we usually measure the fit with the sum of the squared residuals. A residual is the observed value minus the predicted value.

A network with several outputs is different. Argmax makes the outputs easy to read, but its derivative is useless for backpropagation. So for training we use SoftMax, which gives predicted probabilities between 0 and 1. When the output is limited to 0 to 1, we often use cross entropy to measure the fit.

For one row of data, cross entropy looks only at the predicted probability for the class we actually observed. If that probability is \(p\), the loss is \(-\log(p)\). The loss is a measure of how bad the prediction is. The figure below compares this curve with the squared residual.

Step by step

  1. Start with a small training set of petal and sepal widths. Each row has a known species: setosa, versicolor, or virginica.
  2. Run the first row through the network, then run the raw output values through SoftMax. This gives one predicted probability per species.
  3. The first row is setosa, so take the predicted probability for setosa, 0.57. Its cross entropy is \(-\log_e(0.57) = 0.56\).
  4. Do the same for the second row, which is virginica. Its predicted probability is 0.58, and the cross entropy is 0.54.
  5. The third row is versicolor. Its predicted probability is 0.52, and the cross entropy is 0.65.
  6. Add the three cross entropy values to get the total error, 1.75. Backpropagation then adjusts the weights and biases to make this total smaller.
  7. Ask why not use squared residuals instead. Compare the two loss curves and their slopes for a bad prediction, as in the figure above.

Formulas

General cross entropy
$$ \text{Cross Entropy} = -\sum_{i=1}^{M} \text{Observed}_i \times \log(\text{Predicted}_i) $$

Symbols: \(M\) is the number of output classes; here \(M = 3\) (setosa, versicolor, virginica). \(\text{Observed}_i\) is the observed probability that the row belongs to class \(i\); it is 1 for the true class and 0 for the others. \(\text{Predicted}_i\) is the SoftMax output for class \(i\). \(\log\) is the natural log, base \(e\). What it tells you: it is the full form, with one term for each class.

Simplified form for neural networks
$$ \begin{aligned} \text{CE} &= -\big[1\cdot\log(p_{\text{setosa}}) + 0\cdot\log(p_{\text{versicolor}}) + 0\cdot\log(p_{\text{virginica}})\big] \\ &= -\log(p_{\text{observed}}) \end{aligned} $$

Symbols: \(p_{\text{observed}}\) is the predicted probability for the class the row really belongs to. What it tells you: the observed probabilities are 1 or 0, so the terms for the other classes go away. Only one log is left.

Total error
$$ \text{Total error} = \sum_{\text{rows}} -\log(p_{\text{observed}}) $$

Symbols: the sum runs over every row of the training data. What it tells you: this is the number backpropagation tries to minimize.

Squared residual (for comparison)
$$ \text{SR} = (1 - p_{\text{observed}})^2 $$

Symbols: 1 is the observed probability for the true class; \(1 - p_{\text{observed}}\) is the residual. What it tells you: it can never be larger than 1, so it punishes a very bad prediction much less than cross entropy does.

Worked example from the video

Example

Three training rows go through the network and SoftMax. For each row we take the predicted probability of the observed species.

Setosa: \(-\log(0.57) = 0.56\).
Virginica: \(-\log(0.58) = 0.54\).
Versicolor: \(-\log(0.52) = 0.65\).

Total error: \(0.56 + 0.54 + 0.65 = 1.75\).

For comparison, the residual for the setosa row is \(1 - 0.57 = 0.43\). We could square it and add such values to get the sum of the squared residuals. The video explains why cross entropy is used instead.

Common mistakes and subtle points

Watch out Plug in the predicted probability for the observed class, not the largest probability. For the virginica row we use 0.58 because the row is virginica.
Watch out The short form \(-\log(p)\) may look different from the cross entropy you saw before. It is the same formula; the observed probabilities of 0 remove all the other terms.
Watch out Argmax is fine for reading the output, but not for training. Its derivative is useless for backpropagation, so training uses SoftMax and cross entropy.
Watch out The log is the natural log, base \(e\). Using base 10 gives different numbers from the video.

If they ask you in an interview

What is cross entropy for a neural network classifier?
For each training row, it is minus the natural log of the predicted probability for the true class. The probabilities come from SoftMax. We add these values over all rows to get the total error, and backpropagation minimizes it.
Why does the formula reduce to one term?
The general formula sums over all classes, with each log weighted by the observed probability. The observed probability is 1 for the true class and 0 for the others. So every term except the true class drops out.
Why use cross entropy instead of squared residuals with SoftMax outputs?
As the predicted probability for the true class goes toward 0, cross entropy becomes very large. The squared residual stays at 1 or below. The step size in backpropagation depends partly on the derivative. So cross entropy gives a steeper slope and a larger step after a very bad prediction.
Why not train with argmax?
Argmax is good for reading the final answer, but its derivative is useless for backpropagation. SoftMax gives smooth probabilities between 0 and 1 that we can train with, and cross entropy measures their fit.

Recap in 30 seconds

  • With one unrestricted output, we usually use the sum of the squared residuals.
  • With several outputs, SoftMax gives predicted probabilities between 0 and 1.
  • For each row, cross entropy is \(-\log(p)\) for the predicted probability of the observed class.
  • The general formula collapses to one term because the observed probabilities are 1 and 0.
  • In the video, the three rows give 0.56, 0.54, and 0.65, so the total error is 1.75.
  • Cross entropy grows very large for bad predictions, but the squared residual never passes 1.
  • The steep slope of cross entropy gives backpropagation larger steps after bad predictions.
