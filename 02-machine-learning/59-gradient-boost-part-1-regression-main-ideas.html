Gradient Boost Part 1 (of 4): Regression Main Ideas

▶ Watch on YouTube

This video shows how Gradient Boost predicts a continuous value, like weight, by adding one small tree at a time. It is the first of four parts, and it gives the intuition that the later parts build on.

In one breath

Gradient Boost starts with a single leaf that holds the average of the target. It then measures how wrong that guess is for each person. Those errors are called pseudo residuals. Gradient Boost fits a small tree to predict the pseudo residuals, shrinks that tree with a learning rate, and adds it to the prediction. It repeats this until you reach the tree limit or the residuals stop shrinking.

The main idea

Josh uses a small table of six people. For each person we know height, favorite color, gender, and weight. We want to predict weight, which is a continuous number, so this is regression. Note that Gradient Boost for regression is not linear regression, even though the two are related.

Josh first compares Gradient Boost with AdaBoost, because they share a shape. AdaBoost builds a stump, which is a tree with one split. It then builds the next stump from the errors of the previous stump. Each stump gets its own amount of say, so stronger stumps count more.

Gradient Boost changes three things. It starts with a single leaf, not a tree. That leaf is the average weight, and it is the first guess for everybody. After that it builds trees that are bigger than stumps, but still limited in size. In this simple example the trees may have up to four leaves. In real work people usually allow 8 to 32 leaves.

The third change is the scaling. AdaBoost scales each stump by its own amount of say. Gradient Boost scales every tree by the same small number, called the learning rate. So every tree moves the prediction a small step in the right direction.

Step by step

  1. Take the average of the observed weights. Here it is 71.2 kg. This single leaf is the first prediction for every person.
  2. Compute the pseudo residual for each person: observed weight minus 71.2. For the person who weighs 88 kg, the residual is 16.8.
  3. Build a tree that uses height, favorite color, and gender to predict those residuals. Limit it to four leaves in this example.
  4. Because there are fewer leaves than people, some rows land in the same leaf. Replace those residuals with their average, so each leaf holds one number.
  5. Make a new prediction. Start at 71.2, run the row down the tree, and add the leaf value scaled by the learning rate 0.1. That gives 72.9 kg.
  6. Recompute the pseudo residuals against this new prediction. For the 88 kg person the residual falls from 16.8 to 15.1.
  7. Build the next tree on the new residuals and add it, also scaled by 0.1. Keep going until you hit the tree limit, or until extra trees stop shrinking the residuals.

Formulas

Initial leaf
$$ F_0(x) = \frac{1}{n}\sum_{i=1}^{n} y_i = 71.2 $$

Symbols: \(F_0(x)\) is the first prediction for any row \(x\). \(y_i\) is the observed weight of person \(i\). \(n\) is the number of people, here six. What it tells you: before any tree exists, the best flat guess for a continuous target is its average.

Pseudo residual
$$ r_{i,m} = y_i - F_{m-1}(x_i) $$

Symbols: \(r_{i,m}\) is the pseudo residual of person \(i\) before tree \(m\). \(y_i\) is the observed weight. \(F_{m-1}(x_i)\) is the prediction made by everything built so far. What it tells you: the residual is the part of the answer the model still misses, and it becomes the target for the next tree.

Adding one scaled tree
$$ F_m(x) = F_{m-1}(x) + \nu \, \gamma_m(x) $$

Symbols: \(F_m(x)\) is the prediction after \(m\) trees. \(\nu\) is the learning rate, a number between 0 and 1, here 0.1. \(\gamma_m(x)\) is the leaf value that tree \(m\) gives to row \(x\). What it tells you: each tree corrects the prediction, but only by a fraction \(\nu\) of what it wants to.

The finished model
$$ F_M(x) = F_0(x) + \nu \sum_{m=1}^{M} \gamma_m(x) $$

Symbols: \(F_M(x)\) is the final prediction. \(M\) is the total number of trees. The other symbols are as above. What it tells you: a Gradient Boost model is one average plus a chain of small, equally scaled tree corrections.

Worked example from the video

Example

The six weights average to 71.2 kg, so the initial leaf predicts 71.2 for everyone. The first person actually weighs 88 kg, so their pseudo residual is \(88 - 71.2 = 16.8\).

The first tree sends this person to a leaf that holds 16.8. Without scaling the prediction would be \(71.2 + 16.8 = 88\), exactly right. Josh warns that this is bad news: the model fits the training data too well, so bias is low but variance is probably very high.

With the learning rate set to 0.1 the prediction becomes \(71.2 + 0.1 \times 16.8 = 72.9\). The new residual is \(88 - 72.9 = 15.1\), smaller than 16.8.

The second tree is built on these new residuals and sends this person to a leaf holding 15.1. The prediction is now \(71.2 + 0.1 \times 16.8 + 0.1 \times 15.1 = 74.4\). The residual falls again, to \(88 - 74.4 = 13.6\).

After the chain of trees is finished, a new person is scored the same way: start at the initial leaf, then add each tree's leaf value times 0.1. In the video that new person is predicted to weigh 70 kg.

Common mistakes and subtle points

Watch out Gradient Boost for regression is not linear regression. Josh says the two methods are related, but they are different. Do not confuse them.
Watch out The trees predict residuals, never the weights themselves. Only the initial leaf carries the weight scale. If you forget the initial leaf when scoring, every prediction will be far too small.
Watch out Do not drop the learning rate to save time. Without it, one tree can reproduce the observed value exactly, which is overfitting. Jerome Friedman found that many small steps give better predictions on test data.

If they ask you in an interview

How does Gradient Boost differ from AdaBoost?
Both build models in sequence, each one fixing the errors of the last. AdaBoost starts with a stump, reweights the samples, and gives each stump its own amount of say. Gradient Boost starts with a single leaf holding the average, fits fixed-size trees to the residuals, and scales every tree by the same learning rate.
Why do the trees predict residuals instead of the target?
The residual is the part of the target the current model still gets wrong. Fitting a tree to it tells us exactly where to move each prediction and by how much. Adding that correction to the running prediction pushes the model closer to the observed values, one step at a time.
What does the learning rate actually do?
It shrinks the contribution of every tree, usually to a value like 0.1. Without it, a single tree can match the training values exactly, which means low bias and very high variance. With it, each tree takes a small step in the right direction. Jerome Friedman found that many small steps predict test data better.
Why is the tree size limited, and what size is typical?
Gradient Boost builds fixed-size trees, which are usually larger than stumps but still restricted. With fewer leaves than rows, some rows share a leaf, and the leaf holds their average residual. In practice people allow 8 to 32 leaves. The video uses four leaves only to keep the example small.
How do you score a new person once training is done?
Start with the initial leaf, the average of the training target. Run the new row down each tree in order and collect its leaf value. Multiply every leaf value by the learning rate and add them all to the initial leaf. That sum is the prediction.

Recap in 30 seconds

  • Gradient Boost for regression starts with one leaf that holds the average of the target, here 71.2 kg.
  • It then computes pseudo residuals, which are the observed values minus the current prediction.
  • A fixed-size tree is fitted to those residuals, using the ordinary feature columns to split.
  • Leaves that hold several rows store the average of their residuals.
  • The tree's output is multiplied by a learning rate, such as 0.1, and added to the prediction.
  • Every tree is scaled by the same learning rate, which is the main difference from AdaBoost.
  • The process repeats until you reach the tree limit or extra trees stop shrinking the residuals.
  • Part 2 works through the maths and proves that this simple recipe is correct.
