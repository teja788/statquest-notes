CatBoost Part 1: Ordered Target Encoding

▶ Watch on YouTube Also in: —

This video shows how CatBoost turns a categorical feature into numbers without leakage. The trick is to encode each row using only the rows that came before it.

In one breath

Basic target encoding uses each row's own target to encode that same row, and this causes leakage. CatBoost avoids it by reading the rows one at a time, in order. Each row is encoded with a simple formula that uses only earlier rows with the same category, plus a prior of 0.05. Because the row order changes the result, the method is called ordered target encoding. When you classify new data, CatBoost uses the whole training set to encode it.

The main idea

CatBoost is a machine learning method that is very similar to gradient boost and XGBoost at a basic level. Its name is short for "categorical boosting". This is because the way it handles categorical features (features with named options, like colors) is central to the method.

The video uses the Troll 2 data from the target encoding video. We want to use favorite color and height to predict if someone loves Troll 2. The problem is how to turn the color names into numbers.

In basic target encoding, each row's target value (the thing we want to predict) changes that same row's encoded color. This is leakage: the model sees the answer while it learns. Leakage gives models that work well on training data but not so well on testing data.

CatBoost treats the rows as if they arrive one after another. When it encodes a row, it acts as if the earlier rows are all the data it has seen so far. It ignores the current row and every later row.

Step by step

  1. See the leakage in basic target encoding. Each row's own target changes its encoded value. Josh earlier described k-fold target encoding, which splits the data into k groups to reduce this.
  2. See the leakage case from the CatBoost paper. Suppose everyone's favorite color is blue. We use leave-one-out target encoding, which encodes each row with every row except itself. Then people who love Troll 2 all get 0.33, and people who do not all get 0.5.
  3. Notice the perfect split. Any tree that first splits on "favorite color < 0.42" now classifies every training row correctly. The encoded feature carries the answer, so this is leakage.
  4. Read the rows in order. CatBoost treats each row as if it arrives one at a time. It encodes a row using only the rows before it.
  5. Use the CatBoost formula. It adds a prior of 0.05 to the option count, and divides by the number of earlier matching rows plus one.
  6. Encode new data with everything. After the model is built, the whole training set is used to target encode new data you want to classify.

Formulas

The CatBoost formula differs from basic target encoding in two ways. It uses a defined prior (a guess) instead of the overall mean. It also simplifies the denominator: it adds one to the row count instead of adding a weight.

CatBoost ordered target encoding
$$ \text{encoded value} = \frac{\text{OptionCount} + \text{Prior}}{n + 1} $$

Symbols: OptionCount is the number of earlier rows that have this same category and also have target 1 (here, love Troll 2). Prior is a fixed guess; in the examples Josh saw it was 0.05. \(n\) is the number of earlier rows that have this same category. The \(+1\) keeps the denominator above zero. What it tells you: a category seen for the first time gets the prior, and the value then moves toward the share of earlier matching rows that had target 1.

Worked example from the video

Example

Row 1, blue. No data came before it. So OptionCount = 0 and \(n = 0\). The value is \((0 + 0.05)/(0 + 1) = 0.05\).

Rows 2 and 3, red and green. No earlier row has red or green. Both get 0.05 in the same way.

Row 4, blue. We saw blue once before, in row 1, and that person loved Troll 2. So OptionCount = 1 and \(n = 1\). The value is \((1 + 0.05)/(1 + 1) = 0.525\).

Row 5, second green. The one earlier green person loved Troll 2, so the value is also 0.525.

Row 6, third green. Both earlier green people loved Troll 2. So OptionCount = 2 and \(n = 2\). The value is \((2 + 0.05)/(2 + 1) = 0.683\).

Row 7, third blue. Only one of the two earlier blue people loved Troll 2. So OptionCount = 1 and \(n = 2\). The value is \((1 + 0.05)/(2 + 1) = 0.35\).

Common mistakes and subtle points

Watch out The same color can get different numbers in different rows. Blue becomes 0.05, then 0.525, then 0.35. This is expected, because each row sees a different amount of earlier data.
Watch out The order of the rows changes the encoding. That is the reason for the name "ordered" target encoding.
Watch out The ordered method is for training only. New data is encoded with the entire training set.
Watch out Josh thinks the paper's one-category example is a little silly. Standard practice turns a feature with one or two options into zeros and ones, so blue would just become 0. He still notes that CatBoost works, and works well.

If they ask you in an interview

What is ordered target encoding in CatBoost?
CatBoost treats the training rows as if they arrive one at a time. Each row's category is encoded using only the earlier rows with the same category. The formula is option count plus a prior, divided by n plus one. Because the result depends on row order, it is called ordered target encoding.
Why does basic target encoding cause leakage?
Each row's own target value is used to encode that same row. So the feature partly contains the answer. The model then does well on training data but worse on testing data.
What happens the first time a category appears?
No earlier rows have that category, so the option count and n are both zero. The value is just the prior divided by one. In the video's example, that is 0.05.
How does CatBoost encode new data at prediction time?
After the model is trained, it uses the whole training data set to target encode the new rows. The one-row-at-a-time order is only used while training.

Recap in 30 seconds

  • CatBoost stands for categorical boosting and is close to gradient boost and XGBoost.
  • Basic target encoding leaks because a row's target encodes that same row.
  • CatBoost encodes each row using only the earlier rows with the same category.
  • The formula is (OptionCount + Prior) / (n + 1), with a prior of 0.05 in the examples.
  • In the example, blue goes 0.05, 0.525, 0.35 and green goes 0.05, 0.525, 0.683.
  • Row order changes the values, so the method is called ordered target encoding.
  • New data is encoded with the whole training set.
