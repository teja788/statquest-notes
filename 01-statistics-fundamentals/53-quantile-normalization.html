Quantile Normalization

▶ Watch on YouTube

Quantile normalization forces several samples to share exactly the same distribution of values. It removes technical differences between experiments, so you can compare samples fairly.

In one breath

Josh uses microarray data, where each measurement is the activity of one gene in one sample. A brighter light bulb in one experiment makes every value in that sample larger, which is a technical artifact and not biology. Quantile normalization sorts the values inside each sample, averages across samples at each rank, and gives every sample that same set of averages. Each gene keeps its position within its own sample, but all samples end up with identical quantiles.

The main idea

A microarray measures how active genes are by reading the intensity of different colours of light. Josh's plot shows one dot per gene, with the intensity on the y-axis. The three samples have three different mean values, which suggests the overall brightness differed between experiments.

The fix is simple. Take the highest value in every sample and replace all of them by their mean. Do the same for the second highest, then the third, and so on down to the lowest. Nothing else changes. Inside a sample, the gene that was highest is still highest.

Step by step

  1. Keep the raw data on the left and build the normalized data on the right, so you can see what moved.
  2. Look at the most highly expressed gene in each sample. These are different genes in different samples, and that is fine.
  3. Calculate the mean of those highest values, then write that mean into the new plot. That mean is now the normalized value for the highest gene in every sample.
  4. Repeat with the second highest gene in each sample, then the third, and so on, until you reach the least expressed gene.
  5. Read off the result. Every sample now has the same set of values, and every gene keeps the position it had inside its own sample.

Formulas

Josh does not write algebra in the video, but the two lines below say exactly what he draws.

Reference value for rank k
$$ \bar q_{(k)} \;=\; \frac{1}{n}\sum_{j=1}^{n} x_{(k),j} $$

Symbols: \(n\) is the number of samples; \(j\) counts the samples; \(x_{(k),j}\) is the \(k\)-th largest value inside sample \(j\); \(\bar q_{(k)}\) is the mean of those values across the samples. What it tells you: each rank position gets one shared number, obtained by averaging across samples at that position.

Normalized value of a gene
$$ z_{i,j} \;=\; \bar q_{(r_{i,j})} $$

Symbols: \(i\) is the gene; \(j\) is the sample; \(r_{i,j}\) is the rank of gene \(i\) inside sample \(j\), counting from the highest; \(z_{i,j}\) is the normalized value. What it tells you: a gene's new value depends only on its rank in its own sample, so the ranks survive and the raw magnitudes do not.

Every sample now has the same mean and the same quartiles. Red is still the lowest gene in sample 1, green is still the lowest in sample 2, and red is still the lowest in sample 3, exactly as Josh points out.

Common mistakes and subtle points

Watch out The genes averaged together are usually different genes. At the top rank you may average the orange gene from one sample with the blue gene from another. You are averaging positions, not biology.
Watch out The method forces every sample to have the same distribution. That is helpful when the difference is a brighter light bulb. It is harmful when a real, global biological shift exists, because the method will erase it.
Watch out Only the ranks inside a sample survive. Two values that were far apart can end up close together, so the gaps change.
Watch out The name describes the result. Josh calls it quantile normalization because the normalized samples end up with identical quartiles.

If they ask you in an interview

What does quantile normalization actually do?
It makes several samples share one common distribution. You sort the values inside each sample, take the mean across samples at every rank position, and hand that mean back to whichever gene held that rank. Afterwards all samples have identical quantiles, but the ordering inside each sample is untouched.
Why would you need it on microarray data?
A microarray reads gene activity as light intensity. If one experiment used a brighter light source, every measurement in that sample is inflated. That is a technical difference with no biological meaning, so we normalize it away before comparing samples.
When is quantile normalization the wrong choice?
It is wrong when the samples really should have different distributions. If a treatment raises activity across the board, the method removes that real effect too. Then I would check the sample distributions first, and use a method anchored on control features instead.

Recap in 30 seconds

  • Different experiments can differ for purely technical reasons, such as a brighter light bulb.
  • Different sample means in the raw plot are the clue that normalization is needed.
  • Quantile normalization works rank by rank, starting with the most highly expressed gene in each sample.
  • At each rank you take the mean across samples and use it as the new value for that rank.
  • Every sample ends up with exactly the same set of values, so the quartiles match.
  • The order of the genes inside each sample is preserved, so the lowest gene stays the lowest gene.
  • The idea is not limited to microarrays and can be applied to other data with the same problem.
