Multiple Regression in R, Step-by-Step

▶ Watch on YouTube Picks up from the StatQuest on multiple regression

Josh runs the same mice through R twice: a simple regression with one predictor, then a multiple regression with two.

In one breath

Step one is always to plot the data. Step two is lm(), and the only change for multiple regression is a plus sign in the formula. Read plain R-squared for one predictor and adjusted R-squared for several. Then read the p-value on each coefficient row, because it says whether that term is worth keeping beside the others.

The main idea

Simple regression fits a straight line through a cloud of points. Multiple regression adds a second predictor, so the fit becomes a flat plane. In R that difference is one plus sign.

The real work is deciding whether the second predictor earns its place. Both weight and tail length are related to size, so both are reasonable predictors. But weight and tail are also related to each other, so they carry similar information. We may not need both.

Step by step

  1. Put the three measurements in a data frame.

    mouse.data <- data.frame(
  size   = c(1.4, 2.6, 1.0, 3.7, 5.5, 3.2, 3.0, 4.9, 6.3),
  weight = c(0.9, 1.8, 2.4, 3.5, 3.9, 4.4, 5.1, 5.6, 6.3),
  tail   = c(0.7, 1.3, 0.7, 2.0, 3.6, 3.0, 2.9, 3.9, 4.0))
mouse.data

    Python equivalent

    import pandas as pd
mouse = pd.DataFrame({"size":   [1.4,2.6,1.0,3.7,5.5,3.2,3.0,4.9,6.3],
                      "weight": [0.9,1.8,2.4,3.5,3.9,4.4,5.1,5.6,6.3],
                      "tail":   [0.7,1.3,0.7,2.0,3.6,3.0,2.9,3.9,4.0]})

  2. Always plot your data first. It shows whether a line is sensible. Here we can see a relationship.

    plot(mouse.data$weight, mouse.data$size)

    Python equivalent

    import matplotlib.pyplot as plt
plt.scatter(mouse["weight"], mouse["size"])

  3. Fit the line with lm(), which stands for linear model. The tilde reads as "is predicted by". R adds the intercept and the slope for you.

    simple.regression <- lm(size ~ weight, data = mouse.data)
summary(simple.regression)

    Python equivalent (statsmodels uses the same formula style)

    import statsmodels.formula.api as smf
simple = smf.ols("size ~ weight", data=mouse).fit()
print(simple.summary())

  4. The summary prints a big pile of output. For one predictor, read Multiple R-squared and the p-value. Then draw the fitted line.

    abline(simple.regression, col = "blue", lwd = 2)

    Python equivalent

    plt.plot(mouse["weight"], simple.fittedvalues, color="blue")

  5. Now start the multiple regression, and again plot first. Give plot() the whole data frame. R draws every column against every other column.

    plot(mouse.data)

    Python equivalent

    pd.plotting.scatter_matrix(mouse)   # or seaborn.pairplot(mouse)

  6. Fit the plane by adding the second predictor with a plus sign. This time read the adjusted R-squared, then the p-value on each coefficient row.

    multiple.regression <- lm(size ~ weight + tail, data = mouse.data)
summary(multiple.regression)

    Python equivalent

    multi = smf.ols("size ~ weight + tail", data=mouse).fit()
print(multi.summary())
multi.rsquared_adj, multi.pvalues

# explicit nested comparison of the two models
from statsmodels.stats.anova import anova_lm
anova_lm(simple, multi)

Formulas

The two models R fits
$$ \text{size} = \beta_0 + \beta_1\,\text{weight} $$
$$ \text{size} = \beta_0 + \beta_1\,\text{weight} + \beta_2\,\text{tail} $$

Symbols: \(\beta_0\) is the y-intercept, \(\beta_1\) and \(\beta_2\) are the slopes. R adds them all by default. What it tells you: the first draws a line, the second a plane.

Adjusted R-squared
$$ R^2_{adj} = 1 - (1 - R^2)\,\frac{n-1}{n-p-1} $$

Symbols: \(R^2\) is what R calls Multiple R-squared, \(n\) is the number of data points, \(p\) is the number of predictors. What it tells you: the share of explained variation, with a penalty per predictor, so a useless term pushes it down.

The p-value on a coefficient row
$$ t = \frac{\hat{\beta_j}}{SE(\hat{\beta_j})} $$

Symbols: \(\hat{\beta_j}\) is the estimated slope for one predictor and \(SE\) is its standard error. What it tells you: whether that slope could be zero once the other predictors are in the model.

Worked example from the video

Example

For the simple regression, R-squared is 0.613 and the p-value is 0.012. Together they say weight predicts size fairly well.

For the multiple regression, all three headline numbers look good. With two predictors, quote the adjusted R-squared.

The two coefficient rows are the interesting part. The weight row compares the full model against tail alone. Its p-value is large, so the pair is not better than tail alone. The tail row compares the full model against weight alone. Its p-value is small, so the pair is better than weight alone.

Both predictors work, but tail alone does the job. You can skip weighing the mice.

Common mistakes and subtle points

Watch out Plain R-squared can only rise when you add a term, even a worthless one. So use adjusted R-squared to compare models of different sizes.
Watch out A coefficient p-value is not a standalone verdict on that variable. It always means "given everything else in the model". Drop a term and the other p-values can change.
Watch out Correlated predictors are why weight looked useful alone but weak beside tail. The pairs plot shows this overlap before you fit anything.

If they ask you in an interview

Why report adjusted R-squared for multiple regression?
Plain R-squared never falls when you add a predictor, so it always favours the bigger model. Adjusted R-squared subtracts a penalty per parameter, so it can fall when a term adds nothing.
What does the p-value beside one coefficient test?
It tests whether that slope is zero while the other predictors stay in the model. In effect it compares the full model with the model that drops only that term.
Both predictors correlate with the outcome, but one is unnecessary. Why?
The predictors also correlate with each other, so they carry overlapping information. Once tail is in the model, weight has little new to add, and its p-value gets large. I keep whichever variable is cheaper to measure.
How would you do this in Python?
I use statsmodels. smf.ols("size ~ weight + tail", data=df).fit().summary() prints the same table as R.

Recap in 30 seconds

  • Plot the data first; plot(mouse.data) draws every pair of columns at once.
  • Fit with lm(size ~ weight), and add a predictor with a plus sign.
  • One predictor gives a line, two give a plane. Least squares fits both.
  • For simple regression read Multiple R-squared: here 0.613, p-value 0.012.
  • For multiple regression read adjusted R-squared, which penalises extra terms.
  • Each coefficient p-value compares the full model against the model without that term.
  • Weight adds nothing beside tail, so tail lengths alone are enough.
