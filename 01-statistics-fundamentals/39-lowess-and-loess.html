Lowess and Loess

▶ Watch on YouTube

This video shows how to fit a smooth curve to data instead of one straight line. The method is called lowess, or loess.

In one breath

Last time we fit one line to all the data with least squares. Lowess keeps that idea but applies it many times, in small local windows. For every data point, we take the nearest points on the x axis, give the near ones more weight, and fit a weighted least squares line. The height of that line above the focal point becomes one point of the new curve. We then add a second weight that pulls the curve away from outliers, and repeat until the curve is smooth.

The main idea

There are two main ideas. The first is a sliding window that cuts the data into small blobs. The second is that at each data point we fit a line with a type of least squares. If you know least squares, the rest is small extra detail.

Pick one data point and call it the focal point. Its window holds the points that are closest to it along the x axis. Inside that window every point gets a weight, which is how much influence it has on the fit. The focal point gets the most weight. The furthest point in the window gets the least.

Now fit a line through the window with those weights. Read the height of that line at the focal point's x value. That height is one point of the new, fitted curve. Then move on to the next data point and do it again.

Step by step

  1. Choose a window size. In the video the window holds five points. In practice you give a proportion of the points, not an exact count.
  2. Take the first data point as the focal point. Collect the points closest to it along the x axis. Distance along the y axis is never used here.
  3. Turn each x distance into a weight. The focal point is zero units away, so it gets the most weight. The furthest point gets the least.
  4. Fit a weighted least squares line through the window. It follows the near points and mostly ignores the far ones.
  5. Read the height of that line at the focal point's x value. Save it as the first point of the new curve. It is only a draft.
  6. Repeat with the next data point as the focal point. The window often holds the same points, because they are still the closest. The distances change, so the line changes too.
  7. When every point has a draft value, measure the vertical gap between each original point and its new point. Turn that gap into a second weight. A small gap gives a high weight.
  8. Run the whole procedure again with both sets of weights multiplied together. Repeat until the curve stops changing.

Formulas

Josh shows the weight functions as graphs, not as algebra. He says plainly that the shapes were chosen because they work well. There is no physical or biological reason for them. Below are the standard formulas behind those graphs.

Weighted least squares in one window
$$ \min_{a,\;b}\; \sum_{i=1}^{n} w_i \left( y_i - (a + b\,x_i) \right)^2 $$

Symbols: \(x_i\) and \(y_i\) are the coordinates of point \(i\). \(n\) is the number of points in the window. \(a\) is the intercept and \(b\) is the slope. \(w_i\) is the weight of point \(i\). What it tells you: it is ordinary least squares, but each squared error is multiplied by a weight. Heavy points steer the line and light points hardly matter.

Weight from distance along x (tricube)
$$ w_i = \left( 1 - \left| \frac{x_i - x_0}{d} \right|^{3} \right)^{3} $$

Symbols: \(x_0\) is the x value of the focal point. \(d\) is the distance to the furthest point in the window. Points outside the window get a weight of zero. What it tells you: the weight is 1 at the focal point and falls away fast, so the edge of the window barely pulls the line.

Weight from distance along y (robustness)
$$ r_i = y_i - \hat{y}_i, \qquad \delta_i = \left( 1 - \left( \frac{r_i}{6s} \right)^{2} \right)^{2} $$

Symbols: \(\hat{y}_i\) is the draft point on the new curve. \(r_i\) is the vertical gap between old and new. \(s\) is the median of the absolute gaps, which sets the scale. What it tells you: a point far from the draft curve loses its vote. That is how an outlier stops dragging the curve.

The two weights together, and the window size
$$ W_i = w_i \cdot \delta_i, \qquad k = f \cdot N $$

Symbols: \(W_i\) is the final weight used in the refit. \(f\) is the span, the proportion of the data in each window. \(N\) is the total number of points, and \(k\) is the window size. What it tells you: every refit uses both weights at once, and the span decides how local the curve is.

Worked example from the video

Example

Josh uses evenly spaced points and a window of five. The first focal point is the leftmost point. The other four points are 1, 2, 3 and 4 units away on the x axis, so their weights fall in that order. The furthest point barely moves the line, so the fit is less steep than a plain least squares line.

Now move to the second point. The five closest points are the same five, so the window does not move. Only the distances change, to 1, 0, 1, 2 and 3. New distances give new weights, so the line and the new point are different. The third point gives the same window again. Only at the fourth point does the window slide one place to the right.

When all the draft points exist, one outlier has clearly lifted several of them. The vertical gaps between old and new points become the second weights. The outlier gets a very low weight. Repeat the fit with both weights and the curve settles into a smooth progression.

Common mistakes and subtle points

Watch out Window membership uses distance along the x axis only. The video is explicit about this: a point that is far away vertically can still sit in the window. The y distance only matters later, in the second set of weights.
Watch out The window does not slide one place per step. It stays where it is until a different set of points becomes the closest set. The distances inside it still change every step, so the fit changes every step.
Watch out lowess and loess in R run the same idea but have different settings. lowess fits lines only. loess fits a line or a parabola, defaults to a parabola, and can draw confidence intervals around the curve. Check the data first and decide which shape suits it.
Watch out The span decides how the curve looks. The video compares windows holding a fifth of the points, a third, and the default of 75 per cent. A small span follows every wiggle; a large span flattens real structure.
Watch out The weight functions are conventions, not laws. Josh says there is no physical or biological reason for them, and another sensible shape would also work.

If they ask you in an interview

What is lowess, in plain terms?
It is local regression. Instead of one line for all the data, you slide a window along the x axis and fit a small weighted least squares line in each one. The height of that line at the focal point becomes one point on a smooth curve. It shows the shape of a relationship without assuming that shape.
There are two sets of weights. What does each one do?
The first set comes from distance along the x axis. It makes the fit local, so nearby points dominate. The second set comes from the vertical gap between each original point and its fitted point. It makes the fit robust, because outliers lose influence. You multiply the two and refit a few times.
How do you choose the window size?
You set it as a proportion of the data, not a count, so it scales with sample size. A small span gives a wiggly curve that chases noise. A large span gives a near straight line that hides real curvature. I plot two or three spans and pick the one that shows structure.
When would you use this instead of linear regression?
I use it for exploration and diagnostics, when I do not want to commit to a functional form. It is good for showing the trend in a scatter plot, or for checking whether residuals drift. It has no coefficients to interpret, so for explanation or extrapolation I go back to a parametric fit.

Recap in 30 seconds

  • Lowess fits a curve by fitting many small lines instead of one big line.
  • A sliding window picks the points nearest the focal point along the x axis only.
  • Inside the window, closer points get more weight and the focal point gets the most.
  • A weighted least squares fit gives one new curve point at the focal point's x value.
  • The window often stays still for several steps, but the distances and weights still change.
  • A second weight, based on the vertical gap between old and new points, removes the pull of outliers.
  • You repeat the weighted fit a few times until the curve is smooth.
  • You can fit lines or parabolas, and the span is the main setting you have to choose.
